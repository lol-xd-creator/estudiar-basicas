# Part II · The CLI skeleton

**CLI** means *command-line interface*: a program you use by typing commands such as `um scan terraria --json`. This part follows that command from the moment you press Enter until a Python function starts working.

| Chapter | You will learn |
|---|---|
| 3 · The entry point | `__main__.py`, `argparse` subcommands, importing modules by name, and storing functions in objects. |
| 4 · `common.py` | Small helpers: platform checks, path conversion, running other programs, and stopping with a clear error. |

These two chapters are short but dense with Python basics: modules, functions as objects, default arguments, exceptions and string slicing. If one of those feels rusty, follow the links.
