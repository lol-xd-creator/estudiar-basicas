## Todo en una tabla

::: ppt Fórmulas de la unidad
| Modelo | Densidad | Acumulación | $E(x)$ | $V(x)$ |
|---|---|---|---|---|
| **Uniforme** $(a;b)$ | $f(x) = \dfrac{1}{b-a}$, $a \le x \le b$ | $F(x) = \dfrac{x-a}{b-a}$ | $\dfrac{a+b}{2}$ | $\dfrac{(b-a)^2}{12}$ |
| **Exponencial** | $f(x) = \lambda e^{-\lambda x}$, $x \ge 0$ | $F(x) = 1 - e^{-\lambda x}$ | $\mu = \dfrac{1}{\lambda}$ | $\dfrac{1}{\lambda^2}$ |
| **Normal** $N(\mu;\sigma)$ | campana (fórmula abajo) | por tabla, con $z = \dfrac{x-\mu}{\sigma}$ | $\mu$ | $\sigma^2$ |
| **Normal estándar** $N(0;1)$ | | Tabla VI: $P(z < z_i)$ | $0$ | $1$ |
| **$t$ de Student** | | tabla $t$, fila $v = n-1$ | $0$ | $\dfrac{v}{v-2}$, $v > 2$ |
:::

## Qué modelo uso

::: tip Receta
1. **¿Es un tiempo o espacio *entre* sucesos que ocurren a un ritmo promedio (Poisson)?** → **exponencial**.
2. **¿Todos los valores de un intervalo $[a;b]$ son igual de posibles?** (o dan $f(x) = \frac{1}{b-a}$) → **uniforme**.
3. **¿Dicen que es normal, o dan media y desviación de una variable acampanada?** → **normal**: estandarizar y usar la tabla.
4. **¿Es binomial, hipergeométrica o Poisson con $n$ (o $\lambda$) grande?** → **aproximación normal** con la $E$ y la $\sigma$ del modelo discreto.
5. **¿Es una media de muestra pequeña con $\sigma$ desconocida?** → **$t$ de Student** con $n-1$ grados de libertad.
:::

::: ojo
En toda variable continua $P(x = a) = 0$, así que **$<$ y $\le$ dan lo mismo** (y $>$ y $\ge$ también). Rimoldi lo repite en cada caso: en los modelos discretos **no** es así.
:::
