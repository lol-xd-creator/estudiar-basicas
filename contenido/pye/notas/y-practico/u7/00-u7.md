# Práctico U7 · Muestreo

## Machete

::: claves
| Tema | Fórmula |
|---|---|
| **Sistemático** | $k = \dfrac{N}{n}$; arranque al azar entre 1 y $k$; después $a,\ a+k,\ a+2k, \dots$ |
| **Afijación igual** | $n_i = \dfrac{n}{r}$ |
| **Afijación proporcional** | $n_i = \dfrac{N_i}{N}\,n$ |
| **Afijación óptima (Neyman)** | $n_i = \dfrac{N_i\,\sigma_i}{\sum N_i\,\sigma_i}\,n$: se usa si las $\sigma_i$ son distintas |
| **Cantidad de muestras** | con reposición $N^n$; sin reposición $\binom{N}{n}$ |
| **Media muestral** | $E(\bar x) = \mu$; $\ \sigma_{\bar x} = \dfrac{\sigma}{\sqrt n}$ (MCR) o $\dfrac{\sigma}{\sqrt n}\sqrt{\dfrac{N-n}{N-1}}$ (MSR) |
| **Proporción muestral** | $E(\hat P) = P$; $\ \sigma_{\hat P} = \sqrt{\dfrac{PQ}{n}}$ (MCR) o $\times\sqrt{\dfrac{N-n}{N-1}}$ (MSR) |
| **Varianza corregida** | $E(\hat s^2) = \sigma^2$ (MCR) o $S^2 = \sigma^2\frac{N}{N-1}$ (MSR) |
| **Con TCL** ($n \ge 30$ o población normal) | $z = \dfrac{\bar x - \mu}{\sigma_{\bar x}}$; $\ z = \dfrac{\hat P - P}{\sigma_{\hat P}}$ |
:::

::: tip Distribución por enumeración, paso a paso
1. Parámetros de la población: $\mu$, $\sigma^2$ (divide por $N$), $S^2$ (divide por $N-1$), $P$.
2. Cantidad de muestras ($N^n$ o $\binom Nn$) y la lista de todas. Sin reposición se saca la diagonal y se toma un solo triángulo; si hay valores repetidos, son elementos distintos.
3. El estadístico en cada muestra.
4. La tabla de valores distintos con su probabilidad.
5. $E = \sum x\,P(x)$ y $V = \sum x^2 P(x) - E^2$.
6. Comparar con las fórmulas (con o sin factor de corrección).
:::

::: tip InfoStat
- **Todas las muestras posibles:** Aplicaciones → Didácticas → **Todas las muestras posibles**. Se cargan los valores de la población en una columna, el **tamaño muestral**, **M.A.S.** (o Sistemático) y qué calcular en cada muestra: *Media muestral*, *Varianza muestral corregida*, *Proporción de éxitos*… La salida trae también la media y la varianza poblacional.
- **Muestras al azar:** Aplicaciones → Didácticas → **Remuestreo** → método *Aleatorio con reposición* o *sin reposición*, número de muestras, tamaño y **semilla**. Con la misma semilla salen siempre las mismas muestras.
- **Media y varianza de una columna:** Estadísticas → **Medidas resumen** (n, Media, Var(n-1)).
- **Probabilidades con TCL:** Estadísticas → Probabilidades y cuantiles → Normal con media $\mu$ y **varianza $\frac{\sigma^2}{n}$** (la de $\bar x$).
:::
