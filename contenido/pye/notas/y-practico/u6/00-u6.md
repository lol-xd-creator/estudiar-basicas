# Práctico U6 · Modelos continuos

## Machete

::: claves
| Modelo | Cómo se reconoce | Fórmulas |
|---|---|---|
| **Normal** $N(\mu;\sigma)$ | dan media y desviación de una variable "acampanada" | $z = \dfrac{x - \mu}{\sigma}$; $\ x = \mu + z\,\sigma$ |
| **Uniforme** $(a;b)$ | todos los valores de $[a;b]$ igual de probables; $f(x) = \frac{1}{b-a}$ | $P(c<x<d) = \dfrac{d-c}{b-a}$; $E = \frac{a+b}{2}$; $V = \frac{(b-a)^2}{12}$ |
| **Exponencial** | tiempo o espacio **entre** sucesos; dan la media $\mu$ | $\lambda = \frac1\mu$; $P(x \le a) = 1 - e^{-a/\mu}$; $P(x > a) = e^{-a/\mu}$ |
| **Binomial → normal** | $n > 30$ | $E = nP$, $\sigma = \sqrt{nPQ}$ |
| **Poisson → normal** | $\lambda > 20$ | $E = \lambda$, $\sigma = \sqrt\lambda$ |
| **Hipergeométrico → normal** | sin reposición, $n/N > 0{,}05$, $n > 30$ | $E = n\frac{K}{N}$, $\sigma = \sqrt{n\frac KN(1-\frac KN)\frac{N-n}{N-1}}$ |
| **$t$ de Student** | tabla con grados de libertad | $\nu = n - 1$ (si dan $n$, restar 1) |
:::

### Con la tabla

::: tip Los casos de la tabla normal (Tabla VI: da $P(z < a)$)
| Se pide | Se hace |
|---|---|
| $P(z < a)$ | directo |
| $P(z > a)$ | $1 - P(z < a)$ |
| $P(a < z < b)$ | $P(z < b) - P(z < a)$ |
| $P(\lvert x - \mu\rvert < k\sigma)$ | $P(-k < z < k)$ |
| Dada la probabilidad | se busca en el cuerpo de la tabla y se lee $z$; después $x = \mu + z\sigma$ |
| "¿Cuántos…?" | $N \times$ probabilidad |
:::

En variables continuas **$<$ y $\le$ dan lo mismo**.

### Con InfoStat

::: tip InfoStat
**Estadísticas → Probabilidades y cuantiles.** Se elige la distribución a la izquierda y se completan sus parámetros:

| Distribución en InfoStat | Qué se carga |
|---|---|
| Normal (media, varianza) | $\mu$ y **$\sigma^2$** (¡la varianza, no la desviación!) |
| T Student (v) | $v = n - 1$ |
| Chi cuadrado (v) | $v = n - 1$ |
| Exponencial (lambda) | $\lambda = \frac{1}{\mu}$ |
| Uniforme (a,b) | $a$ y $b$ |
| Binomial (n,p), Poisson (lambda) | para comparar con la aproximación |

- **Dado $x$, la probabilidad:** escribir el valor en **Valor de x** y leer **Prob $(X \le x)$** o **Prob $(X > x)$**. Un intervalo es la resta de dos acumuladas.
- **Dada la probabilidad, el valor:** escribir la probabilidad en la casilla **Prob $(X \le x)$** (o **Prob $(X > x)$**) y presionar **Calcular**: aparece $x$.
- **Aproximaciones:** se usa **Normal** con la **media y la varianza del modelo discreto** ($nP$ y $nPQ$, o $\lambda$ y $\lambda$), sin estandarizar.
- Gráfico con el área: **Aplicaciones → Didácticas → Gráficos de funciones de densidad continuas** (opciones *Menores o iguales que*, *Mayores o iguales que*, *Entre* y *Complementario*).
:::
