# Práctico U8 · Estimación

## Machete

::: claves
| Qué | Fórmula |
|---|---|
| **IC para $\mu$, $\sigma$ conocida** | $\bar x \pm z_{1-\alpha/2}\,\dfrac{\sigma}{\sqrt n}$ |
| **IC para $\mu$, $\sigma$ desconocida, $n \ge 30$** | $\bar x \pm z_{1-\alpha/2}\,\dfrac{\hat s}{\sqrt n}$ |
| **IC para $\mu$, $\sigma$ desconocida, $n < 30$** (población normal) | $\bar x \pm t_{(n-1);\,1-\alpha/2}\,\dfrac{\hat s}{\sqrt n}$ |
| **IC para $P$** | $\hat P \pm z_{1-\alpha/2}\sqrt{\dfrac{\hat P(1-\hat P)}{n}}$ |
| **Sin reposición** ($n > 5\,\%$ de $N$) | error estándar $\times\sqrt{\dfrac{N-n}{N-1}}$ |
| **Tamaño para $\mu$** | $n \ge \dfrac{z^2\sigma^2}{e^2}$ |
| **Tamaño para $P$** | $n \ge \dfrac{z^2 P(1-P)}{e^2}$; sin datos, $P = 0{,}5$ |
| **Expresión del riesgo** | $P(\lvert\hat\theta - \theta\rvert > e) = \alpha$ |

| Confianza | 90 % | 95 % | 95,45 % | 98 % | 99 % | 99,73 % |
|---|---|---|---|---|---|---|
| $z_{1-\alpha/2}$ | 1,645 | 1,96 | 2 | 2,326 | 2,576 | 3 |
:::

::: tip Receta del intervalo
1. Parámetro ($\mu$ o $P$) y estimación puntual ($\bar x$ o $\hat P$). Si dan datos: calcular $\bar x$ y $\hat s^2 = \frac{\sum(x_i - \bar x)^2}{n-1}$.
2. Elegir $z$ o $t$ (¿población normal?, ¿$\sigma$ conocida?, ¿$n \ge 30$?).
3. Error: $e$ = coeficiente $\times$ error estándar. $n$ siempre se redondea **hacia arriba**.
4. Intervalo $[\text{estimación} - e;\ \text{estimación} + e]$ y conclusión: "con un X % de confianza, el parámetro está entre … y …; el error de estimación es a lo sumo $e$".
:::

::: tip InfoStat
- **Intervalo con datos:** cargar los datos en una columna (Archivo → Nueva tabla; el nombre, en Datos → Acciones sobre columnas → Editar etiqueta) → Estadísticas → Inferencia basada en una muestra → **Intervalos de confianza** → elegir la variable → tildar **Media** (o **Proporción** con *Éxitos valores =* 1, o **Varianza**), *Estimación paramétrica*, **Bilateral**, la **confianza** → Aceptar.
- **Cómo se lee la salida:** *Estimación* = estimación puntual ($\bar x$ o $\hat P$); *E.E.* = error estándar estimado ($\frac{\hat s}{\sqrt n}$ o $\sqrt{\hat P(1-\hat P)/n}$); *n*; *LI* y *LS* = límites. El error es $e = LS - \text{Estimación}$.
- **Proporción:** la columna lleva 1 (éxito) y 0 (fracaso), por ejemplo 90 unos y 110 ceros.
- **Tamaño de muestra:** Estadísticas → **Cálculo del tamaño muestral**:
  - *Para estimar una media con una precisión deseada*: **Amplitud** del intervalo $= 2e$, la confianza y la **cota superior para la varianza** ($\sigma^2$).
  - *Para estimar una proporción*: amplitud en porcentaje ($2e \cdot 100$), confianza y proporción.
- InfoStat usa **$t$ con $n-1$** aunque $n$ sea grande: con $n \ge 30$ da casi lo mismo que $z$.
:::
