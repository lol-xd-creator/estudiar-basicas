# Práctico U9 · Pruebas de hipótesis

## Machete

::: claves
| Paso | Qué hacer |
|---|---|
| 1. Hipótesis | $H_0$ con la igualdad; $H_1$ con lo que se quiere **probar** o lo que **preocupa** ("si es menor, se suspende la compra" → $H_1: \mu < \mu_0$) |
| 2. Estadístico | $\sigma$ conocida: $z = \dfrac{\bar x - \mu_0}{\sigma/\sqrt n}$ · $\sigma$ desconocida y $n < 30$: $t_{n-1} = \dfrac{\bar x - \mu_0}{\hat s/\sqrt n}$ · $n \ge 30$: $z$ con $\hat s$ · proporción: $z = \dfrac{\hat P - P_0}{\sqrt{P_0Q_0/n}}$ |
| 3. Punto crítico | derecha $\mu_0 + z_{1-\alpha}\,\sigma_{\bar x}$ · izquierda $\mu_0 - z_{1-\alpha}\,\sigma_{\bar x}$ · bilateral $\mu_0 \mp z_{1-\alpha/2}\,\sigma_{\bar x}$ |
| 4. Decisión | ¿el estimador observado cae en la zona de rechazo? ¿o el valor p es menor que $\alpha$? |
| 5. Conclusión | en términos del problema; si se rechaza, puede haber error **tipo I**; si no se rechaza, error **tipo II** |
| 6. $\beta$ y potencia | se usa **el mismo punto crítico**, estandarizado con $\mu_1$ (o $P_1$ y su propia desviación): $\beta$ = área de aceptación bajo $H_1$; $1 - \beta$ = área de rechazo |

| $\alpha$ | 0,10 | 0,05 | 0,025 | 0,01 |
|---|---|---|---|---|
| Lateral ($z_{1-\alpha}$) | 1,28 | 1,645 | 1,96 | 2,326 |
| Bilateral ($z_{1-\alpha/2}$) | 1,645 | 1,96 | 2,24 | 2,576 |
:::

::: tip InfoStat
- **Dócima con datos:** cargar la columna → Estadísticas → Inferencia basada en una muestra → **Prueba t para una media** → elegir la variable → tildar *n, Media, DE, T, p* → tipo de prueba (**Bilateral**, **Unilateral derecha** o **Unilateral izquierda**) → **valor del parámetro** $\mu_0$ → Aceptar.
- **Cómo se lee la salida:** `n | Media | DE | T | p(Unilateral D)`. *T* es el estadístico $\frac{\bar x - \mu_0}{DE/\sqrt n}$ y *p* el **valor p**. Si **$p < \alpha$ se rechaza $H_0$**.
- **Puntos críticos, $\beta$ y potencia** (cuando $\sigma$ es conocida): Aplicaciones → Didácticas → **Gráficos de funciones de densidad continuas** → Normal con **media $\mu_0$** y **varianza de la media muestral** $\frac{\sigma^2}{n}$ → *Mayores o iguales que* (derecha), *Menores o iguales que* (izquierda) o *Entre* (bilateral, con $1-\alpha$) → da el punto crítico. **Clonar** el gráfico, cambiar la media por $\mu_1$ → el área de rechazo es la **potencia**; con **Complementario** se obtiene $\beta$.
- **Solo los valores de tabla:** Estadísticas → Probabilidades y cuantiles (Normal o T Student).
:::
