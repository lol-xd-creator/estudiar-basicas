# 6 · Verbos modales y deducción

Los **modales** (*can, could, may, might, must, should, will, would*) agregan una "actitud" al verbo: capacidad, permiso, obligación, consejo o qué tan seguro estás de algo. Esta unidad es de las que más preguntas tienen, en B2 (obligación, *mustn't* contra *don't have to*) y en C1 (deducción en pasado: *must have done*, *can't have done*, *should have done*).

::: claves
- **Los modales no cambian:** sin *-s* (*she can*), sin *to* después (*can go*), sin *do* (*Can you...?*).
- ***mustn't*** = está **prohibido**. ***don't have to*** = **no hace falta**. Son opuestos.
- **Deducción en presente:** ***must be*** (seguro que sí), ***can't be*** (seguro que no), ***might/may/could be*** (puede ser). Nunca *mustn't* para "seguro que no".
- **Deducción en pasado:** modal + ***have*** + **participio**: *must have failed*, *can't have seen*, *might have been*.
- **Crítica o arrepentimiento:** *should have tested* (debería haber), *shouldn't have pushed*.
- ***needn't have done*** (lo hiciste y no hacía falta) ≠ ***didn't need to do*** (no hacía falta, normalmente no lo hiciste).
- **Un logro puntual en el pasado:** *was able to / managed to*, no *could*.
:::

## Cómo funcionan

| Regla | Bien | Mal |
|---|---|---|
| Sin *-s* en tercera persona | *She **can** code.* | *She cans code.* |
| Después va la **base**, sin *to* | *You **should check** the logs.* | *You should to check.* |
| Preguntas sin *do* | ***Can** you help me?* | *Do you can help me?* |
| Negación con *not* | *You **mustn't** share passwords.* | *You don't must share.* |
| No hay dos modales juntos | *You **will be able to** deploy.* | *You will can deploy.* |

Los modales no tienen infinitivo, participio ni *-ing*. Para otros tiempos se usan **sustitutos**:

| Modal | Sustituto | Ejemplo en otro tiempo |
|---|---|---|
| *can* (poder, saber) | ***be able to*** | ***I'll be able to** join the call.* / ***I've never been able to** use Vim.* |
| *must* (deber) | ***have to*** | *We **had to** restart the server.* / *You **will have to** sign the NDA.* |
| *can* (permiso) | ***be allowed to*** | *We **weren't allowed to** use ChatGPT during the test.* |

::: ojo
**Semimodales con *to*:** *have to, need to, ought to, be able to, be allowed to* sí llevan *to*. *ought to* = *should*: *You **ought to** update the library.*
:::

## Capacidad: *can*, *could*, *be able to*

- **Presente:** *She **can** speak three languages.*
- **Pasado, capacidad general:** *I **could** read English when I was ten.*
- **Pasado, logro en una ocasión concreta:** ***was able to*** o ***managed to***, **no *could***.

| Oración | Por qué |
|---|---|
| *Despite the outage, we **were able to** deploy on time.* ✓ | Lo logramos esa vez. |
| *Despite the outage, we **managed to** deploy on time.* ✓ | Ídem (con esfuerzo). |
| *Despite the outage, we could deploy on time.* ✗ | *could* = capacidad general, no un logro puntual. |
| *We **couldn't** deploy on time.* ✓ | En negativa, *couldn't* sirve para las dos cosas. |

## Permiso: *can*, *could*, *may*, *be allowed to*

| Forma | Registro | Ejemplo |
|---|---|---|
| ***Can** I...?* | Normal | ***Can** I use your charger?* |
| ***Could** I...?* | Más educado | ***Could** I ask you a question?* |
| ***May** I...?* | Formal | ***May** I come in?* |
| ***be allowed to*** | Reglas, cualquier tiempo | *Interns **are allowed to** work remotely on Fridays.* |

## Obligación, prohibición y necesidad

| Forma | Significado | Ejemplo |
|---|---|---|
| ***must*** | Obligación (a menudo del que habla, o reglas escritas). | *All passwords **must** contain at least 12 characters.* |
| ***have to*** | Obligación externa (reglas, circunstancias). | *I **have to** wear a badge in the office.* |
| ***need to*** | Necesidad. | *You **need to** install Python 3.12 first.* |
| ***mustn't*** | **Prohibido.** | *You **mustn't** commit API keys to the repository.* |
| ***don't have to*** / ***don't need to*** / ***needn't*** | **No hace falta** (podés, pero no es obligatorio). | *You **don't have to** come to the office on Fridays.* |
| ***should*** / ***ought to*** | **Consejo**, lo recomendable. | *You **should** write tests before refactoring.* |
| ***had better*** (*'d better*) + base | Advertencia: si no, algo malo pasa. | ***You'd better back up** the database first.* |

::: ojo
**La trampa número uno:**

- *You **mustn't** use the production database for tests.* — está **prohibido**.
- *You **don't have to** use the production database for tests.* — **no es obligatorio**, podés usar otra.

En castellano "no tenés que" suena a prohibición; en inglés, ***don't have to*** **no** prohíbe.

**El pasado de *must* (obligación) es *had to*:** *Yesterday I **had to** work late* (nunca *I musted*).
:::

## Deducción: qué tan seguro estás

Los modales también sirven para **sacar conclusiones** a partir de evidencia.

### En presente: modal + base

| Qué tan seguro | Modal | Ejemplo |
|---|---|---|
| Seguro que **sí** (~95 %) | ***must*** | *She's not answering. She **must be** in a meeting.* |
| Es **posible** (~50 %) | ***may / might / could*** | *It **might be** a caching problem.* |
| Seguro que **no** (~95 %) | ***can't / couldn't*** | *It **can't be** a hardware issue: the other servers are fine.* |

Para una acción en curso: modal + ***be*** + ***-ing***: *He **must be working** from home today.*

### En pasado: modal + *have* + participio

| Qué tan seguro | Forma | Ejemplo |
|---|---|---|
| Seguro que **sí** | ***must have*** + participio | *The build **must have failed** during the night: there's an alert.* |
| Es **posible** | ***may / might / could have*** + participio | *Someone **might have changed** the config.* |
| Seguro que **no** | ***can't / couldn't have*** + participio | *She **can't have seen** my message: she was on a plane.* |

::: ojo
- **"Seguro que no" es *can't*, nunca *mustn't*:** *It mustn't be the cache* ✗ → *It **can't be** the cache* ✓. *mustn't* solo significa prohibición.
- **Después del modal va *have*, no *has* ni *had*:** *She must **have** left*, nunca *She must has left*.
- ***couldn't have*** también sirve para "seguro que no" en pasado: *He **couldn't have known**.*
:::

## Modales perfectos: crítica, arrepentimiento y posibilidades perdidas

| Forma | Significado | Ejemplo |
|---|---|---|
| ***should have*** + participio | Debería haberlo hecho (y no lo hice). | *We **should have tested** it on staging first.* |
| ***shouldn't have*** + participio | No debería haberlo hecho (y lo hice). | *I **shouldn't have pushed** directly to main.* |
| ***could have*** + participio | Era posible (y no pasó). | *You **could have asked** me for help!* / *It **could have been** worse.* |
| ***would have*** + participio | Lo habría hecho (condición no cumplida, unidad 7). | *I **would have helped** you, but I was busy.* |
| ***needn't have*** + participio | Lo hiciste, **pero no hacía falta**. | *You **needn't have bought** a new laptop: we provide one.* |
| ***didn't need to*** + base | No hacía falta (en general, **no lo hiciste**). | *I **didn't need to** buy a laptop: the company gave me one.* |

## Preferencias: *would rather* y *would prefer*

- ***would rather*** + base: ***I'd rather work** remotely **than** commute.*
- ***would rather*** + **otra persona** + **pasado**: ***I'd rather you didn't push** to main.* (preferiría que no...)
- ***would prefer*** + ***to*** + base: ***I'd prefer to** start tomorrow.*

## Resumen: un modal, varios significados

| Modal | Significados |
|---|---|
| *can* | capacidad, permiso, posibilidad general (*Bugs **can** appear anywhere*), *can't* = deducción negativa |
| *could* | capacidad pasada, permiso educado, posibilidad, *could have* = posibilidad perdida |
| *may / might* | posibilidad, *may* = permiso formal |
| *must* | obligación, deducción positiva |
| *should* | consejo, expectativa (*The build **should** finish in 5 minutes*) |

## Ejemplos en inglés técnico

- *Users **must** enable two-factor authentication to access the platform.*
- *You **don't have to** know machine learning to use this API.*
- *The model's answer **can't be** right: it says the project started in 2030.*
- *The server **must have restarted**: the uptime counter is at zero.*
- *We **should have documented** the endpoints before the new developers joined.*
- *AI assistants **may** produce code that looks correct but **might** contain subtle bugs.*
- *Thanks to the backups, we **were able to** restore the data in less than an hour.*

## Preguntas tipo examen

::: pregunta Choose the correct option: "You ___ share your password with anyone, not even with the IT team."
- [ ] don't have to
- [x] mustn't
- [ ] needn't
- [ ] couldn't
::: solucion Explicación
Es una **prohibición**: ***mustn't***. *don't have to* y *needn't* significan "no hace falta", que cambiaría el sentido por completo (como si compartirla fuera opcional).
:::
:::

::: pregunta Choose the correct option: "Employees ___ come to the office on Fridays; they can work from home if they prefer."
- [ ] mustn't
- [x] don't have to
- [ ] can't
- [ ] shouldn't
::: solucion Explicación
*they can work from home if they prefer*: no es obligatorio venir, pero tampoco está prohibido. Eso es ***don't have to***. *mustn't* y *can't* dirían que está prohibido venir.
:::
:::

::: pregunta Choose the correct option: "Ana isn't answering her messages. She ___ in a meeting."
- [x] must be
- [ ] must have
- [ ] can't be
- [ ] should be
::: solucion Explicación
**Deducción** a partir de evidencia (no contesta): ***must be*** = seguro que está en una reunión. *can't be* diría lo contrario. *should be* expresa expectativa ("debería estar"), no deducción.
:::
:::

::: pregunta Choose the correct option: "That ___ a hardware problem. The same code works perfectly on the other machines."
- [ ] mustn't be
- [x] can't be
- [ ] mightn't have
- [ ] doesn't have to be
::: solucion Explicación
"Seguro que no" en presente es ***can't be***. ***mustn't*** **nunca** se usa para deducción: solo para prohibición. Es una de las trampas más comunes del examen.
:::
:::

::: pregunta Choose the correct option: "The tests passed yesterday and now they fail. Someone ___ the configuration."
- [ ] must change
- [x] must have changed
- [ ] must has changed
- [ ] must had changed
::: solucion Explicación
**Deducción sobre el pasado**: ***must have*** + **participio**. Después de un modal va siempre ***have*** (base), nunca *has* ni *had*.
:::
:::

::: pregunta Choose the correct option: "She ___ my email. She was on a flight with no internet all day."
- [ ] mustn't have read
- [x] can't have read
- [ ] shouldn't have read
- [ ] needn't have read
::: solucion Explicación
"Seguro que no" sobre el **pasado**: ***can't have*** + participio (o *couldn't have*). *mustn't have* no existe con valor de deducción. *shouldn't have read* sería una crítica ("no debería haberlo leído").
:::
:::

::: pregunta Choose the correct option: "We lost all the data. We ___ a backup before the migration."
- [ ] must have made
- [x] should have made
- [ ] could make
- [ ] needn't have made
::: solucion Explicación
**Crítica o arrepentimiento** sobre el pasado (no lo hicimos y fue un error): ***should have*** + participio. *must have made* sería una deducción ("seguro que hicimos un backup"), que contradice *We lost all the data*.
:::
:::

::: pregunta Choose the correct option: "You ___ printed the documents. Everything is available online."
- [ ] didn't need to
- [x] needn't have
- [ ] mustn't have
- [ ] don't have to
::: solucion Explicación
Los imprimiste (*printed* ya está en participio) **y no hacía falta**: ***needn't have*** + participio. *didn't need to* iría con la base (*didn't need to print*) y no dice si lo hiciste.
:::
:::

::: pregunta Choose the correct option: "The internet connection was terrible, but we ___ finish the demo on time."
- [ ] could
- [x] were able to
- [ ] can
- [ ] might
::: solucion Explicación
Es un **logro puntual** en el pasado (esa vez, con dificultades): ***were able to*** (o *managed to*). ***could*** en afirmativa expresa capacidad general en el pasado, no un logro de una ocasión concreta.
:::
:::

::: pregunta Choose the correct option: "In the future, AI tools ___ to write most of the boilerplate code for us."
- [ ] will can
- [x] will be able
- [ ] will able
- [ ] can will
::: solucion Explicación
No se pueden juntar dos modales (*will can* ✗). Para *can* en futuro se usa el sustituto ***be able to***: *will **be able to** write*. Fijate que el *to* ya está después del hueco.
:::
:::

::: pregunta Choose the correct option: "Yesterday I ___ stay late because the release was delayed."
- [ ] must
- [ ] musted
- [x] had to
- [ ] must to
::: solucion Explicación
*must* no tiene pasado: para la obligación en pasado se usa ***had to***. *must to* agrega un *to* que los modales no llevan.
:::
:::

::: pregunta Choose the correct option: "The client ___ have approved the budget, but I'm not sure. Let's wait for the email."
- [ ] must
- [x] might
- [ ] can't
- [ ] should
::: solucion Explicación
*but I'm not sure* marca **posibilidad** (~50 %): ***might have*** + participio (o *may/could have*). *must* sería certeza y *can't* sería certeza negativa.
:::
:::

::: pregunta Choose the correct option: "I'd rather you ___ the meeting until next week."
- [ ] don't postpone
- [ ] not to postpone
- [x] didn't postpone
- [ ] won't postpone
::: solucion Explicación
***would rather*** + **otra persona** + **pasado** (aunque se hable del presente o del futuro): *I'd rather you **didn't postpone***. Con el mismo sujeto sería *I'd rather not postpone it*.
:::
:::

::: pregunta Choose the correct option: "You ___ update your dependencies regularly. Old versions can have security vulnerabilities."
- [x] should
- [ ] must to
- [ ] had better to
- [ ] ought
::: solucion Explicación
Es un **consejo**: ***should*** + base. *must to* y *had better to* agregan un *to* que no va. *ought* necesita *to* (*ought to update*).
:::
:::
