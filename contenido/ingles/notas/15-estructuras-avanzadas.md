# 15 · C1 (2): subjuntivo, participle clauses, elipsis y estructuras avanzadas

El segundo bloque de C1 junta estructuras que hacen que un texto suene "avanzado": el **subjuntivo** (*It is essential that he **be** there*), las ***participle clauses*** (*Having finished the tests, we...*), la **elipsis** (*So do I*, *I hope so*), el lenguaje prudente (*hedging*), el **registro formal** y los ***idioms*** de oficina.

::: claves
- **Subjuntivo:** después de *suggest, recommend, insist, demand, require* y *It is essential / vital / important that...*, va la **base** del verbo para todas las personas: *that he **review**, that it **be***.
- ***as if / as though*** + pasado para algo irreal: *He talks **as if** he **knew** everything.*
- ***Participle clauses:*** *-ing* (activo, al mismo tiempo), ***having*** + participio (antes), participio solo (pasivo). **El sujeto tiene que ser el mismo** que el de la oración principal.
- **Elipsis:** *So do I* / *Neither can I*; *I think **so*** / *I hope **not***.
- ***Hedging*** (decir algo con prudencia): *It appears that, tends to, is likely to, arguably, to some extent*.
- **Registro formal:** *obtain* (get), *require* (need), *assist* (help), *purchase* (buy).
- ***no matter*** / ***-ever***: *However hard we try, ...*
:::

## El subjuntivo

En castellano el subjuntivo está en todos lados ("sugiero que **revise**"). En inglés casi desapareció, pero sobrevive en estructuras formales: después de verbos y adjetivos de **sugerencia, exigencia o importancia**, va la **base** del verbo, **sin *-s*** y con ***be*** en vez de *is/are*.

| Después de... | Ejemplo |
|---|---|
| ***suggest, recommend, propose, insist, demand, request, require, ask*** + ***that*** | *The auditor **recommended that** the company **review** its policies.* (no *reviews*) |
| ***It is essential / vital / important / crucial / necessary / imperative*** + ***that*** | ***It is essential that** every user **be** verified.* (no *is*) |
| Negativa: ***not*** + base | *We insisted that he **not be** given admin access.* |

En inglés británico también se usa ***should*** + base: *They recommended that the company **should review** its policies*.

**Expresiones fijas con subjuntivo:** *if need **be*** (si hace falta), *be that as it may* (sea como sea), *so **be** it*, *come what may*.

::: ojo
- *She suggested that he **reviews** the code* ✗ en el registro del examen → *that he **review*** ✓.
- *It's important that the server **is** restarted* se oye, pero en un examen C1 la respuesta es *that the server **be** restarted*.
:::

### El "pasado" irreal: *were*, *as if*, *as though*

Ya lo viste con *If I were you*, *wish* e *It's time* (unidades 6 y 7). También va con ***as if*** y ***as though*** (como si), cuando lo que sigue **no es real**:

- *He talks **as if** he **knew** everything about AI.* (no sabe tanto)
- *She acts **as though** she **were** the manager.* (no lo es)
- *It looks **as if** **it's going to** rain.* (si es probable, va el tiempo normal)

## *Participle clauses*

Son cláusulas **sin sujeto ni conjunción**, que empiezan con un participio. Hacen el texto más compacto y formal.

| Forma | Qué expresa | Ejemplo | Equivale a |
|---|---|---|---|
| ***-ing*** (participio presente) | Algo **simultáneo**, o la **causa** (activo) | ***Working** remotely, I save two hours a day.* | *Because I work remotely, ...* |
| | | ***Not knowing** the answer, I asked my mentor.* | *As I didn't know...* |
| ***Having*** + participio | Algo **anterior** (activo) | ***Having finished** the tests, we merged the branch.* | *After we had finished...* |
| Participio solo | **Pasivo** | ***Trained** on huge datasets, LLMs can write fluent text.* | *Because they are trained...* |
| | | ***Built** in 2010, the system is now hard to maintain.* | *It was built in 2010, and...* |
| ***Having been*** + participio | Pasivo y anterior | ***Having been tested** thoroughly, the app was released.* | *After it had been tested...* |

**Expresiones fijas:** ***Given that*** (dado que), ***Compared with / to*** (comparado con), ***Considering*** (teniendo en cuenta), ***Generally speaking***, ***Judging by***.

- ***Given that** the budget is limited, we'll use open-source tools.*
- ***Compared with** last year, response times have improved by 30%.*

::: ojo
**El participio "colgado" (*dangling participle*):** el sujeto implícito de la *participle clause* tiene que ser **el mismo** que el de la oración principal.

| Mal | Por qué | Bien |
|---|---|---|
| ***Walking** into the office, **the server** crashed.* | Parece que el servidor entró caminando. | ***Walking** into the office, **I** saw that the server had crashed.* |
| ***Having finished** the report, **the computer** was shut down.* | La computadora no terminó el informe. | ***Having finished** the report, **she** shut down the computer.* |
:::

## Elipsis y sustitución

El inglés evita repetir: reemplaza o directamente omite lo que ya se dijo.

### *So do I* / *Neither do I*

Para decir "yo también" o "yo tampoco", se repite **el auxiliar** de la oración original, con inversión:

| Original | "Yo también" | "Yo tampoco" |
|---|---|---|
| *I **love** Python.* (sin auxiliar → *do*) | ***So do I**.* | |
| ***I'm** tired.* | ***So am I**.* | |
| *I **can't** attend.* | | ***Neither can I**.* / ***Nor can I**.* |
| *She **didn't** like the talk.* | | ***Neither did I**.* |
| ***I've** finished.* | ***So have I**.* | |

En el habla informal: *Me too* / *Me neither*. Para decir lo contrario, sin inversión: *I love Python. — **I don't**.* / *I can't attend. — **I can**.*

### *I think so* / *I hope not*

Para no repetir una oración entera, se usa ***so*** (afirmativo) o ***not*** (negativo):

| Pregunta | Afirmativo | Negativo |
|---|---|---|
| *Will the build pass?* | *I **think so**.* / *I **hope so**.* | *I **don't think so**.* / *I **hope not**.* |
| *Is the server down?* | *I'm **afraid so**.* | *I'm **afraid not**.* |
| *Did they approve it?* | *I **suppose so**.* / *I **guess so**.* | *I **suppose not**.* |

::: ojo
- *I think **it*** ✗ / *I think **yes*** ✗ → *I think **so*** ✓.
- Con *hope* y *afraid*, la negativa es con ***not***: *I hope **not*** ✓ (no *I don't hope so*). Con *think*, lo natural es *I **don't** think so*.
:::

### Omitir el verbo después del auxiliar o de *to*

- *She can speak Polish, but I **can't**.* (no hace falta repetir *speak Polish*)
- *I wanted to call you, but I didn't have time **to**.* (el *to* reemplaza a *to call you*)
- *Have you pushed your changes? — Yes, I **have**.*

### *one / ones* y *do so*

- *I don't like this laptop. I prefer the new **one**.* / *These tests are better than the old **ones**.*
- *If you want to leave early, you can **do so**.* (formal, en vez de repetir el verbo)

## Hablar con prudencia: *hedging*

En textos técnicos y académicos no se afirman las cosas de forma absoluta: se "suavizan". Las preguntas de lectura (unidad 16) suelen jugar con esa diferencia entre "es" y "parece ser".

| Recurso | Ejemplo |
|---|---|
| ***seem / appear*** + *to* | *The model **appears to** perform better on short texts.* |
| ***It seems / appears that*** | ***It appears that** the attack started in March.* |
| ***tend to*** | *Larger models **tend to** be more accurate.* |
| ***be likely / unlikely to*** | *Prices **are likely to** fall.* |
| modales: ***may, might, could*** | *This **may** explain the delay.* |
| adverbios: ***arguably, apparently, possibly, presumably, supposedly, allegedly*** | *Python is **arguably** the most popular language for AI.* |
| ***to some extent / to a certain degree*** | *The results are, **to some extent**, encouraging.* |
| ***It could be argued that*** | ***It could be argued that** AI will create more jobs than it destroys.* |

Lo contrario, para reforzar (*boosting*): ***clearly, undoubtedly, certainly, without a doubt, it is evident that***.

## Registro formal contra informal

En emails formales, informes y textos del examen, se prefieren palabras de origen latino a los *phrasal verbs* y palabras cortas:

| Informal | Formal |
|---|---|
| *get* | *obtain, receive* |
| *need* | *require* |
| *help* | *assist* |
| *ask for* | *request* |
| *find out* | *discover, determine* |
| *start / begin* | *commence* |
| *buy* | *purchase* |
| *tell* | *inform* |
| *try* | *attempt* |
| *show* | *demonstrate* |
| *think about* | *consider* |
| *go up / go down* | *increase / decrease* |
| *enough* | *sufficient* |
| *about* (aproximadamente) | *approximately* |
| *a lot of* | *a considerable number / amount of, numerous* |
| *so* | *therefore* |
| *but* | *however* |
| *sorry* | *we apologise for* |

Además, en lo formal **no se usan contracciones** (*do not*, no *don't*) y se usa más la pasiva.

## *Idioms* del trabajo

Un ***idiom*** es una expresión cuyo significado no sale de sus palabras. Estas aparecen mucho en contextos de oficina:

| *Idiom* | Significado |
|---|---|
| ***be on the same page*** | estar de acuerdo, entender lo mismo |
| ***cut corners*** | hacer algo mal o a medias para ahorrar tiempo o plata |
| ***the bottom line*** | lo esencial, el resultado final |
| ***a steep learning curve*** | algo que cuesta mucho aprender al principio |
| ***in the long run*** | a largo plazo |
| ***get the hang of*** | agarrarle la mano a algo |
| ***from scratch*** | desde cero |
| ***back to square one*** | volver al punto de partida |
| ***hit the ground running*** | arrancar algo con todo, rendir desde el primer día |
| ***keep someone in the loop*** | mantener a alguien informado |
| ***bring someone up to speed*** | poner a alguien al día |
| ***call it a day*** | dar por terminado el día de trabajo |
| ***touch base*** | ponerse en contacto brevemente |
| ***a ballpark figure*** | un número aproximado |
| ***the ball is in your court*** | te toca decidir o actuar a vos |
| ***bite off more than you can chew*** | abarcar más de lo que se puede |
| ***low-hanging fruit*** | lo más fácil de conseguir primero |
| ***a game changer*** | algo que cambia las reglas del juego |
| ***think outside the box*** | pensar de forma creativa |
| ***a piece of cake*** | muy fácil |
| ***under the weather*** | medio enfermo |

## Otras estructuras de C1

| Estructura | Significado | Ejemplo |
|---|---|---|
| ***no matter*** + *what / how / who / where* | no importa qué / cómo... | ***No matter how** hard we try, the tests keep failing.* |
| ***whatever / however / whoever / wherever*** | ídem, más formal | ***However** hard we try, ... / **Whatever** you decide, let me know.* |
| ***be bound to*** + base | ser seguro que pasará | *If you don't test it, something **is bound to** break.* |
| ***be on the verge of*** + *-ing* / sustantivo | estar al borde de | *The startup **is on the verge of** closing a big deal.* |
| ***it's no wonder (that)*** | no es raro que | ***It's no wonder** the app is slow: it loads 50 MB of images.* |
| ***would sooner*** + base | preferiría (= *would rather*) | *I **would sooner** rewrite it than fix it.* |
| ***were to*** + base | si llegara a (hipótesis) | *If the server **were to** fail, the backup would take over.* |

## Ejemplos en inglés técnico

- ***It is essential that** all personal data **be** encrypted at rest and in transit.*
- *The security team **recommended that** every employee **use** a password manager.*
- ***Having analysed** the logs, the engineers identified the root cause.*
- ***Released** in 2022, ChatGPT quickly became one of the fastest-growing applications in history.*
- *AI-generated code **tends to** look correct, but it **may** contain subtle errors.*
- *We didn't want to **cut corners**, so we rebuilt the authentication module **from scratch**.*
- *Will the migration be ready by Friday? — **I'm afraid not**.*

## Preguntas tipo examen

::: pregunta Choose the correct option: "The security consultant recommended that every employee ___ two-factor authentication."
- [ ] enables
- [x] enable
- [ ] enabled
- [ ] is enabling
::: solucion Explicación
Después de ***recommend that*** va el **subjuntivo**: la base del verbo, **sin *-s***, aunque el sujeto sea *every employee*. Es la forma más típica de C1. También valdría *should enable*.
:::
:::

::: pregunta Choose the correct option: "It is vital that the database ___ backed up before the migration starts."
- [ ] is
- [x] be
- [ ] will be
- [ ] was
::: solucion Explicación
Después de ***It is vital / essential / important that*** va el subjuntivo: ***be***, para todas las personas. En pasiva: *be backed up*.
:::
:::

::: pregunta Choose the correct option: "He talks about machine learning as if he ___ an expert, but he has never trained a model."
- [ ] is
- [x] were
- [ ] has been
- [ ] will be
::: solucion Explicación
***as if*** + **pasado** (*were*) cuando lo que sigue **no es real**: no es un experto (*he has never trained a model*). *is* diría que podría serlo de verdad.
:::
:::

::: pregunta Choose the correct option: "___ all the tests, the developer merged the branch into main."
- [ ] Finished
- [ ] Having been finished
- [x] Having finished
- [ ] To finish
::: solucion Explicación
***Having*** + **participio** expresa algo **anterior** y **activo**: el desarrollador primero terminó los tests y después hizo el merge. *Finished* solo sería pasivo (los tests no "terminan al desarrollador"), y *Having been finished* también es pasivo.
:::
:::

::: pregunta Choose the correct option: "___ on billions of web pages, large language models can generate surprisingly fluent text."
- [ ] Training
- [x] Trained
- [ ] Having trained
- [ ] To train
::: solucion Explicación
Los modelos **son entrenados** (no entrenan a nadie): sentido **pasivo** → **participio** solo, ***Trained***. *Training* y *Having trained* serían activos: los modelos estarían entrenando algo.
:::
:::

::: pregunta Which sentence is NOT correct?
- [ ] Having read the documentation, I understood the problem.
- [x] Having read the documentation, the problem became clear.
- [ ] After reading the documentation, I understood the problem.
- [ ] Once I had read the documentation, the problem became clear.
::: solucion Explicación
Es un ***dangling participle***: el sujeto implícito de *Having read* tiene que ser el de la oración principal, y acá es *the problem*, como si el problema hubiera leído la documentación. En la última no pasa, porque *Once I had read* tiene su propio sujeto.
:::
:::

::: pregunta Choose the correct option: "I really enjoyed the AI workshop. — So ___ I."
- [ ] was
- [x] did
- [ ] do
- [ ] have
::: solucion Explicación
"Yo también" repite **el auxiliar** de la oración original. *enjoyed* está en *past simple* sin auxiliar visible, así que va ***did***: *So did I*.
:::
:::

::: pregunta Choose the correct option: "I can't open the shared folder. — ___ can I. Maybe the permissions changed."
- [ ] So
- [ ] Either
- [x] Neither
- [ ] Too
::: solucion Explicación
"Yo tampoco" con una oración negativa: ***Neither*** (o *Nor*) + auxiliar + sujeto. *So* es para afirmativas, y *either* va al final (*I can't either*).
:::
:::

::: pregunta Choose the correct option: "Will the client approve the budget? — I hope ___."
- [ ] it
- [ ] yes
- [x] so
- [ ] that
::: solucion Explicación
Para no repetir toda la oración, se usa ***so***: *I hope so*, *I think so*, *I'm afraid so*. *I hope it* y *I hope yes* son traducciones literales de "espero que sí".
:::
:::

::: pregunta Choose the correct option: "Is the production server still down? — I'm afraid ___."
- [ ] no
- [x] so
- [ ] yes
- [ ] it
::: solucion Explicación
Respuesta afirmativa (sí, sigue caído) y con lamento: ***I'm afraid so***. La negativa sería *I'm afraid not*.
:::
:::

::: pregunta Choose the correct option, in a formal email: "We would be grateful if you could ___ the attached documents."
- [ ] check out
- [ ] have a look at
- [x] review
- [ ] go over
::: solucion Explicación
En registro **formal** se prefieren verbos de una palabra de origen latino a los *phrasal verbs* y las expresiones coloquiales: ***review***. Las otras tres significan algo parecido, pero son informales.
:::
:::

::: pregunta Choose the option that expresses the idea most cautiously (hedging): "The new model ___ better on short texts."
- [ ] performs definitely
- [ ] clearly performs
- [x] appears to perform
- [ ] always performs
::: solucion Explicación
***appears to*** + base es un recurso de ***hedging***: afirma con prudencia ("parece rendir mejor"). *clearly*, *definitely* y *always* hacen lo contrario: refuerzan la afirmación.
:::
:::

::: pregunta Choose the correct option: "After the client changed all the requirements, we had to start again ___."
- [x] from scratch
- [ ] from the scratch
- [ ] on the scratch
- [ ] by scratch
::: solucion Explicación
***from scratch*** = **desde cero**. Es un *idiom* fijo: no lleva artículo ni cambia de preposición.
:::
:::

::: pregunta Choose the correct option: "We should take some time to do it properly. If we ___ now, we'll pay for it later."
- [ ] cut edges
- [x] cut corners
- [ ] cut costs
- [ ] break corners
::: solucion Explicación
***cut corners*** = hacer algo a medias o mal para ahorrar tiempo. *cut costs* (reducir costos) existe, pero no encaja con "hacerlo bien" ni con "lo vamos a pagar después".
:::
:::

::: pregunta Choose the correct option: "___ hard we try, the legacy code keeps breaking."
- [ ] Whatever
- [ ] No matter
- [x] However
- [ ] Although
::: solucion Explicación
***However*** + adjetivo o adverbio = "por más que", "no importa cuán": *However hard we try*. *No matter* necesitaría *how* (*No matter how hard*). *Whatever* va con sustantivos, y *Although hard we try* no es gramatical.
:::
:::
