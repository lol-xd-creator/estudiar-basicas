# 13 · Vocabulario: phrasal verbs, collocations, preposiciones y falsos amigos

En el examen, la parte de vocabulario no pregunta palabras raras: pregunta **qué palabras van juntas**. Por ejemplo, *make* o *do a decision*, *depend on* u *of*, qué significa *carry out*, si va *reliable* o *reliability*. Como leés bastante, mucho de esto lo vas a reconocer; la unidad lo ordena en seis bloques:

- *phrasal verbs*;
- *collocations*;
- preposiciones que van pegadas a una palabra;
- falsos amigos;
- formación de palabras;
- palabras que se confunden.

::: claves
- ***Phrasal verbs:*** verbo + partícula con significado propio (*carry out* = llevar a cabo). Si son separables, el **pronombre va en el medio**: *set **it** up*, nunca *set up it*.
- ***make* contra *do*:** *make* = crear, producir (*make a decision, a mistake, progress*); *do* = realizar una tarea (*do research, a task, business*).
- **Preposiciones fijas:** *depend **on***, *consist **of***, *responsible **for***, *good **at***, *interested **in***, *aware **of***.
- **Tiempo:** ***in*** (meses, años), ***on*** (días, fechas), ***at*** (horas).
- **Falsos amigos:** *actually, eventually, assist, realize, library, sensible, carpet, exit, career, introduce, pretend, support*.
- **Formación de palabras:** el hueco pide una **clase** de palabra (sustantivo, adjetivo, adverbio) y a veces un **prefijo negativo** (*un-, in-, im-, ir-, dis-*).
:::

## *Phrasal verbs*

Un ***phrasal verb*** es un verbo + una partícula (*up, out, off, on, in, down, over...*) que juntos significan algo distinto: *run* = correr, ***run out of*** = quedarse sin. Son muy comunes en el inglés técnico y de oficina.

### Los más usados en tecnología y trabajo

| *Phrasal verb* | Significado | Ejemplo |
|---|---|---|
| ***set up*** | configurar, armar | *We **set up** a new CI pipeline.* |
| ***carry out*** | llevar a cabo, realizar | *The team **carried out** a security audit.* |
| ***roll out*** | lanzar gradualmente | *The feature will be **rolled out** to all users next month.* |
| ***figure out*** | descubrir, entender (pensando) | *I can't **figure out** why the test fails.* |
| ***find out*** | averiguar, enterarse | *We **found out** that the API had changed.* |
| ***run out of*** | quedarse sin | *The server **ran out of** memory.* |
| ***look into*** | investigar | *I'll **look into** the issue tomorrow.* |
| ***come up with*** | idear, proponer | *She **came up with** a better solution.* |
| ***break down*** | romperse, dejar de funcionar / desglosar | *The old server **broke down**.* / *Let's **break down** the task.* |
| ***turn out*** | resultar | *The bug **turned out** to be a typo.* |
| ***phase out*** | eliminar gradualmente | *We're **phasing out** the legacy system.* |
| ***back up*** | hacer copia de seguridad / respaldar | ***Back up** your files before updating.* |
| ***shut down*** | apagar, cerrar | *They **shut down** the service at midnight.* |
| ***log in / log out*** | iniciar / cerrar sesión | *You need to **log in** with your company account.* |
| ***sign up (for)*** | registrarse, inscribirse | *I **signed up for** the EPAM program.* |
| ***fill in / fill out*** | completar (un formulario) | *Please **fill in** the application form.* |
| ***point out*** | señalar, hacer notar | *The reviewer **pointed out** a security issue.* |
| ***take over*** | hacerse cargo, tomar el control | *She **took over** the project when he left.* |
| ***take on*** | asumir (trabajo), contratar | *We can't **take on** more clients right now.* |
| ***bring up*** | mencionar un tema | *He **brought up** the budget in the meeting.* |
| ***go through*** | revisar a fondo / atravesar | *Let's **go through** the code together.* |
| ***sort out / work out*** | resolver, solucionar | *We **sorted out** the access problem.* |
| ***keep up with*** | mantenerse al día | *It's hard to **keep up with** new AI tools.* |
| ***fall behind*** | atrasarse | *We **fell behind** schedule.* |
| ***put off*** | posponer | *They **put off** the release until Monday.* |
| ***call off*** | cancelar | *The meeting was **called off**.* |
| ***turn down*** | rechazar | *She **turned down** the job offer.* |
| ***end up*** | terminar (haciendo algo) | *We **ended up** rewriting the whole module.* |
| ***run into*** | toparse con (un problema) | *We **ran into** some compatibility issues.* |
| ***give up*** | rendirse, dejar | *Don't **give up**: debugging takes time.* |
| ***scale up / scale down*** | aumentar / reducir la capacidad | *We **scaled up** the cluster for Black Friday.* |
| ***get along with*** | llevarse bien con | *I **get along** well **with** my team.* |
| ***put up with*** | tolerar, aguantar | *I can't **put up with** this slow laptop anymore.* |

### Separables e inseparables

- **Separables:** el objeto puede ir en el medio o al final: *set up **the server*** / *set **the server** up*. Pero si el objeto es un **pronombre**, va **siempre en el medio**: *set **it** up* ✓, *set up it* ✗.
- **Inseparables:** el objeto va siempre después: *look into **it***, *deal with **it***, *go through **it***.
- **De tres palabras:** siempre juntos: *run out of **it***, *come up with **it***, *keep up with **them***.

## *Collocations*

Una ***collocation*** es una combinación de palabras que "va junta" por costumbre, no por una regla. Un nativo dice *make a mistake*, no *do a mistake*, y no hay una lógica para deducirlo.

### *make* contra *do*

| ***make*** (crear, producir, provocar) | ***do*** (realizar una tarea o actividad) |
|---|---|
| *make a decision* | *do research* |
| *make a mistake* | *do a task / a job* |
| *make progress* | *do business* |
| *make a change* | *do your best* |
| *make an effort* | *do homework / exercises* |
| *make a plan* | *do a favour* |
| *make money* | *do damage* |
| *make a call* | *do the dishes* |
| *make a suggestion* | *do a course* |
| *make sure* | *do something / nothing / anything* |

### Otros verbos frecuentes

| Verbo | *Collocations* |
|---|---|
| ***take*** | *take a break, take a risk, take notes, take part (in), take place, take into account, take advantage of, take responsibility for, take a test* |
| ***have*** | *have a meeting, have a look, have an idea, have a problem, have a chat* |
| ***pay*** | *pay attention (to), pay a visit, pay a compliment* |
| ***give*** | *give feedback, give a presentation, give advice, give permission* |
| ***keep*** | *keep track of, keep in touch, keep a record, keep in mind* |

### *Collocations* del trabajo técnico

| Verbo + sustantivo | Significado |
|---|---|
| ***meet** a deadline* | cumplir un plazo (no *achieve a deadline*) |
| ***raise** a concern / an issue / a question* | plantear una duda o un problema |
| ***pose** a risk / a threat / a challenge* | representar un riesgo |
| ***address** an issue / a problem* | ocuparse de un problema |
| ***draw** a conclusion* | sacar una conclusión |
| ***reach** an agreement / a decision* | llegar a un acuerdo |
| ***run** a test / a script / a query* | ejecutar |
| ***fix** a bug* / ***file** a bug report* | arreglar un bug / reportarlo |
| ***gain** experience* | adquirir experiencia |
| ***conduct** research / a survey* | realizar una investigación (formal) |
| ***set** a goal / a deadline* | fijar un objetivo / un plazo |

| Adjetivo + sustantivo | Significado |
|---|---|
| ***tight** deadline* | plazo ajustado |
| ***steep** learning curve* | curva de aprendizaje empinada (cuesta aprender) |
| ***major** issue / **minor** bug* | problema grave / bug menor |
| ***high / low** quality, **high** demand* | alta / baja calidad, alta demanda |
| ***cutting-edge / state-of-the-art** technology* | tecnología de punta |
| ***user-friendly** interface* | interfaz fácil de usar |
| ***heavy** traffic / **heavy** workload* | tráfico intenso / mucha carga de trabajo |

## Preposiciones que van pegadas a una palabra

**Verbo + preposición:**

| Preposición | Verbos |
|---|---|
| ***on*** | *depend on, rely on, focus on, insist on, comment on, concentrate on* |
| ***of*** | *consist of, approve of, think of, take care of* |
| ***for*** | *apply for* (un puesto), *pay for, wait for, search for, look for, account for* |
| ***to*** | *belong to, refer to, listen to, apply to* (una empresa), *object to, respond to* |
| ***in*** | *succeed in, invest in, specialise in, participate in, result in, believe in* |
| ***with*** | *deal with, comply with, agree with* (alguien), *cope with, collaborate with* |
| ***from*** | *result from, benefit from, suffer from, differ from, protect from* |
| ***about*** | *complain about, worry about, talk about, think about* |

**Adjetivo + preposición:**

| Preposición | Adjetivos |
|---|---|
| ***of*** | *aware of, capable of, proud of, afraid of, full of, typical of, in charge of* |
| ***in*** | *interested in, involved in, experienced in* |
| ***at*** | *good at, bad at, skilled at* |
| ***with*** | *familiar with, satisfied with, compatible with, busy with, happy with* |
| ***for*** | *responsible for, suitable for, famous for, ready for* |
| ***to*** | *similar to, related to, equivalent to, committed to, open to* |
| ***on*** | *keen on, based on, dependent on* |
| ***from*** | *different from, free from* |

**Sustantivo + preposición:** *access **to**, solution **to**, key **to**, reason **for**, demand **for**, need **for**, increase / decrease **in**, impact / effect **on**, advantage **of**, knowledge **of**, experience **in / with**, cause **of**.*

### *in*, *on*, *at*

| | Tiempo | Lugar |
|---|---|---|
| ***in*** | meses, años, estaciones, partes del día: *in October, in 2026, in the morning, in two weeks* | espacios cerrados o áreas: *in the office, in Córdoba, in the document, in the email* |
| ***on*** | días y fechas: *on Monday, on 23 October, on my birthday, on the weekend* (EE. UU.) | superficies y medios: *on the screen, on the website, on the internet, on page 5* |
| ***at*** | horas y momentos puntuales: *at 9 a.m., at night, at the weekend* (Reino Unido), *at the end* | puntos: *at work, at home, at the desk, at the conference* |

## Formación de palabras

En muchas preguntas, la palabra base está dada y hay que elegir la **forma** que corresponde al hueco. Primero mirá **qué clase de palabra** pide el hueco:

- después de un artículo o de un adjetivo → **sustantivo**: *the **reliability** of the system*;
- antes de un sustantivo o después de *be* → **adjetivo**: *a **reliable** system*;
- modificando a un verbo → **adverbio**: *it works **reliably***.

| Clase | Sufijos típicos | Ejemplos |
|---|---|---|
| Sustantivo | *-tion, -sion, -ment, -ness, -ity, -ance, -ence, -er/-or, -ist, -ship* | *decision, development, awareness, security, performance, dependence, developer, analyst* |
| Adjetivo | *-able/-ible, -ful, -less, -ive, -al, -ous, -ic* | *reliable, useful, useless, effective, digital, dangerous, automatic* |
| Verbo | *-ize/-ise, -ify, -en* | *optimize, simplify, strengthen* |
| Adverbio | *-ly* | *efficiently, securely* |

**Prefijos negativos:**

| Prefijo | Cuándo | Ejemplos |
|---|---|---|
| ***un-*** | el más común | *unreliable, unavailable, unsuccessful, unnecessary* |
| ***in-*** | palabras latinas | *inefficient, inaccurate, incorrect, incompatible* |
| ***im-*** | antes de *p* y *m* | *impossible, improper, immature* |
| ***il-*** | antes de *l* | *illegal, illogical* |
| ***ir-*** | antes de *r* | *irrelevant, irresponsible, irregular* |
| ***dis-*** | verbos y adjetivos | *disagree, disconnect, dishonest* |
| ***mis-*** | "mal", equivocado | *misunderstand, misconfigure, misuse* |

**Otros prefijos:** *re-* (de nuevo: *reboot*), *over-* (de más: *overload*), *under-* (de menos: *underestimate*), *pre-* (antes: *preinstalled*), *co-* (juntos: *co-founder*), *non-* (no: *non-profit*).

**Familias de palabras útiles:**

| Verbo | Sustantivo | Adjetivo | Negativo |
|---|---|---|---|
| *rely* | *reliability* | *reliable* | *unreliable* |
| *secure* | *security* | *secure* | *insecure* |
| *succeed* | *success* | *successful* | *unsuccessful* |
| *decide* | *decision* | *decisive* | *indecisive* |
| *analyse* | *analysis*, *analyst* | *analytical* | |
| *depend* | *dependency*, *dependence* | *dependent* | *independent* |
| *perform* | *performance* | *high-performing* | |
| *maintain* | *maintenance* | *maintainable* | *unmaintainable* |
| *avail* | *availability* | *available* | *unavailable* |
| *respond* | *response*, *responsibility* | *responsive*, *responsible* | *irresponsible* |

## Palabras que se confunden

| Par | Diferencia | Ejemplo |
|---|---|---|
| ***affect / effect*** | *affect* = verbo (afectar); *effect* = sustantivo (efecto) | *The bug **affected** 200 users. The **effect** was serious.* |
| ***lose / loose*** | *lose* = perder; *loose* = flojo, suelto | *Don't **lose** your data.* / *a **loose** cable* |
| ***rise / raise*** | *rise* sin objeto; *raise* con objeto (unidad 2) | *Costs **rose**.* / *They **raised** prices.* |
| ***lie / lay*** | *lie* (yacer, estar acostado) sin objeto; *lay* (poner) con objeto | ***Lie** down.* / ***Lay** the laptop on the desk.* |
| ***borrow / lend*** | *borrow* = pedir prestado; *lend* = prestar | *Can I **borrow** your charger? / Can you **lend** me your charger?* |
| ***job / work*** | *job* = puesto (contable); *work* = trabajo, actividad (incontable) | *I got a new **job**.* / *I have a lot of **work**.* |
| ***economic / economical*** | *economic* = de la economía; *economical* = que ahorra | ***economic** crisis* / *an **economical** solution* |
| ***principle / principal*** | *principle* = principio; *principal* = principal | *SOLID **principles*** / *the **principal** reason* |
| ***advice / advise*** | sustantivo / verbo | *Thanks for the **advice**. I **advise** you to...* |
| ***accept / except*** | aceptar / excepto | *All tests passed **except** one.* |
| ***then / than*** | entonces / que (comparación) | *faster **than** before* |
| ***quite / quiet*** | bastante / silencioso | *It's **quite** fast. The office is **quiet**.* |

## Ejemplos en inglés técnico

- *We need to **figure out** why the service keeps **running out of** memory.*
- *The security team **carried out** an audit and **pointed out** several vulnerabilities.*
- *Our success **depends on** how quickly we can **adapt to** new technologies.*
- *AI-generated code can **pose a risk** if nobody reviews it carefully.*
- *We **made a decision** to **phase out** the old API by the end of the year.*
- *The **reliability** of the system improved after we **set up** automatic backups.*
- *I'll **attend** the conference **on** 15 November, and I'll **give a presentation** about LLMs.*

## Preguntas tipo examen

::: pregunta Choose the correct option: "We need to ___ a decision about the new architecture by Friday."
- [ ] do
- [x] make
- [ ] get
- [ ] put
::: solucion Explicación
***make a decision*** es una *collocation*: con *make* van las cosas que se crean o producen (*a decision, a mistake, a plan, progress*). Con *do* van las tareas (*do research, do a task*).
:::
:::

::: pregunta Choose the correct option: "The security team ___ a full audit of the system last month."
- [x] carried out
- [ ] carried on
- [ ] took off
- [ ] ran into
::: solucion Explicación
***carry out*** = **llevar a cabo**, realizar (*carry out an audit, a test, research*). *carry on* = continuar; *take off* = despegar o sacarse ropa; *run into* = toparse con.
:::
:::

::: pregunta Choose the correct option: "The application crashed because the server ran ___ memory."
- [ ] out
- [ ] off
- [x] out of
- [ ] away from
::: solucion Explicación
***run out of*** + sustantivo = **quedarse sin**. Es un *phrasal verb* de tres palabras: no se puede omitir el *of* cuando sigue lo que se acabó.
:::
:::

::: pregunta Which sentence is correct?
- [ ] I'll set up it tomorrow.
- [x] I'll set it up tomorrow.
- [ ] I'll set it tomorrow up.
- [ ] I'll up set it tomorrow.
::: solucion Explicación
***set up*** es separable. Si el objeto es un **pronombre** (*it*), va **siempre en el medio**: *set **it** up*. Con un sustantivo valen las dos: *set up the server* / *set the server up*.
:::
:::

::: pregunta Choose the correct option: "The quality of the model's answers depends ___ the quality of the training data."
- [ ] of
- [ ] from
- [x] on
- [ ] in
::: solucion Explicación
***depend on***, siempre. *depend of* es el error típico del hispanohablante, que traduce "depender **de**". Lo mismo con *rely on*.
:::
:::

::: pregunta Choose the correct option: "Our team is responsible ___ maintaining the payment service."
- [ ] of
- [x] for
- [ ] to
- [ ] with
::: solucion Explicación
***responsible for*** (+ sustantivo o *-ing*). En castellano es "responsable **de**", por eso la trampa es *of*. Comparalo con *in charge **of***, que sí lleva *of*.
:::
:::

::: pregunta Choose the correct option: "I couldn't ___ the meeting because I was sick."
- [ ] assist
- [x] attend
- [ ] assist to
- [ ] attend to
::: solucion Explicación
"Asistir" (ir) a una reunión o una clase es ***attend*** (sin preposición). ***assist*** es un falso amigo: significa **ayudar**. *attend to* significa ocuparse de algo.
:::
:::

::: pregunta Choose the correct option: "We discovered the bug in March and, after three months of work, we ___ released a fix in June."
- [ ] actually
- [ ] currently
- [x] eventually
- [ ] actual
::: solucion Explicación
***eventually*** = **finalmente**, después de mucho tiempo o esfuerzo (*after three months of work*). Es un falso amigo: no significa "eventualmente". *actually* = en realidad; *currently* = actualmente (no va con un pasado); *actual* es un adjetivo (real).
:::
:::

::: pregunta Choose the correct option: "The ___ of the system has improved since we added automatic failover."
- [ ] reliable
- [ ] reliably
- [x] reliability
- [ ] unreliable
::: solucion Explicación
Después de ***The*** y antes de ***of*** va un **sustantivo**: ***reliability***. *reliable* y *unreliable* son adjetivos, y *reliably* es adverbio.
:::
:::

::: pregunta Choose the correct option: "That information is completely ___ to our discussion, so let's move on."
- [ ] unrelevant
- [ ] inrelevant
- [x] irrelevant
- [ ] disrelevant
::: solucion Explicación
Antes de una palabra que empieza con ***r***, el prefijo negativo es ***ir-***: *irrelevant, irresponsible, irregular*. Antes de *l* es *il-* (*illegal*) y antes de *p* o *m*, *im-* (*impossible*).
:::
:::

::: pregunta Choose the correct option: "The outage seriously ___ our customers' trust."
- [ ] effected
- [x] affected
- [ ] effect
- [ ] affection
::: solucion Explicación
***affect*** es el **verbo** (afectar) y ***effect***, el **sustantivo** (efecto). Acá el hueco es un verbo en pasado: ***affected***.
:::
:::

::: pregunta Choose the correct option: "The technical interview will take place ___ 28 October ___ 10 a.m."
- [ ] in / at
- [x] on / at
- [ ] at / on
- [ ] on / in
::: solucion Explicación
***on*** + fecha o día (*on 28 October, on Monday*) y ***at*** + hora (*at 10 a.m.*). ***in*** va con meses y años (*in October, in 2026*).
:::
:::

::: pregunta Choose the correct option: "If we don't hire more people, we won't be able to ___ the deadline."
- [ ] reach
- [ ] achieve
- [x] meet
- [ ] arrive
::: solucion Explicación
"Cumplir un plazo" es ***meet a deadline***, una *collocation* fija. También se dice *miss a deadline* (no cumplirlo).
:::
:::

::: pregunta Choose the correct option: "Using passwords like '123456' ___ a serious security risk."
- [ ] makes
- [ ] does
- [x] poses
- [ ] puts
::: solucion Explicación
***pose a risk / a threat / a challenge*** = representar un riesgo. Es una *collocation* típica de textos técnicos y formales.
:::
:::

::: pregunta Choose the correct option: "Can I ___ your charger? I left mine at home."
- [ ] lend
- [x] borrow
- [ ] rent
- [ ] give
::: solucion Explicación
***borrow*** = **pedir** prestado (yo recibo). ***lend*** = **prestar** (yo doy): *Can you **lend** me your charger?*
:::
