# 11.1 · Relativos, artículos, cuantificadores y comparativos

Cuatro temas cortos que aparecen en cualquier examen B2. Son las piezas que arman los **sustantivos**: cómo se describen (*the tool **that we use***), cómo se presentan (*a*, *the* o nada), cuántos hay (*few*, *a few*, *much*, *many*) y cómo se comparan (*faster*, *the most efficient*).

::: claves
- **Relativos:** *who* (personas), *which* (cosas), *that* (las dos, solo sin comas), *whose* (de quien), *where*, *when*.
- **Con comas** (información extra) **nunca va *that***, y el relativo no se puede omitir.
- ***a/an*** según el **sonido**: *an hour*, *a user*, *an API*.
- **En general, sin artículo:** *AI is changing the world* (no *The AI*). Las profesiones llevan *a*: *I'm **a** developer*.
- ***few*** (pocos, casi nada) ≠ ***a few*** (algunos). Lo mismo con *little* / *a little*.
- ***fewer*** + contables, ***less*** + incontables.
- **Comparativos:** *faster than*, *more efficient than*; *much/far better* (nunca *very better*).
- ***so*** + adjetivo, ***such*** + (*a*) + adjetivo + sustantivo.
:::

## Pronombres relativos

Un **relativo** une dos oraciones y describe a un sustantivo: *The developer **who** wrote this code is on holiday.*

| Relativo | Para | Ejemplo |
|---|---|---|
| ***who*** | personas | *The engineer **who** fixed the bug got a bonus.* |
| ***which*** | cosas, animales | *The library **which** we use is deprecated.* |
| ***that*** | personas o cosas (solo sin comas) | *The tool **that** generates the reports is slow.* |
| ***whose*** | posesión (de quien, cuyo) | *The client **whose** data was leaked is suing us.* / *A model **whose** weights are public.* |
| ***where*** | lugares | *The office **where** I work is in Córdoba.* |
| ***when*** | momentos | *I remember the day **when** we launched the app.* |
| ***whom*** | personas como objeto (formal), después de preposición | *The person **to whom** I spoke was very helpful.* |
| ***why*** | razones (*the reason why*) | *That's the reason **why** the build failed.* |

### Especificativas contra explicativas

| | **Especificativa** (*defining*) | **Explicativa** (*non-defining*) |
|---|---|---|
| ¿Qué hace? | **Identifica** de cuál se habla. Sin ella, no se sabe cuál. | Agrega **información extra**. Se puede sacar. |
| Comas | **No** | **Sí** |
| *that* | Sí | **Nunca** |
| ¿Se puede omitir el relativo? | Sí, si es objeto | **Nunca** |
| Ejemplo | *The servers **that** run the AI models are in Frankfurt.* (solo esos) | *Our main server, **which** runs Linux, is in Frankfurt.* (hay uno) |

::: ojo
**Cambia el significado:**

- *The developers **who** knew Python got the job.* — solo los que sabían Python.
- *The developers, **who** knew Python, got the job.* — todos, y además sabían Python.

**Con comas, *that* está prohibido:** *Python, **that** is easy to learn, ...* ✗ → *Python, **which** is easy to learn, ...* ✓
:::

### Cuándo se puede omitir el relativo

En una especificativa, si el relativo es el **objeto** (después viene otro sujeto), se puede sacar:

- *The tool **(that)** **we** use is free.* — *we* es el sujeto de *use*: se puede omitir.
- *The tool **that** **generates** reports is free.* — *that* es el sujeto de *generates*: **no** se puede omitir.

### Otros detalles

- ***which*** puede referirse a **toda la oración anterior** (siempre con coma): *The server crashed, **which** delayed the release.*
- **Preposiciones:** en el habla van al final (*the team **I work with***); en formal, antes de *whom* o *which* (*the team **with whom** I work*). Nunca *with who* ni *with that*.
- ***what*** = "lo que", no reemplaza a *which/that* después de un sustantivo: ***What** I need is more RAM* ✓ / *The RAM **what** I need* ✗.
- **Relativas reducidas** (sin relativo ni *be*): *The people **working** on the project* (= *who are working*), *the code **written** by the intern* (= *that was written*).

## Artículos: *a/an*, *the* o nada

### *a* contra *an*

Depende del **sonido** de la palabra siguiente, no de la letra:

| *an* + sonido vocal | *a* + sonido consonante |
|---|---|
| ***an** hour* (la *h* no suena) | ***a** user* (suena "iu") |
| ***an** API* (suena "ei-pi-ai") | ***a** university* (suena "iu") |
| ***an** MVP* (suena "em") | ***a** one-time password* (suena "uan") |
| ***an** honest answer* | ***a** European company* (suena "iu") |

### Cuándo va cada uno

| Artículo | Cuándo | Ejemplo |
|---|---|---|
| ***a/an*** | Uno cualquiera, se menciona por primera vez. | *We found **a** bug.* |
| | **Profesiones** (obligatorio). | *She's **an** engineer.* (no *She's engineer*) |
| | *what a...*, *such a...*, frecuencia. | *Twice **a** week.* |
| ***the*** | Algo **específico** o ya mencionado. | *We found a bug. **The** bug was in the login.* |
| | Algo **único** o conocido por todos. | ***the** internet, **the** cloud, **the** sun* |
| | Superlativos y ordinales. | ***the** best model, **the** first version* |
| | Con *of* que especifica. | ***the** history **of** computing* |
| **nada** | Plurales e incontables en **general**. | ***AI** is changing **the** world.* / ***Developers** love **coffee**.* |
| | Idiomas, la mayoría de países y ciudades, comidas. | *She speaks **Polish**.* / *I live in **Argentina**.* |
| | Expresiones fijas. | *at work, at home, by email, by car, in 2024, on Monday* |

::: ojo
**El error del hispanohablante:** en castellano decimos "**la** inteligencia artificial está cambiando..." o "**los** programadores usan...". En inglés, cuando se habla **en general**, no va *the*:

| Mal | Bien |
|---|---|
| ***The** artificial intelligence is changing everything.* | ***Artificial intelligence** is changing everything.* |
| ***The** software is important for **the** companies.* | ***Software** is important for **companies**.* |
| *I am developer.* | *I am **a** developer.* |

**Países con *the*:** los que son plurales o uniones: ***the** United States, **the** UK, **the** Netherlands, **the** Philippines*.
:::

## Cuantificadores

| Contables (*bugs*) | Incontables (*code*) | Ambos |
|---|---|---|
| ***many*** bugs | ***much*** code | ***a lot of / lots of*** |
| ***few / a few*** bugs | ***little / a little*** code | ***some / any*** |
| ***fewer*** bugs | ***less*** code | ***no / none of / all*** |
| ***a large number of*** bugs | ***a great deal of*** code | ***plenty of*** |
| ***several*** bugs | ***an amount of*** code | ***enough*** |

- ***much*** y ***many*** se usan sobre todo en **negativas y preguntas**; en afirmativas suena más natural *a lot of*: *We don't have **much** time* / *We have **a lot of** time*.

### *few* contra *a few*

| | Significado | Tono | Ejemplo |
|---|---|---|---|
| ***few*** | pocos, **casi ninguno** | negativo | ***Few** people understand this algorithm.* (casi nadie) |
| ***a few*** | **algunos**, unos cuantos | positivo | *I have **a few** questions.* (tengo algunas) |
| ***little*** | poco, casi nada (incontable) | negativo | *There's **little** documentation.* (casi no hay) |
| ***a little*** | un poco (incontable) | positivo | *I speak **a little** Polish.* |

### Otros pares

- ***each*** (cada uno, individualmente, de 2 en adelante) contra ***every*** (todos, como grupo, de 3 en adelante). Los dos con sustantivo **singular**: *Each/Every test **passes***.
- ***both*** (los dos), ***either*** (cualquiera de los dos), ***neither*** (ninguno de los dos):
  - *Neither option **is** good.* (*neither* + singular)
  - *Neither **of** the options **is/are** good.*
- ***no*** + sustantivo / ***none*** solo o con *of*: *There are **no** errors* / ***None** of the tests failed*.
- ***any*** en negativas y preguntas (*Are there **any** questions?*), y con el sentido de "cualquiera" en afirmativas (*Choose **any** framework*).
- ***some*** en afirmativas y en ofrecimientos o pedidos (*Would you like **some** help?*).

::: ojo
- ***fewer*** + contables, ***less*** + incontables: ***fewer** bugs*, ***less** code*. (*less bugs* se oye, pero en un examen es error).
- ***a great deal of*** solo con incontables: *a great deal of **data*** ✓ / *a great deal of **errors*** ✗ → ***a large number of** errors*.
:::

## Comparativos y superlativos

| Tipo de adjetivo | Comparativo | Superlativo |
|---|---|---|
| Una sílaba: *fast* | *fast**er** (than)* | *the fast**est*** |
| Termina en *-y*: *easy* | *eas**ier*** | *the eas**iest*** |
| Dos o más sílabas: *efficient* | ***more** efficient* | *the **most** efficient* |
| Irregular: *good / bad / far* | *better / worse / further* | *the best / the worst / the furthest* |

**Estructuras que el examen pregunta:**

| Estructura | Ejemplo |
|---|---|
| ***as*** + adjetivo + ***as*** (igualdad) | *Go is **as fast as** C in some cases.* |
| ***not as / not so*** + adjetivo + ***as*** | *Python is **not as fast as** C.* |
| ***the*** + comparativo, ***the*** + comparativo | ***The more** data you have, **the better** the model.* |
| comparativo + ***and*** + comparativo (cada vez más) | *Models are getting **bigger and bigger**.* / ***more and more** powerful* |
| ***much / far / a lot / slightly / a bit*** + comparativo | *This version is **much faster**.* (nunca *very faster*) |
| ***one of the*** + superlativo + **plural** | *It's **one of the best tools** I've used.* |
| superlativo + ***in*** (lugar, grupo) / ***of*** (período, conjunto) | *the best developer **in** the team* / *the best day **of** my life* |
| ***than me*** (informal) / ***than I am*** (formal) | *She's more experienced **than I am**.* |

::: ojo
- ***very*** **no va con comparativos:** *very better* ✗ → ***much** better* ✓.
- ***than***, no *that*: *faster **than** the old one*.
- **No se duplica:** *more faster* ✗, *the most fastest* ✗.
- ***further*** = más lejos y también "adicional": ***further** information*.
:::

## *so* / *such* y *too* / *enough*

| Estructura | Ejemplo |
|---|---|
| ***so*** + adjetivo / adverbio | *The build is **so slow**.* |
| ***such*** + ***a/an*** + adjetivo + sustantivo singular | *It's **such a slow** build.* |
| ***such*** + adjetivo + plural o incontable | *They are **such good** developers.* / ***such good** advice* |
| ***so... that*** / ***such... that*** (consecuencia) | *The model was **so** big **that** it didn't fit in memory.* |
| ***too*** + adjetivo (demasiado, problema) | *This laptop is **too old to run** Docker.* |
| adjetivo + ***enough*** (suficiente) | *It isn't **fast enough**.* |
| ***enough*** + sustantivo | *We don't have **enough memory**.* |

::: ojo
***enough*** va **después** del adjetivo y **antes** del sustantivo: *fast enough* ✓ / *enough fast* ✗; *enough time* ✓.
:::

## Ejemplos en inglés técnico

- *A large language model is **a** neural network **that** has been trained on huge amounts of text.*
- *EPAM, **which** was founded in 1993, works with clients all over **the** world.*
- *The engineer **whose** code caused the outage wrote **a** detailed postmortem.*
- ***Few** companies can afford to train their own models, so most use **an** API.*
- *The new model is **much cheaper** and **slightly more accurate than** the old one.*
- ***The more** tests you write, **the fewer** bugs you'll find in production.*
- *It was **such a** complex migration **that** it took six months.*

## Preguntas tipo examen

::: pregunta Choose the correct option: "Python, ___ was created by Guido van Rossum, is one of the most popular languages."
- [ ] that
- [x] which
- [ ] who
- [ ] what
::: solucion Explicación
Va entre **comas**: es una explicativa (información extra). Con comas **nunca** va *that*. Para una cosa, ***which***. *who* es para personas y *what* no funciona como relativo después de un sustantivo.
:::
:::

::: pregunta Choose the correct option: "The developer ___ laptop was stolen had to reset all his passwords."
- [ ] who
- [ ] which
- [x] whose
- [ ] who's
::: solucion Explicación
Posesión (la laptop **del** desarrollador): ***whose***. *who's* es la contracción de *who is* / *who has*.
:::
:::

::: pregunta In which sentence can the relative pronoun be omitted?
- [ ] The engineer who fixed the bug is on holiday.
- [x] The framework that we chose is very popular.
- [ ] Our CTO, who joined last year, is from Poland.
- [ ] The service that sends the emails is down.
::: solucion Explicación
Se puede omitir cuando es el **objeto** en una especificativa: *The framework (that) **we** chose* (*we* es el sujeto de *chose*). En la primera y la cuarta, el relativo es el **sujeto**. En la tercera hay comas (explicativa), y ahí nunca se omite.
:::
:::

::: pregunta Choose the correct option: "We need to hire ___ experienced data engineer."
- [ ] a
- [x] an
- [ ] the
- [ ] —
::: solucion Explicación
Uno cualquiera, mencionado por primera vez: artículo indefinido. *experienced* empieza con **sonido vocal**, así que va ***an***.
:::
:::

::: pregunta Choose the correct option: "___ is transforming the way companies work."
- [ ] The artificial intelligence
- [x] Artificial intelligence
- [ ] An artificial intelligence
- [ ] The artificial intelligences
::: solucion Explicación
Se habla de la IA **en general**, como concepto: **sin artículo**. En castellano decimos "**la** inteligencia artificial", pero en inglés *the* solo va si se habla de una específica (*the AI that we built*).
:::
:::

::: pregunta Choose the correct option: "Unfortunately, ___ people attended the workshop, so it was cancelled."
- [ ] a few
- [x] few
- [ ] a little
- [ ] little
::: solucion Explicación
Se canceló porque fue **casi nadie**: ***few*** (tono negativo). *a few* = algunos (tono positivo), que no explica la cancelación. *little* y *a little* son para incontables, y *people* es contable.
:::
:::

::: pregunta Choose the correct option: "The new version has ___ bugs than the previous one."
- [ ] less
- [x] fewer
- [ ] little
- [ ] lesser
::: solucion Explicación
*bugs* es **contable**: ***fewer***. ***less*** va con incontables (*less code, less time*).
:::
:::

::: pregunta Choose the correct option: "This laptop is ___ than the one I had before."
- [ ] very faster
- [ ] more faster
- [x] much faster
- [ ] the fastest
::: solucion Explicación
Para reforzar un comparativo se usa ***much***, *far*, *a lot* o *slightly*; **nunca *very***. *more faster* duplica el comparativo.
:::
:::

::: pregunta Choose the correct option: "The more data you use for training, ___ the model usually performs."
- [ ] better
- [ ] the best
- [x] the better
- [ ] more better
::: solucion Explicación
Estructura ***the*** + comparativo, ***the*** + comparativo ("cuanto más..., mejor..."): *The more data..., **the better**...* Las dos partes llevan *the*.
:::
:::

::: pregunta Choose the correct option: "It was ___ difficult problem that nobody could solve it."
- [ ] so
- [ ] such
- [x] such a
- [ ] so a
::: solucion Explicación
Con **adjetivo + sustantivo singular** va ***such a***: *such **a** difficult problem*. ***so*** va solo con el adjetivo: *The problem was **so** difficult that...*
:::
:::

::: pregunta Choose the correct option: "The server isn't powerful ___ to run the new model."
- [ ] too
- [x] enough
- [ ] so
- [ ] such
::: solucion Explicación
***enough*** va **después** del adjetivo: *powerful **enough** to run*. *too* iría antes y con otro sentido: *too weak to run it*.
:::
:::

::: pregunta Choose the correct option: "It is one of the ___ in the company."
- [ ] best project
- [x] best projects
- [ ] better projects
- [ ] most best projects
::: solucion Explicación
***one of the*** + superlativo + sustantivo en **plural**: *one of the best **projects***. Uno entre varios, así que el sustantivo va en plural.
:::
:::

::: pregunta Choose the correct option: "We tested two frameworks, but ___ of them was fast enough."
- [ ] either
- [ ] both
- [x] neither
- [ ] none
::: solucion Explicación
**Dos** opciones y **ninguna** sirvió: ***neither*** (*of them* + verbo en singular, *was*). ***none*** se usa para tres o más. *both* iría con plural (*were*) y diría que los dos eran rápidos, lo que contradice el *but*.
:::
:::

::: pregunta Choose the correct option: "My sister works as ___ software engineer at a startup."
- [ ] —
- [ ] the
- [x] a
- [ ] an
::: solucion Explicación
Las **profesiones** llevan artículo indefinido en inglés: *works as **a** software engineer*, *She's **a** developer*. *software* empieza con sonido consonante, así que es *a*.
:::
:::

::: pregunta Choose the correct option: "The system crashed during the demo, ___ was really embarrassing."
- [ ] that
- [x] which
- [ ] what
- [ ] it
::: solucion Explicación
***which*** después de una coma puede referirse a **toda la oración anterior** (el hecho de que el sistema se cayera). *that* no va con comas, *what* no es relativo en esta posición, y *it* formaría dos oraciones unidas solo por una coma.
:::
:::
