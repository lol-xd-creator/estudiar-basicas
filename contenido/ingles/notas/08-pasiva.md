# 8 · Voz pasiva y causativa

La **voz pasiva** es la voz de la documentación técnica, los informes y las noticias: *The data **is stored** in the cloud*, *The model **was trained** on public data*. Esta unidad enseña a armarla en cualquier tiempo y cuándo usarla, más dos estructuras que el examen pregunta mucho: la pasiva impersonal (*AI **is expected to** create jobs*) y la causativa (*We **had** the code **reviewed***).

::: claves
- **Forma:** ***be*** (en el tiempo que corresponda) + **participio**. *is used, is being used, has been used, was used, will be used, must be used*.
- **Se usa** cuando importa la acción o el resultado, no quién la hace. Quién la hace va con ***by*** solo si importa.
- ***being*** (*continuous*) ≠ ***been*** (*perfect*): *is **being** reviewed* (ahora) / *has **been** reviewed* (ya está).
- **No tienen pasiva** los verbos sin objeto: *happen, occur, arrive, exist, consist*. *It was happened* ✗.
- **Con dos objetos**, el más natural es la persona: *I **was given** access*.
- **Pasiva impersonal (C1):** *It is said that...* / *AI **is said to be**...* / *The attack **is believed to have started**...*
- **Causativa:** ***have/get*** + objeto + participio = que otro lo haga por vos: *I **had** my laptop **repaired***.
:::

## Activa contra pasiva

En la **activa**, el sujeto **hace** la acción. En la **pasiva**, el sujeto la **recibe**: el objeto de la activa pasa a ser el sujeto.

| Activa | Pasiva |
|---|---|
| ***The team** deployed **the model**.* | ***The model** was deployed (by the team).* |
| ***Someone** has deleted **the file**.* | ***The file** has been deleted.* |
| ***They** will release **the update** tomorrow.* | ***The update** will be released tomorrow.* |

**Para armarla:**

1. El objeto pasa adelante como sujeto.
2. Se pone ***be*** en el **mismo tiempo** que tenía el verbo de la activa.
3. El verbo principal va en **participio**.
4. Quien hacía la acción se agrega con ***by***, o se omite.

## La pasiva en todos los tiempos

Con *test* (participio: *tested*) y el sujeto *the code*:

| Tiempo | Activa | Pasiva |
|---|---|---|
| *Present simple* | *they **test** it* | *it **is tested*** |
| *Present continuous* | *they **are testing** it* | *it **is being tested*** |
| *Present perfect* | *they **have tested** it* | *it **has been tested*** |
| *Past simple* | *they **tested** it* | *it **was tested*** |
| *Past continuous* | *they **were testing** it* | *it **was being tested*** |
| *Past perfect* | *they **had tested** it* | *it **had been tested*** |
| *Future (will)* | *they **will test** it* | *it **will be tested*** |
| *going to* | *they **are going to test** it* | *it **is going to be tested*** |
| *Future perfect* | *they **will have tested** it* | *it **will have been tested*** |
| Modal | *they **must test** it* | *it **must be tested*** |
| Modal perfecto | *they **should have tested** it* | *it **should have been tested*** |
| Infinitivo | *they want **to test** it* | *it needs **to be tested*** |
| Gerundio | *I hate them **interrupting** me* | *I hate **being interrupted*** |

::: tip
**El truco:** la última palabra siempre es el **participio** (*tested*), y la anterior es alguna forma de ***be*** (*is, are, was, been, being, be*). Si ves *be* + participio, es pasiva.
:::

**Preguntas y negaciones:** el primer auxiliar hace el trabajo, como siempre.

- ***Was** the bug **reported** by a user?*
- *The pull request **hasn't been reviewed** yet.*
- ***Who** was this function **written by**?* (la preposición queda al final)

::: ojo
- ***being*** contra ***been***:
  - *The code **is being reviewed**.* — lo están revisando **ahora** (*continuous*).
  - *The code **has been reviewed**.* — ya **fue** revisado (*perfect*).
- **El participio de los irregulares:** *was **written*** (no *was wrote*), *has been **chosen***, *was **built***.
- **Concordancia con el nuevo sujeto:** *The files **were** deleted* / *The file **was** deleted*.
:::

## Cuándo se usa la pasiva

| Cuándo | Ejemplo |
|---|---|
| No se sabe quién lo hizo | *My account **has been hacked**.* |
| Es obvio o no importa quién | *The office **is cleaned** every night.* |
| Lo importante es el resultado o el proceso | *The data **is encrypted** before it **is sent**.* |
| Textos técnicos, científicos y formales | *The results **were obtained** using a neural network.* |
| Para no culpar a nadie | *Mistakes **were made**.* |

***by*** + agente solo cuando aporta información: *Python **was created by** Guido van Rossum.*

***by*** contra ***with***: ***by*** para quien hace la acción, ***with*** para el instrumento: *The file was encrypted **by** the system **with** a 256-bit key.*

## Verbos que no tienen pasiva

Solo puede ir en pasiva un verbo que tenga **objeto** (verbo transitivo). Estos no lo tienen, así que **nunca** van en pasiva:

***happen, occur, take place, arrive, exist, die, disappear, consist of, belong to, seem, appear***

| Mal | Bien |
|---|---|
| *The error **was happened** at night.* | *The error **happened** at night.* |
| *The meeting **will be taken place** online.* | *The meeting **will take place** online.* |
| *The team **is consisted** of five people.* | *The team **consists** of five people.* |

## Verbos con dos objetos

Verbos como *give, send, show, offer, tell, teach, pay, promise* tienen dos objetos: una **cosa** y una **persona**. Cualquiera puede ser el sujeto de la pasiva, pero lo más natural es la **persona**:

- Activa: *They **gave** me access to the repository.*
- Pasiva con la persona (más común): ***I was given** access to the repository.*
- Pasiva con la cosa: ***Access was given** to me.*

Otros: *She **was offered** a job*, *We **were told** to wait*, *I **was sent** the wrong file*.

## Pasiva con *phrasal verbs* y con *make*, *see*, *let*

- **La preposición del *phrasal verb* se queda pegada al verbo:** *The meeting **was called off*** (se canceló), *The issue **is being looked into*** (se está investigando).
- ***make*** y ***see*** recuperan el ***to*** en pasiva (unidad 10):
  - Activa: *They **made** us **rewrite** the module.* → Pasiva: *We **were made to rewrite** the module.*
  - Activa: *Someone **saw** him **leave**.* → Pasiva: *He **was seen to leave**.*
- ***let*** casi no se usa en pasiva: se reemplaza por ***be allowed to***: *We **were allowed to** use AI tools.*

## Pasiva impersonal (C1)

Sirve para transmitir lo que **se dice**, **se cree** o **se espera**, sin decir quién lo dice. Es típica de noticias e informes. Funciona con *say, believe, think, expect, know, report, consider, estimate, claim*.

| Estructura | Ejemplo |
|---|---|
| ***It is*** + participio + ***that*** + oración | ***It is expected that** AI **will create** new jobs.* |
| Sujeto + ***is*** + participio + ***to*** + base (al mismo tiempo) | *AI **is expected to create** new jobs.* |
| Sujeto + ***is*** + participio + ***to be*** + *-ing* (en curso) | *The company **is said to be developing** its own model.* |
| Sujeto + ***is*** + participio + ***to have*** + participio (antes) | *The attack **is believed to have started** in March.* |
| ***There is said to be*** | ***There are thought to be** thousands of affected users.* |

::: ojo
**El infinitivo indica cuándo pasó respecto de "se dice":**

- *He **is said to work** at EPAM.* — se dice que trabaja ahí (ahora).
- *He **is said to have worked** at EPAM.* — se dice que trabajó ahí (antes).

Si *say/believe* está en pasado, se corre todo: *It **was** believed that... / The system **was** thought **to be** secure.*
:::

## La causativa: *have / get something done*

Sirve para decir que **otra persona** hace algo **por vos** (normalmente un servicio).

| Estructura | Ejemplo | Significado |
|---|---|---|
| ***have*** + objeto + participio | *We **had** the code **reviewed** by an external company.* | Lo revisó otra empresa (lo encargamos). |
| ***get*** + objeto + participio (más informal) | *I need to **get** my laptop **repaired**.* | Que me la arreglen. |
| Para algo **malo** que te pasó | *She **had** her account **hacked**.* | Le hackearon la cuenta. |
| ***have*** + persona + base | *I'll **have** the intern **check** the logs.* | Le pido al pasante que lo haga. |
| ***get*** + persona + ***to*** + base | *I **got** IT **to reset** my password.* | Convencí a IT de que lo hiciera. |

::: ojo
**El orden importa:**

- *I **had my laptop repaired**.* — alguien me la arregló (causativa).
- *I **had repaired** my laptop.* — **yo** la había arreglado (*past perfect*).
:::

***need*** + ***-ing*** también tiene sentido pasivo: *The server **needs restarting*** = *needs to be restarted*.

## Ejemplos en inglés técnico

- *Python **was first released** in 1991.*
- *All passwords **are hashed** before they **are stored** in the database.*
- *The new version **is being tested** on staging and **will be released** next week.*
- *Large language models **are trained** on huge amounts of text.*
- *This vulnerability **should have been detected** during the code review.*
- *EPAM **is known to be** one of the leading software engineering companies in the world.*
- *We **had** the application **audited** by a security firm.*

## Preguntas tipo examen

::: pregunta Choose the correct option: "The new feature ___ on staging at the moment, so please don't deploy anything."
- [ ] is tested
- [x] is being tested
- [ ] has been tested
- [ ] is testing
::: solucion Explicación
*at the moment*: la acción está **en curso**, y la función **recibe** la acción (alguien la prueba). Es pasiva en *present continuous*: ***is being*** + participio. *is testing* sería activa: la función estaría probando algo.
:::
:::

::: pregunta Choose the correct option: "The vulnerability ___ by a security researcher last month."
- [ ] discovered
- [ ] has been discovered
- [x] was discovered
- [ ] is discovered
::: solucion Explicación
*last month* = momento terminado → *past simple*. La vulnerabilidad **recibe** la acción → pasiva: ***was*** + participio. *has been discovered* no combina con *last month* (unidad 3).
:::
:::

::: pregunta Choose the correct option: "Don't worry, your pull request ___ already ___."
- [ ] is / reviewed
- [x] has / been reviewed
- [ ] has / being reviewed
- [ ] was / been reviewed
::: solucion Explicación
*already* pide *present perfect*; en pasiva: ***has been*** + participio. ***been*** es el participio de *be* (*perfect*); ***being*** es la forma *-ing* (*continuous*). *was been* no existe.
:::
:::

::: pregunta Which sentence is NOT correct?
- [ ] The error occurred during the night.
- [x] The error was occurred during the night.
- [ ] The error was detected during the night.
- [ ] The error was reported by the monitoring system.
::: solucion Explicación
***occur*** (ocurrir) no tiene objeto, así que **no tiene pasiva**: *The error **occurred***. Lo mismo pasa con *happen, take place, arrive, exist*. *detect* y *report* sí tienen objeto y sí admiten pasiva.
:::
:::

::: pregunta Choose the correct option: "After the interview, I ___ a position in the Python training program."
- [ ] offered
- [x] was offered
- [ ] was offering
- [ ] have offered
::: solucion Explicación
A mí me ofrecieron el puesto: yo **recibo** la acción. Con verbos de dos objetos (*offer someone something*), la pasiva más natural tiene a la **persona** como sujeto: ***I was offered** a position*. *I offered* significaría que yo lo ofrecí.
:::
:::

::: pregunta Choose the correct option: "All user data must ___ before it is sent to the server."
- [ ] encrypt
- [ ] be encrypting
- [x] be encrypted
- [ ] been encrypted
::: solucion Explicación
Pasiva con modal: ***must be*** + participio. Después de un modal va la **base** (*be*), no *been*. *be encrypting* sería activa en *continuous*.
:::
:::

::: pregunta Choose the correct option: "Artificial intelligence ___ to transform the healthcare industry in the next decade."
- [ ] expects
- [x] is expected
- [ ] is expecting
- [ ] has expected
::: solucion Explicación
**Pasiva impersonal**: sujeto + ***is expected to*** + base = "se espera que la IA transforme...". *AI expects* diría que la IA misma espera algo.
:::
:::

::: pregunta Choose the correct option: "The hackers are believed ___ the system several weeks before the attack was discovered."
- [ ] to access
- [ ] to be accessing
- [x] to have accessed
- [ ] having accessed
::: solucion Explicación
El acceso pasó **antes** del momento en que "se cree": ***to have*** + participio. *to access* indicaría que pasa al mismo tiempo que la creencia (ahora). Es la estructura impersonal de C1 más preguntada.
:::
:::

::: pregunta Choose the correct option: "My laptop stopped working, so I ___ at the service center."
- [ ] repaired it
- [ ] had repaired it
- [x] had it repaired
- [ ] have it repairing
::: solucion Explicación
**Causativa**: ***have*** + objeto + **participio** = otro lo hizo por mí: *I **had it repaired***. *had repaired it* es *past perfect* y diría que lo arreglé yo mismo.
:::
:::

::: pregunta Choose the correct option: "We were made ___ the entire report because of a few formatting errors."
- [ ] rewrite
- [x] to rewrite
- [ ] rewriting
- [ ] rewritten
::: solucion Explicación
En activa, ***make*** va con infinitivo **sin** *to* (*They made us rewrite*), pero en **pasiva recupera el *to***: *We were made **to rewrite***. Es una trampa típica.
:::
:::

::: pregunta Choose the correct option: "The project was cancelled. Who ___ by?"
- [x] was it cancelled
- [ ] did it cancel
- [ ] was it cancelling
- [ ] did it cancelled
::: solucion Explicación
Pregunta en pasiva: el auxiliar *was* pasa adelante y el participio queda: ***Who was it cancelled by?*** La preposición *by* va al final. *did it cancel* sería activa: el proyecto habría cancelado algo.
:::
:::

::: pregunta Choose the correct option: "It ___ that the company will open a new office in Córdoba next year."
- [ ] says
- [x] is said
- [ ] is saying
- [ ] has said
::: solucion Explicación
**Pasiva impersonal**: ***It is said that*** + oración = "se dice que...". *It says* se usa para lo que dice un texto o un cartel (*The email says that...*), no para un rumor sin fuente.
:::
:::

::: pregunta Choose the correct option: "The configuration file ___ when the server crashed, so some settings were lost."
- [ ] was updating
- [x] was being updated
- [ ] had updated
- [ ] updated
::: solucion Explicación
Una acción **en curso** en el pasado (lo estaban actualizando) interrumpida por otra: *past continuous*. Como el archivo **recibe** la acción, va en pasiva: ***was being*** + participio. *was updating* diría que el archivo actualizaba algo.
:::
:::

::: pregunta Choose the correct option: "The training session will ___ online because of the weather."
- [ ] be taken place
- [x] take place
- [ ] be took place
- [ ] taken place
::: solucion Explicación
***take place*** (tener lugar) no tiene objeto, así que no admite pasiva: *will **take place***. *be taken place* es un error frecuente porque "se realizará" suena pasivo en castellano.
:::
:::
