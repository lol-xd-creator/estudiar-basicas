# 10 · Gerundio contra infinitivo

Cuando un verbo va seguido de otro, el segundo puede ir en ***-ing*** (*enjoy **coding***), con ***to*** (*decide **to code***) o sin nada (*make someone **code***). No hay una lógica que lo explique todo: depende del **primer** verbo, y hay que aprender las listas. Es de los temas con más preguntas en B2, porque las cuatro opciones "suenan" parecidas.

::: claves
- **Después de una preposición, siempre *-ing*:** *interested **in learning***, *good **at debugging***, *before **leaving***.
- ***to*** **a veces es preposición:** *look forward to **hearing***, *be used to **working***, *object to **paying***.
- **Verbos + *-ing*:** *enjoy, avoid, finish, consider, mind, suggest, keep, risk, deny, admit, miss, imagine, involve, postpone*.
- **Verbos + *to*:** *want, decide, plan, manage, fail, refuse, afford, tend, agree, hope, expect, offer, promise, seem*.
- **Sin *to*:** después de modales, ***make*** y ***let*** (*it made me **rewrite** it*), *had better, would rather*.
- **Cambian de significado:** *stop, remember, forget, try, regret, go on, mean*.
- **Para qué** (finalidad): ***to*** + base, nunca *for* + base: *I'm studying **to pass** the test*.
:::

## El *-ing* como sustantivo

El ***-ing*** convierte un verbo en un sustantivo: "el hecho de hacer algo". En castellano usamos el infinitivo ("**testear** es importante"); en inglés, el gerundio.

| Dónde | Ejemplo | Castellano |
|---|---|---|
| Como **sujeto** | ***Testing** is important.* | **Testear** es importante. |
| Después de una **preposición** | *She's good **at explaining** complex topics.* | Es buena **para explicar**... |
| Después de ciertos **verbos** | *I enjoy **solving** problems.* | Disfruto **resolver**... |

::: ojo
**Después de una preposición, siempre *-ing***, aunque en castellano vaya infinitivo:

| Castellano | Mal | Bien |
|---|---|---|
| Antes **de irte**, apagá la PC. | *Before **to leave**...* / *Before **leave**...* | *Before **leaving**, ...* |
| Gracias **por ayudarme**. | *Thanks for **help** me.* | *Thanks for **helping** me.* |
| En vez **de usar** Java... | *Instead of **use** Java...* | *Instead of **using** Java...* |
| Estoy interesado **en aprender**... | *interested in **to learn*** | *interested in **learning*** |
| Lo resolvimos **automatizando** el proceso. | *by **automate*** | *by **automating*** |
:::

## Verbos seguidos de *-ing*

| Verbo | Ejemplo |
|---|---|
| ***enjoy*** | *I **enjoy working** with data.* |
| ***avoid*** | *Try to **avoid using** global variables.* |
| ***finish*** | *Have you **finished writing** the tests?* |
| ***consider*** | *We're **considering moving** to the cloud.* |
| ***mind*** (molestar) | *Would you **mind sharing** your screen?* |
| ***suggest / recommend*** | *She **suggested adding** more logs.* |
| ***keep*** (seguir, repetir) | *The app **keeps crashing**.* |
| ***risk*** | *We can't **risk losing** the data.* |
| ***deny / admit*** | *He **admitted making** a mistake.* |
| ***miss*** (extrañar, perderse) | *I **miss working** in an office.* |
| ***imagine*** | *Can you **imagine coding** without the internet?* |
| ***involve*** (implicar) | *The job **involves travelling**.* |
| ***postpone / put off / delay*** | *They **postponed launching** the product.* |
| ***practise*** | *You should **practise speaking** English.* |
| ***can't help*** (no poder evitar) | *I **can't help thinking** it's a bad idea.* |
| ***can't stand*** (no soportar) | *I **can't stand waiting** for slow builds.* |
| ***feel like*** (tener ganas) | *I don't **feel like going** out tonight.* |

**Expresiones con *-ing*:** *it's worth **reading***, *there's no point (in) **waiting***, *it's no use **trying***, *have difficulty / trouble **understanding***, *spend time **debugging***, *be busy **preparing***.

## *to* como preposición: la trampa

En algunas expresiones, ***to*** no es parte de un infinitivo, sino una **preposición** (como "a" en castellano). Y después de una preposición va ***-ing***:

| Expresión | Ejemplo |
|---|---|
| ***look forward to*** (esperar con ganas) | *I look forward to **hearing** from you.* |
| ***be used to / get used to*** | *I'm used to **working** remotely.* (unidad 4) |
| ***object to*** (oponerse a) | *I object to **paying** for unused licenses.* |
| ***when it comes to*** | *When it comes to **choosing** a framework, ...* |
| ***in addition to*** | *In addition to **writing** code, she manages the team.* |
| ***be committed / dedicated to*** | *We're committed to **improving** our service.* |
| ***the key to*** | *The key to **learning** English is practice.* |

**Truco:** si después de ese *to* podría ir un **sustantivo**, es preposición: *I look forward to **the meeting*** ✓ → *I look forward to **meeting** you*.

## Verbos seguidos de *to* + base

| Verbo | Ejemplo |
|---|---|
| ***want / would like*** | *I **want to learn** Rust.* |
| ***decide / choose*** | *We **decided to use** PostgreSQL.* |
| ***plan / intend / aim*** | *We **plan to launch** in March.* |
| ***manage*** (lograr) | *We **managed to fix** the bug before the demo.* |
| ***fail*** (no lograr) | *The service **failed to respond**.* |
| ***refuse*** (negarse) | *The server **refused to start**.* |
| ***afford*** (permitirse) | *We can't **afford to lose** this client.* |
| ***tend*** | *Junior developers **tend to over-engineer**.* |
| ***agree / offer / promise / threaten*** | *She **offered to help** me.* |
| ***hope / expect*** | *I **hope to get** into the program.* |
| ***seem / appear*** | *The model **seems to work**.* |
| ***learn*** | *I **learned to code** with Python.* |
| ***need*** | *You **need to restart** the server.* |
| ***deserve / pretend / arrange / attempt*** | *They **arranged to meet** on Monday.* |

**Adjetivo + *to*:** *easy **to use***, *hard **to read***, *likely **to fail***, *ready **to deploy***, *happy **to help***. También ***too*** + adjetivo + ***to*** (*too slow **to use***) y adjetivo + ***enough to*** (*fast **enough to run** on a phone*).

## Verbo + persona + *to* + base

Muchos verbos van con una **persona** y después ***to***:

***want, ask, tell, allow, enable, encourage, expect, force, require, invite, remind, teach, persuade, advise, warn***

- *I **want you to review** my code.* (nunca *I want that you review*)
- *This tool **allows users to create** dashboards.*
- *AI **enables companies to automate** repetitive tasks.*
- *The manager **encouraged me to apply**.*

::: ojo
- ***want that*** no existe: *I want **that you** help me* ✗ → *I want **you to** help me* ✓.
- ***allow*** y ***enable*** necesitan un objeto antes del *to*, o *-ing*: *It allows **to export*** ✗ → *It allows **users to export*** ✓ / *It allows **exporting*** ✓.
:::

## Infinitivo sin *to*

| Después de... | Ejemplo |
|---|---|
| Los **modales** | *You **should check** the logs.* |
| ***make*** + persona (obligar, hacer que) | *The bug **made** me **rewrite** the whole function.* |
| ***let*** + persona (dejar) | *My manager **lets** us **work** from home.* |
| ***help*** + persona (con o sin *to*) | *Can you **help** me **(to) configure** this?* |
| ***had better / would rather*** | ***You'd better save** your work.* |
| ***Why not...?*** | ***Why not use** a library?* |
| ***see / hear / watch / feel*** + persona | *I **saw** him **delete** the file.* (acción completa) |

::: ojo
- ***make*** **en pasiva recupera el *to***: *I **was made to** rewrite it* (unidad 8).
- ***see*** + persona + ***-ing*** = vi la acción **en curso** (una parte): *I saw him **deleting** files* (estaba borrando). Con la base, la vi **completa**: *I saw him **delete** the file*.
:::

## Verbos que admiten las dos formas

**Casi igual significado:** *begin, start, continue, like, love, hate, prefer*.

- *It **started raining** / **to rain**.*
- *I **like working** / **to work** in the morning.*
- Con ***would*** (*would like, would love, would prefer, would hate*) va siempre ***to***: *I'd like **to join** the program*.

**Distinto significado:** acá está la trampa.

| Verbo | + *-ing* | + *to* |
|---|---|---|
| ***stop*** | *He **stopped smoking**.* — dejó de fumar. | *He **stopped to smoke**.* — se detuvo **para** fumar. |
| ***remember*** | *I **remember sending** the email.* — recuerdo haberlo enviado (antes). | ***Remember to send** the email.* — acordate de enviarlo (después). |
| ***forget*** | *I'll never **forget meeting** him.* — no olvidaré haberlo conocido. | *I **forgot to push** my changes.* — me olvidé de pushear. |
| ***try*** | ***Try restarting** the server.* — probá reiniciarlo (como experimento). | *I **tried to restart** it, but it didn't work.* — intenté (me costó, no pude). |
| ***regret*** | *I **regret not learning** English earlier.* — me arrepiento de algo pasado. | *We **regret to inform** you that...* — lamentamos informarle (fórmula formal). |
| ***go on*** | *She **went on talking** for an hour.* — siguió hablando. | *She **went on to explain** the new feature.* — pasó a explicar (algo nuevo). |
| ***mean*** | *This **means rewriting** the module.* — implica reescribirlo. | *I **meant to call** you.* — tenía intención de llamarte. |
| ***need*** | *The server **needs restarting**.* — necesita ser reiniciado (pasivo). | *You **need to restart** the server.* — tenés que reiniciarlo. |

::: tip
**Para *remember*, *forget* y *regret*:** ***-ing*** mira **hacia atrás** (algo que ya pasó); ***to*** mira **hacia adelante** (algo que todavía hay que hacer).
:::

## Finalidad: *to*, no *for*

Para decir **para qué** hacés algo, se usa ***to*** + base (o *in order to*, *so as to*):

| Mal | Bien |
|---|---|
| *I'm studying **for pass** the test.* | *I'm studying **to pass** the test.* |
| *I'm studying **for to pass** the test.* | *I'm studying **in order to pass** the test.* |

***for*** + ***-ing*** describe la **función** de una cosa: *This tool is used **for monitoring** servers* (también *to monitor*). ***for*** + sustantivo: *I'm studying **for the test***.

## Formas perfectas y pasivas

| Forma | Ejemplo | Para qué |
|---|---|---|
| ***having*** + participio | *He denied **having deleted** the file.* | Destacar que pasó antes. |
| ***to have*** + participio | *She seems **to have left**.* | Ídem, con verbos de *to*. |
| ***being*** + participio | *I hate **being interrupted**.* | Pasiva con *-ing*. |
| ***to be*** + participio | *The data needs **to be cleaned**.* | Pasiva con *to*. |

## Ejemplos en inglés técnico

- ***Learning** a new language **involves making** a lot of mistakes.*
- *We **decided to migrate** the database **instead of upgrading** the old server.*
- *This framework **allows developers to build** APIs quickly.*
- *I **look forward to hearing** from you about the next stage of the selection process.*
- *If the app **keeps freezing**, **try clearing** the cache.*
- *Don't **forget to back up** the database **before running** the migration.*
- *AI assistants **can help** you **write** code faster, but you still **need to review** it.*

::: pregunta Choose the correct option: "I look forward to ___ from you soon."
- [ ] hear
- [ ] to hear
- [x] hearing
- [ ] be heard
::: solucion Explicación
En ***look forward to***, *to* es una **preposición**, así que va ***-ing***: *look forward to **hearing***. Es la frase de cierre típica de los emails formales, y la trampa más famosa del tema.

***want*** no va con *that* + oración: se usa ***want*** + persona + ***to*** + base. *I want that you...* traduce palabra por palabra "quiero que vos...".
