# 2 · Mapa de los tiempos verbales y verbos irregulares

Esta unidad es el **mapa**: muestra que los 12 "tiempos" del inglés salen de una sola lógica, y te enseña a **desarmar** cualquier forma verbal para saber qué es. Cuándo se usa cada una se ve en detalle en las unidades 3 (presentes), 4 (pasados) y 5 (futuros).

::: claves
- **Tiempo + aspecto:** 3 tiempos (pasado, presente, futuro) × 4 aspectos (simple, *continuous*, *perfect*, *perfect continuous*) = **12 formas**.
- **Las dos piezas:**
  - ***be* + *-ing*** = *continuous* (acción en curso);
  - ***have* + participio** = *perfect* (acción anterior a un momento de referencia).
- **El primer auxiliar marca el tiempo:** *was* → pasado, *is* → presente, *will* → futuro, *had* → pasado, *has* → presente.
- ***be* + participio** no es *continuous*: es **voz pasiva** (*is used*, *has been fixed*).
- **Verbos irregulares:** el examen mezcla pasado y participio (*wrote/written*, *chose/chosen*) y palabras parecidas (*found/founded*, *rose/raised*, *fell/felt*).
- **Verbos de estado** (*know, need, contain, belong, mean*): no van en *continuous*.
:::

## La idea: tiempo + aspecto

En castellano también combinás piezas: "trabaj**o**", "**estoy** trabaj**ando**", "**he** trabaj**ado**", "**había** trabaj**ado**". El inglés hace lo mismo, pero de forma más sistemática, y con dos ejes:

- **Tiempo:** *cuándo* (pasado, presente, futuro).
- **Aspecto:** *cómo se mira* la acción.

| Aspecto | Qué mira | Pieza | Ejemplo |
|---|---|---|---|
| **Simple** | El hecho, completo o habitual. | — | *The model **predicts** words.* |
| ***Continuous*** | La acción **en curso** en un momento, sin terminar, o temporal. | *be* + *-ing* | *The model **is training** right now.* |
| ***Perfect*** | Algo **anterior** a un momento de referencia, que se conecta con ese momento. | *have* + participio | *The model **has finished** training.* (ya está listo) |
| ***Perfect continuous*** | La **duración** de una actividad hasta un momento. | *have been* + *-ing* | *The model **has been training** for six hours.* |

::: tip
**Una pista para el *perfect*:** siempre hay **dos momentos**. Algo pasó **antes** y se mira **desde** otro momento: desde ahora (*present perfect*), desde un momento del pasado (*past perfect*) o desde uno del futuro (*future perfect*).
:::

## Las 12 formas

Con el verbo *train* (entrenar). El sujeto es *it*, salvo donde se aclara.

| Aspecto | Pasado | Presente | Futuro |
|---|---|---|---|
| **Simple** | *it **trained*** | *it **trains*** | *it **will train*** |
| ***Continuous*** | *it **was training*** | *it **is training*** | *it **will be training*** |
| ***Perfect*** | *it **had trained*** | *it **has trained*** | *it **will have trained*** |
| ***Perfect continuous*** | *it **had been training*** | *it **has been training*** | *it **will have been training*** |

**Fijate en la lógica:**

- Bajando una fila se **agrega una pieza**: *trains* → *is training* → *has trained* → *has been training*.
- Cambiando de columna **solo cambia el primer auxiliar**: *was/is/will be*, *had/has/will have*.
- En el pasado y el presente simple no hay auxiliar visible; por eso aparece ***do/does/did*** en preguntas y negaciones (unidad 1).

**Preguntas y negaciones:** el **primer** auxiliar va antes del sujeto o lleva el *not*. El resto no se mueve.

| Forma | Pregunta | Negación |
|---|---|---|
| *it trains* | ***Does** it train?* | *it **doesn't** train* |
| *it trained* | ***Did** it train?* | *it **didn't** train* |
| *it is training* | ***Is** it training?* | *it **isn't** training* |
| *it has trained* | ***Has** it trained?* | *it **hasn't** trained* |
| *it had been training* | ***Had** it been training?* | *it **hadn't** been training* |
| *it will have trained* | ***Will** it have trained?* | *it **won't** have trained* |

## Cómo desarmar cualquier forma verbal

En lectura y en las preguntas del examen aparecen formas largas como *will have been deployed*. Se desarman **de izquierda a derecha**:

1. **El primer auxiliar dice el tiempo:**
   - *do/does, am/is/are, has/have* → presente;
   - *did, was/were, had* → pasado;
   - *will* → futuro (*would*: condicional o "futuro del pasado", unidades 7 y 9).
2. ***have* + participio** → hay aspecto ***perfect***.
3. ***be* + *-ing*** → hay aspecto ***continuous***.
4. ***be* + participio** → es **voz pasiva** (la acción la recibe el sujeto, unidad 8).

| Forma | Desarmada | Nombre |
|---|---|---|
| *had been training* | *had* (pasado) + *been* (*have* + participio: *perfect*) + *training* (*be* + *-ing*: *continuous*) | *past perfect continuous* |
| *is being reviewed* | *is* (presente) + *being* (*be* + *-ing*: *continuous*) + *reviewed* (*be* + participio: pasiva) | *present continuous*, pasiva |
| *has been fixed* | *has* (presente) + *been* (*perfect*) + *fixed* (*be* + participio: pasiva) | *present perfect*, pasiva |
| *has been fixing* | *has* (presente) + *been* (*perfect*) + *fixing* (*be* + *-ing*: *continuous*) | *present perfect continuous* |
| *will have been deployed* | *will* (futuro) + *have been* (*perfect*) + *deployed* (pasiva) | *future perfect*, pasiva |

::: ojo
***has been fixed*** y ***has been fixing*** se diferencian solo en la última palabra, y significan cosas muy distintas:

- *The bug **has been fixed**.* — el bug **fue arreglado** (alguien lo arregló; pasiva).
- *She **has been fixing** bugs all day.* — ella **estuvo arreglando** bugs todo el día (*continuous*).

**Participio = la cosa recibe la acción. *-ing* = el sujeto hace la acción.**
:::

## Castellano contra inglés

La mayoría de las formas tiene un equivalente directo. Las trampas están en las filas marcadas.

| Castellano | Inglés | Ojo |
|---|---|---|
| Trabajo en EPAM (siempre, rutina). | *I **work** at EPAM.* | |
| Estoy trabajando (ahora). | ***I'm working**.* | |
| **Trabajo acá desde 2024.** | *I **have worked** / **have been working** here since 2024.* | El castellano usa presente; el inglés, *present perfect* (unidad 3). |
| Trabajé ayer. | *I **worked** yesterday.* | |
| **Ya terminé.** | ***I've** already **finished**.* | En Argentina casi no se usa "he terminado": decimos "terminé" para todo. El inglés separa: sin momento concreto, *present perfect*. |
| Trabajaba ahí (hábito). | *I **used to work** there.* | Unidad 4. |
| Estaba trabajando cuando... | *I **was working** when...* | |
| Había trabajado. | *I **had worked**.* | |
| Trabajaré / voy a trabajar. | *I **will work** / **I'm going to work**.* | Unidad 5. |
| **Mañana trabajo** (ya está arreglado). | ***I'm working** tomorrow.* | Plan fijo: *present continuous* (unidad 5). |
| Habré terminado para el viernes. | *I **will have finished** by Friday.* | |

## Las formas del verbo

Cada verbo tiene cuatro formas. Con ellas y los auxiliares se arman las 12.

| Forma | Regular | Irregular | Para qué |
|---|---|---|---|
| **Base** (infinitivo) | *deploy* | *write* | Presente, después de *do/will/can*. |
| **Pasado** | *deployed* | *wrote* | *Past simple*, solo, sin auxiliar. |
| **Participio** | *deployed* | *written* | Después de *have* (*perfect*) o de *be* (pasiva). |
| ***-ing*** | *deploying* | *writing* | Después de *be* (*continuous*) o como sustantivo. |

::: ojo
- **El pasado va solo; el participio necesita auxiliar:** *I **wrote** it* ✓, *I have **written** it* ✓, *I have **wrote** it* ✗, *I **written** it* ✗.
- **Después de *did* va la base:** *Did you **write** it?*, nunca *Did you wrote it?*
:::

**Cómo se escriben los regulares:**

- **-ed** común: *deploy → deploy**ed***, *open → open**ed***.
- **termina en e → -d**: *save → save**d***, *use → use**d***.
- **consonante + y → -ied**: *try → tr**ied***, *copy → cop**ied***.
- **se duplica la consonante final** si la palabra termina en consonante-vocal-consonante y el acento va al final: *stop → sto**pp**ed*, *commit → commi**tt**ed*, *refer → refe**rr**ed*. Si el acento no va al final, no se duplica: *open → opened*, *visit → visited*.
- El ***-ing*** sigue las mismas reglas: *make → making*, *run → ru**nn**ing*, *commit → commi**tt**ing*, *lie → l**y**ing*.

## Verbos de estado

Algunos verbos describen un **estado** (algo que es así), no una **acción** (algo que pasa). Esos **no van en *continuous***, aunque en castellano digas "estoy entendiendo".

| Tipo | Verbos |
|---|---|
| Mente | *know, understand, believe, mean, remember, forget, realize, recognize, agree, doubt* |
| Deseo y gusto | *want, need, prefer, like, love, hate* |
| Posesión y composición | *have* (tener), *own, belong, contain, include, consist of* |
| Otros | *seem, appear* (parecer), *depend, matter, cost, exist* |

- *This dataset **contains** two million rows.* ✓ — *is containing* ✗
- *I **understand** what you mean.* ✓ — *I'm understanding* ✗
- *The file **belongs** to the admin.* ✓

**Verbos que cambian de significado** (en un sentido son estado y en otro, acción):

| Verbo | Estado (sin *-ing*) | Acción (con *-ing*) |
|---|---|---|
| *think* | *I **think** it's a bug.* (opino) | ***I'm thinking** about it.* (lo estoy pensando) |
| *have* | *We **have** two servers.* (tenemos) | ***We're having** a meeting.* (actividad) |
| *see* | *I **see** the problem.* (lo veo, entiendo) | ***I'm seeing** the client tomorrow.* (me reúno) |
| *look* | *It **looks** good.* (parece) | ***I'm looking** at the logs.* (miro) |
| *appear* | *It **appears** to be broken.* (parece) | ***She's appearing** at the conference.* (se presenta) |

## Las 12 formas en un texto técnico

Una historia corta con cada forma marcada. Leela y tratá de nombrar cada forma antes de mirar la tabla de abajo.

> *Our team **trains** (1) a new model every month. Right now, it **is training** (2) on customer data, and it **has been training** (3) for six hours. So far, it **has processed** (4) about half of the dataset.*
>
> *Last month we **trained** (5) a smaller model. While it **was training** (6), the server crashed. We discovered that the disk **had filled up** (7): logs **had been growing** (8) for weeks without anyone noticing.*
>
> *Tomorrow we **will deploy** (9) the new model. This time tomorrow, we **will be testing** (10) it in production. By Friday, it **will have answered** (11) thousands of requests, and by the end of the month we **will have been running** (12) it for three weeks.*

::: solucion Ver las formas
| N.º | Forma | Nombre |
|---|---|---|
| 1 | *trains* | *present simple* (rutina) |
| 2 | *is training* | *present continuous* (ahora) |
| 3 | *has been training* | *present perfect continuous* (duración hasta ahora) |
| 4 | *has processed* | *present perfect* (resultado hasta ahora) |
| 5 | *trained* | *past simple* (hecho terminado) |
| 6 | *was training* | *past continuous* (en curso cuando pasó otra cosa) |
| 7 | *had filled up* | *past perfect* (antes de otro pasado) |
| 8 | *had been growing* | *past perfect continuous* (duración hasta un momento pasado) |
| 9 | *will deploy* | *future simple* |
| 10 | *will be testing* | *future continuous* (en curso en un momento futuro) |
| 11 | *will have answered* | *future perfect* (terminado antes de un momento futuro) |
| 12 | *will have been running* | *future perfect continuous* (duración hasta un momento futuro) |
:::

## Preguntas tipo examen

::: pregunta "By the time the meeting started, the team had been debugging for three hours." Which tense is "had been debugging"?
- [ ] Past continuous
- [ ] Present perfect continuous
- [x] Past perfect continuous
- [ ] Past perfect simple
::: solucion Explicación
Desarmala: ***had*** (pasado) + ***been*** (*have* + participio: *perfect*) + ***debugging*** (*be* + *-ing*: *continuous*) = ***past perfect continuous***. Mide la duración de una actividad hasta un momento del pasado (cuando empezó la reunión).
:::
:::

::: pregunta Choose the correct option: "This dataset ___ more than two million records."
- [ ] is containing
- [x] contains
- [ ] has been containing
- [ ] contain
::: solucion Explicación
***contain*** es un **verbo de estado**: describe cómo es el dataset, no una acción en curso. Por eso no va en *continuous*. *contain* sin *-s* no concuerda con *this dataset* (tercera persona del singular).
:::
:::

::: pregunta Choose the correct option: "Right now the model ___ on the new data, so the server is quite slow."
- [ ] trains
- [x] is training
- [ ] has trained
- [ ] trained
::: solucion Explicación
*Right now* marca una acción **en curso en este momento**: ***present continuous*** (*is* + *-ing*). *trains* sería una rutina (*it trains every night*), y *has trained* diría que ya terminó.
:::
:::

::: pregunta Choose the correct option: "Yesterday we ___ a new microservice from scratch."
- [ ] builded
- [ ] have built
- [x] built
- [ ] build
::: solucion Explicación
*build* es irregular: ***build – built – built***. *Yesterday* es un momento terminado, así que va *past simple*, no *present perfect* (*have built* no se usa con *yesterday*). *builded* no existe.
:::
:::

::: pregunta Choose the correct option: "The new feature was ___ by a junior developer."
- [ ] wrote
- [ ] write
- [x] written
- [ ] writing
::: solucion Explicación
***was* + participio** = voz pasiva: la función **fue escrita** por alguien. El participio de *write* es ***written*** (*write – wrote – written*). *wrote* es el pasado, que va solo, sin auxiliar. *was writing* sería *continuous* y no tendría sentido con *by a junior developer*.
:::
:::

::: pregunta Which sentence is in the present perfect?
- [ ] She worked at EPAM for two years.
- [x] She has worked at EPAM for two years.
- [ ] She is working at EPAM this year.
- [ ] She had worked at EPAM for two years.
::: solucion Explicación
*Present perfect* = ***has/have* (presente) + participio**. *worked* solo es *past simple* (y significa que ya no trabaja ahí), *is working* es *present continuous* y *had worked* es *past perfect*.
:::
:::

::: pregunta Choose the correct option: "I ___ what you mean, but I don't agree with you."
- [ ] am understanding
- [x] understand
- [ ] understanding
- [ ] am understand
::: solucion Explicación
***understand*** es verbo de estado: no se usa en *continuous*, aunque en castellano digas "te estoy entendiendo". *understanding* solo no tiene auxiliar, y *am understand* mezcla *be* con la forma base.
:::
:::

::: pregunta What are the past simple and past participle of "choose"?
- [x] chose – chosen
- [ ] choosed – choosed
- [ ] chose – chose
- [ ] chosen – chose
::: solucion Explicación
***choose – chose – chosen*** (patrón ABC, como *write – wrote – written*). *choosed* no existe. La última opción las da al revés.
:::
:::

::: pregunta Choose the correct option: "Sorry, I can't talk now. We ___ a meeting with the client."
- [ ] have
- [x] are having
- [ ] has
- [ ] had
::: solucion Explicación
Acá *have* no es "tener" (estado) sino "**hacer una actividad**" (*have a meeting, have lunch*), así que sí puede ir en *continuous*: está pasando **ahora**, ***are having***. *We have a meeting* significaría "tenemos una reunión (agendada)".
:::
:::

::: pregunta "The report will have been reviewed by Friday." What does this sentence mean?
- [ ] The report is being reviewed at this moment.
- [x] The review will be finished before or on Friday.
- [ ] The report was reviewed last Friday.
- [ ] Someone will start reviewing the report on Friday.
::: solucion Explicación
Desarmala: ***will*** (futuro) + ***have been*** (*perfect*) + ***reviewed*** (pasiva) = *future perfect* pasivo. *Future perfect* = algo **terminado antes** de un momento futuro (*by Friday* = "para el viernes", a más tardar el viernes).
:::
:::

::: pregunta Choose the correct option: "EPAM was ___ in 1993."
- [ ] found
- [x] founded
- [ ] find
- [ ] finded
::: solucion Explicación
"Fundar" es ***found – founded – founded***, un verbo regular distinto de *find – found – found* (encontrar). *was found* significaría "fue encontrada". *finded* no existe.
:::
:::

::: pregunta Which sentence is NOT correct?
- [ ] I'm thinking about changing jobs.
- [ ] I think this approach is better.
- [x] I'm thinking this approach is better.
- [ ] What do you think of the new API?
::: solucion Explicación
*think* como **opinión** ("me parece") es verbo de estado: ***I think** this approach is better*, sin *-ing*. Como **proceso mental** ("lo estoy pensando, lo estoy considerando") sí admite *continuous*: *I'm thinking about changing jobs*.
:::
:::

::: pregunta Choose the correct option: "The price of the cloud service ___ a lot last year."
- [ ] rised
- [ ] raised
- [x] rose
- [ ] risen
::: solucion Explicación
***rise – rose – risen*** = subir **solo**, sin objeto: el precio subió. ***raise*** (regular) es subir **algo**, con objeto: *The provider **raised** its prices*. *risen* es el participio y necesitaría *has*. *rised* no existe.
:::
:::

::: pregunta Choose the correct option: "I ___ the documentation when I found a mistake in one of the examples."
- [ ] read
- [x] was reading
- [ ] have read
- [ ] am reading
::: solucion Explicación
Una acción **en curso en el pasado** (estaba leyendo) interrumpida por otra corta (*when I found*): ***past continuous*** (*was* + *-ing*) para la larga, *past simple* para la corta. *I read ... when I found* sonaría a que empezaste a leer después de encontrar el error. Es la combinación más típica del pasado; se ve en la unidad 4.
:::
:::
