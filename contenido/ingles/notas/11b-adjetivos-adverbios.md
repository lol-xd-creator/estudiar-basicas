# 11.2 · Adjetivos y adverbios

Tres trampas muy frecuentes en B2 que tienen que ver con cómo se describe algo:

- ***bored*** contra ***boring***: quién siente y qué provoca el sentimiento;
- ***good*** contra ***well***, ***hard*** contra ***hardly***: adjetivo contra adverbio, y adverbios que cambian de significado con *-ly*;
- el **orden** cuando hay varios adjetivos juntos.

::: claves
- ***-ed*** = cómo **se siente** alguien: *I'm **bored***. ***-ing*** = lo que **provoca** ese sentimiento: *The meeting is **boring***.
- **El adjetivo describe a un sustantivo**, también después de *be, look, sound, seem, feel, become, get*: *It sounds **good***. **El adverbio describe a un verbo**: *She codes **well***.
- ***good*** es adjetivo; ***well***, adverbio: *She speaks English **well***, nunca *speaks good*.
- **Adverbios sin *-ly*:** *fast, hard, late, early, high, near*. Con *-ly* cambian de significado: ***hardly*** = casi no, ***lately*** = últimamente, ***nearly*** = casi, ***highly*** = muy.
- **Adjetivos que terminan en *-ly*** (*friendly, likely, costly*) no son adverbios: *in a friendly way*.
- ***very*** + adjetivo normal (*very good*); ***absolutely*** + adjetivo extremo (*absolutely amazing*).
- **Orden:** opinión, tamaño, edad, forma, color, origen, material, propósito: *a **powerful new** laptop*.
:::

## *-ed* contra *-ing*

Muchos adjetivos de sentimientos tienen dos formas. La diferencia es **quién siente** y **qué provoca**:

- ***-ed***: la persona que **siente** algo. *I'm **interested** in AI.* (a mí me interesa)
- ***-ing***: la cosa (o persona) que **provoca** el sentimiento. *AI is **interesting**.* (la IA genera interés)

| *-ed* (cómo me siento) | *-ing* (cómo es lo que lo provoca) |
|---|---|
| *I'm **bored**.* — estoy aburrido | *The meeting is **boring**.* — es aburrida |
| *I'm **confused** by the error.* | *The error message is **confusing**.* |
| *She was **tired** after the sprint.* | *The sprint was **tiring**.* |
| *We're **excited** about the launch.* | *The launch is **exciting**.* |
| *I was **surprised** by the results.* | *The results were **surprising**.* |
| *The client was **disappointed**.* | *The demo was **disappointing**.* |
| *I get **frustrated** when the build fails.* | *Slow builds are **frustrating**.* |
| *I'm **annoyed** with the notifications.* | *The notifications are **annoying**.* |
| *He felt **overwhelmed** by the workload.* | *The workload was **overwhelming**.* |
| *I was **embarrassed** when the demo crashed.* | *The crash was **embarrassing**.* |
| *I'm **worried** about the deadline.* | *The situation is **worrying**.* |
| *We were **amazed** by the speed.* | *The speed was **amazing**.* |
| *She was **exhausted**.* | *The trip was **exhausting**.* |
| *The client was **satisfied** with the work.* | *It was a **satisfying** result.* |

::: ojo
- ***I'm boring*** significa "**soy** aburrido" (aburro a los demás), no "estoy aburrido". Lo mismo con *I'm confusing* (confundo a los demás) o *I'm interesting*.
- Una **persona** también puede ser *-ing*, si provoca el sentimiento: *Our new manager is very **inspiring**.*
- ***impress*** es irregular: *I was **impressed*** (me impresionó) / *The results were **impressive*** (no *impressing*).
:::

## Adjetivo contra adverbio

| | **Adjetivo** | **Adverbio** |
|---|---|---|
| Describe a... | un **sustantivo** (cómo es algo) | un **verbo**, un adjetivo u otro adverbio (cómo se hace algo) |
| Ejemplo | *a **careful** developer* | *She reviews code **carefully**.* |
| Ejemplo | *a **quick** fix* | *We fixed it **quickly**.* |

### Cómo se forma el adverbio

| Regla | Ejemplos |
|---|---|
| adjetivo + ***-ly*** | *quick → quick**ly***, *careful → careful**ly*** |
| ***-y → -ily*** | *easy → eas**ily***, *heavy → heav**ily*** |
| ***-le → -ly*** | *simple → simp**ly***, *possible → possib**ly*** |
| ***-ic → -ically*** | *automatic → automat**ically***, *basic → bas**ically*** (excepción: *public → publicly*) |
| casos especiales | *true → tr**uly***, *full → full**y***, *good → **well*** |

### Después de *be*, *look*, *sound*...: adjetivo

Algunos verbos no describen una acción sino un **estado** o una **impresión**, y conectan el sujeto con un adjetivo. Después de ellos va **adjetivo**, no adverbio:

***be, look, sound, seem, feel, smell, taste, become, get, stay, remain***

- *The plan **sounds good**.* ✓ — *sounds well* ✗
- *The new interface **looks great**.* ✓
- *The system **remained stable** during the test.* ✓
- *The situation **is getting worse**.* ✓

Pero si el verbo describe una **acción**, va adverbio: *She **looked carefully** at the logs* (miró con cuidado, acción de mirar).

### *good* contra *well*

| Palabra | Clase | Ejemplo |
|---|---|---|
| ***good*** | adjetivo | *She's a **good** developer.* / *Your English is **good**.* / *It sounds **good**.* |
| ***well*** | adverbio | *She codes **well**.* / *You speak English very **well**.* / *The demo went **well**.* |
| ***well*** | adjetivo: **bien de salud** | *I'm not feeling **well** today.* |

::: ojo
*You speak English very **good*** ✗ → *very **well*** ✓. Es de los errores más comunes y de los más preguntados.
:::

### Adjetivos que terminan en *-ly*

Estas palabras terminan en *-ly* pero son **adjetivos**, y no tienen adverbio:

***friendly, lovely, lonely, likely, costly, silly, ugly, elderly, lively***

- *The support team was very **friendly**.* ✓ (adjetivo)
- *She spoke to me **in a friendly way**.* ✓ — *spoke friendly* ✗, *friendlily* ✗
- *A **costly** mistake* (un error caro).

## Adverbios que no llevan *-ly* (y los que cambian con *-ly*)

Algunos adverbios tienen **la misma forma** que el adjetivo: ***fast, hard, late, early, high, low, near, straight, daily, weekly, monthly***.

- *It's a **fast** server.* (adjetivo) / *It runs **fast**.* (adverbio) — nunca *fastly*.
- *We publish a **weekly** report.* / *We publish it **weekly**.*

Y si se les agrega *-ly*, **cambia el significado**:

| Sin *-ly* | Con *-ly* |
|---|---|
| *He works **hard**.* — trabaja duro | *He **hardly** works.* — **casi no** trabaja |
| *She arrived **late**.* — llegó tarde | *Have you seen her **lately**?* — **últimamente** |
| *The server is **near** the office.* — cerca | *The migration is **nearly** done.* — **casi** |
| *The plane flew **high**.* — alto | *This course is **highly** recommended.* — **muy, altamente** |
| *Most people agree.* — la mayoría | *The team is **mostly** remote.* — **mayormente** |
| *The tool is **free**.* — gratis | *You can move **freely**.* — **libremente** |
| *The file is **close** to the limit.* — cerca | *We're monitoring it **closely**.* — **de cerca**, con atención |
| *It goes **deep** into the system.* — profundo (físico) | *I'm **deeply** sorry.* — **profundamente** |
| *The door is **wide** open.* — de par en par | *Python is **widely** used.* — **ampliamente** |
| *Keep it **short**.* — corto | *The meeting will start **shortly**.* — **en breve** |

::: ojo
***hardly*** es **negativo**: no se usa con otra negación. *I hardly **never** use it* ✗ → *I **hardly ever** use it* ✓ (casi nunca). *I **hardly** know anyone* = casi no conozco a nadie.
:::

## Dónde va el adverbio

| Tipo | Posición | Ejemplo |
|---|---|---|
| **Modo** (*carefully, quickly, well*) | Al final, después del objeto | *She explained the problem **clearly**.* (no *explained clearly the problem*) |
| **Grado** (*very, extremely, really, quite, fairly, rather*) | Antes del adjetivo o adverbio | *It's **extremely** fast.* / *It works **really** well.* |
| **Frecuencia** (*always, often, never*) | Antes del verbo principal (unidad 1) | *We **often** deploy on Fridays.* |
| **De opinión sobre toda la oración** (*Fortunately, Unfortunately, Obviously, Surprisingly, Hopefully*) | Al principio | ***Fortunately**, we had a backup.* |

## Adjetivos graduables y extremos (C1)

Algunos adjetivos admiten grados (algo puede ser más o menos *good*, *big*, *tired*). Otros ya son **extremos** o absolutos (*amazing* ya es "muy bueno"). Cada grupo va con intensificadores distintos:

| Tipo | Ejemplos | Va con | No va con |
|---|---|---|---|
| **Graduable** | *good, bad, big, small, tired, important, difficult, interesting* | ***very**, extremely, quite, a bit, slightly* | ~~*absolutely good*~~ |
| **Extremo** | *amazing, awful, enormous, tiny, exhausted, essential, impossible, perfect* | ***absolutely**, totally, completely, utterly* | ~~*very amazing*~~, ~~*very impossible*~~ |

***really*** sirve con los dos: *really good*, *really amazing*. ***completely / totally*** van también con adjetivos absolutos como *wrong, different, new, unacceptable*.

## El orden de varios adjetivos

Cuando hay varios adjetivos antes de un sustantivo, siguen un orden fijo. No hace falta memorizar todo: lo más preguntado es que **la opinión va primero** y **el propósito va último**, pegado al sustantivo.

| Orden | Tipo | Ejemplos |
|---|---|---|
| 1 | Opinión | *nice, powerful, reliable* |
| 2 | Tamaño | *big, small* |
| 3 | Edad | *new, old* |
| 4 | Forma | *round, flat* |
| 5 | Color | *black, white* |
| 6 | Origen | *Italian, Polish* |
| 7 | Material | *metal, plastic* |
| 8 | Propósito | *gaming, office* |

- *a **powerful new** language model* (opinión + edad) — no *a new powerful*.
- *a **nice small black** laptop* (opinión + tamaño + color).
- *an **old Polish** software company* (edad + origen).
- *a **comfortable new office** chair* (opinión + edad + propósito).

## Adjetivos compuestos

Dos o más palabras unidas por guiones que funcionan como un solo adjetivo antes del sustantivo:

- **número + sustantivo en singular:** *a **40-minute** test*, *a **two-year** contract*, *a **ten-page** report* (no *40-minutes*);
- otros frecuentes: *a **well-known** company*, *a **long-term** plan*, *an **open-source** library*, *a **user-friendly** interface*, *an **AI-powered** tool*, *a **high-quality** dataset*, *a **time-consuming** task*.

## Ejemplos en inglés técnico

- *The documentation was so **confusing** that half the team got **frustrated**.*
- *The new model performs **surprisingly well** on short texts.*
- *We've been **closely** monitoring the servers **lately**, and they look **stable**.*
- *I **hardly ever** use Java now; I work **mostly** with Python.*
- *EPAM is a **well-known** company with a **highly** skilled workforce.*
- *We're looking for a **reliable, fast, open-source** database.*
- *The results were **absolutely amazing**: the response time dropped by 80%.*

## Preguntas tipo examen

::: pregunta Choose the correct option: "The two-hour meeting was really ___, and half the team fell asleep."
- [x] boring
- [ ] bored
- [ ] bore
- [ ] boredom
::: solucion Explicación
La reunión **provoca** aburrimiento: ***boring*** (*-ing*). *bored* es cómo se sienten las personas (*the team was bored*). *bore* es el verbo o un sustantivo, y *boredom*, el sustantivo "aburrimiento".
:::
:::

::: pregunta Choose the correct option: "I was completely ___ by the error message, so I asked a colleague."
- [ ] confusing
- [x] confused
- [ ] confuse
- [ ] confusion
::: solucion Explicación
Es cómo **me sentí** yo: ***confused*** (*-ed*). *I was confusing* significaría que yo confundía a los demás. El mensaje sí sería *confusing*.
:::
:::

::: pregunta Choose the correct option: "Everyone was ___ with the results of the pilot project."
- [ ] impressing
- [ ] impressive
- [x] impressed
- [ ] impression
::: solucion Explicación
Cómo **se sintió** la gente: ***impressed***. Los resultados serían ***impressive*** (no *impressing*: *impress* es irregular en la forma que provoca el sentimiento).
:::
:::

::: pregunta Choose the correct option: "After six months in the program, she speaks English very ___."
- [ ] good
- [x] well
- [ ] goodly
- [ ] best
::: solucion Explicación
Describe **cómo habla** (un verbo): adverbio, ***well***. *good* es adjetivo (*Her English is good*). *speaks very good* es uno de los errores más preguntados.
:::
:::

::: pregunta Choose the correct option: "Your proposal sounds ___. Let's discuss it with the team."
- [x] good
- [ ] well
- [ ] nicely
- [ ] greatly
::: solucion Explicación
***sound*** no describe una acción sino una impresión, y conecta el sujeto con un **adjetivo**: *sounds **good***. Lo mismo con *look, seem, feel, be*. Los adverbios (*well, nicely, greatly*) no van ahí.
:::
:::

::: pregunta Choose the correct option: "He works very ___ to meet every deadline."
- [x] hard
- [ ] hardly
- [ ] hardness
- [ ] harder
::: solucion Explicación
*hard* es adjetivo **y** adverbio con la misma forma: *works hard* = trabaja duro. ***hardly*** significa "casi no": *He hardly works* = casi no trabaja. *very harder* es imposible (unidad 11).
:::
:::

::: pregunta Choose the correct option: "It's my first week, so I ___ know anyone in the new team."
- [x] hardly
- [ ] hard
- [ ] late
- [ ] near
::: solucion Explicación
***hardly*** = **casi no**: *I hardly know anyone*. Fijate que va con *anyone*, porque *hardly* ya es negativo.
:::
:::

::: pregunta Choose the correct option: "Have you used the new API ___? I heard it changed a lot."
- [ ] late
- [x] lately
- [ ] latest
- [ ] later
::: solucion Explicación
***lately*** = **últimamente** (va con *present perfect*). *late* = tarde (*I arrived late*). *latest* = el más reciente (*the latest version*).
:::
:::

::: pregunta Choose the correct option: "Python is ___ used in data science and machine learning."
- [x] widely
- [ ] wide
- [ ] widen
- [ ] width
::: solucion Explicación
Describe al participio *used* (cómo se usa): adverbio, ***widely*** = ampliamente. *wide* es adjetivo (ancho), *widen* es verbo (ensanchar) y *width*, sustantivo (ancho).
:::
:::

::: pregunta Choose the correct option: "The migration is ___ finished; we only need to update the documentation."
- [x] nearly
- [ ] near
- [ ] nearest
- [ ] nearby
::: solucion Explicación
***nearly*** = **casi** (*almost*). *near* y *nearby* hablan de cercanía física (*near the office*), y *nearest* es el superlativo.
:::
:::

::: pregunta Choose the correct option: "This online course is ___ recommended for beginners."
- [ ] high
- [x] highly
- [ ] higher
- [ ] height
::: solucion Explicación
***highly*** = **muy, altamente** (*highly recommended, highly skilled, highly unlikely*). *high* es altura física (*The server rack is high*).
:::
:::

::: pregunta Choose the correct option: "The support agent spoke to me ___ and solved my problem in minutes."
- [ ] friendly
- [x] in a friendly way
- [ ] friendlily
- [ ] friend
::: solucion Explicación
***friendly*** es un **adjetivo** aunque termine en *-ly*, y no tiene adverbio (*friendlily* no se usa). Para describir **cómo** habló se dice ***in a friendly way***. *The agent was friendly* sí estaría bien.
:::
:::

::: pregunta Choose the correct option: "The results of the new model were absolutely ___."
- [ ] good
- [x] amazing
- [ ] big
- [ ] interesting
::: solucion Explicación
***absolutely*** va con adjetivos **extremos** (*amazing, awful, perfect, essential*). Con adjetivos graduables (*good, big, interesting*) se usa *very* o *extremely*: *absolutely good* ✗.
:::
:::

::: pregunta Which phrase has the correct adjective order?
- [ ] a new powerful laptop
- [x] a powerful new laptop
- [ ] a laptop powerful new
- [ ] a new laptop powerful
::: solucion Explicación
La **opinión** (*powerful*) va antes de la **edad** (*new*), y todos los adjetivos van **antes** del sustantivo: *a powerful new laptop*.
:::
:::

::: pregunta Choose the correct option: "We signed a ___ contract with the client."
- [ ] two-years
- [x] two-year
- [ ] two year's
- [ ] twos-year
::: solucion Explicación
En un **adjetivo compuesto** con número, el sustantivo va en **singular** y con guion: *a **two-year** contract*, como *a 40-minute test*. *two-years* lleva el plural donde no va.
:::
:::

::: pregunta Choose the correct option: "Our team handled the incident very ___."
- [ ] professional
- [x] professionally
- [ ] profession
- [ ] professionalism
::: solucion Explicación
Describe **cómo** lo manejaron (el verbo *handled*): adverbio, ***professionally***. *professional* es adjetivo (*a professional team*).
:::
:::
