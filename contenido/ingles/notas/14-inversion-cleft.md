# 14 · C1 (1): inversión, cleft sentences y énfasis

Esta es la unidad más "de C1". Son estructuras que casi no se usan al hablar, pero que aparecen en textos formales y en **todos** los exámenes de nivel avanzado. La buena noticia: son pocas reglas y muy mecánicas. Todas sirven para **destacar** una parte de la oración.

::: claves
- **Inversión:** si la oración **empieza** con una expresión negativa o restrictiva, el auxiliar va **antes** del sujeto, como en una pregunta: ***Never have I** seen...*, ***Rarely does** it crash*.
- **Sin auxiliar visible, aparece *do/does/did***: *Not only **does** it run faster...*
- ***Hardly / Scarcely... when*** y ***No sooner... than***, con *past perfect*.
- ***Only when / Not until...***: la inversión va en la **segunda** parte: *Only when the tests passed **did we deploy***.
- **Condicionales:** *Should you need..., Had I known..., Were it not for...*
- ***Cleft sentences:*** *It was **the cache** that caused the bug.* / ***What** we need **is** more data.*
- **Énfasis con *do/does/did***: *I **do** understand.*
:::

## Inversión: qué es

En una pregunta, el auxiliar va antes del sujeto: *Have you seen...?* La **inversión** usa ese mismo orden en una oración que **no** es pregunta. Pasa cuando la oración arranca con una palabra negativa o restrictiva, para darle fuerza:

| Normal | Con inversión |
|---|---|
| *I have **never** seen such a fast model.* | ***Never have I** seen such a fast model.* |
| *The system **rarely** crashes.* | ***Rarely does** the system crash.* |
| *We had **hardly** started when the server went down.* | ***Hardly had we** started when the server went down.* |

**Cómo se arma:**

1. La expresión negativa pasa al principio.
2. El auxiliar va antes del sujeto. Si no hay auxiliar (*present simple* o *past simple*), aparece ***do/does/did*** y el verbo vuelve a la base.
3. El resto queda igual.

::: ojo
**Si la expresión negativa no está al principio, no hay inversión:**

- *I have **never** seen...* ✓ (orden normal)
- ***Never** I have seen...* ✗ (la expresión está al principio y falta la inversión)
- ***Never have I** seen...* ✓
:::

## Las expresiones que piden inversión

### Frecuencia negativa

***Never, Rarely, Seldom, Hardly ever, Not once, At no time***

- ***Rarely do** we **see** such good results on the first try.*
- ***Not once did** the system **fail** during the test.*
- ***At no time was** the data **exposed** to third parties.*

### *Not only... but (also)*

- ***Not only does** the new model **answer** faster, **but** it **also** costs less.*
- ***Not only did** she **fix** the bug, **but** she **also** wrote tests for it.*

La inversión va solo en la parte de *Not only*; la parte de *but* tiene orden normal.

### Una cosa pasó apenas terminó otra

| Estructura | Ejemplo |
|---|---|
| ***Hardly / Scarcely / Barely*** + *had* + sujeto + participio + ***when*** | ***Hardly had** we **deployed** the update **when** users started reporting errors.* |
| ***No sooner*** + *had* + sujeto + participio + ***than*** | ***No sooner had** I **sent** the email **than** I noticed the mistake.* |

::: ojo
**La pareja de cada uno es fija:** *Hardly... **when***, *No sooner... **than***. Mezclarlas (*No sooner... when*, *Hardly... than*) es la trampa clásica. Y las dos van con ***past perfect*** en la primera parte.
:::

### *Only...* y *Not until...*

Con ***Only*** + una expresión de tiempo o condición, y con ***Not until***, la inversión va en la **cláusula principal** (la segunda), no en la que sigue a *only*:

| Expresión | Ejemplo |
|---|---|
| ***Only when*** | ***Only when** the tests passed **did we deploy**.* |
| ***Only after*** | ***Only after** reading the logs **did I understand** the problem.* |
| ***Only then*** | ***Only then did** we **realize** the data was corrupted.* |
| ***Only if*** | ***Only if** all checks pass **will** the code **be merged**.* |
| ***Only by*** | ***Only by** automating the process **can we scale**.* |
| ***Not until*** | ***Not until** the client complained **did we notice** the bug.* |

::: ojo
- ***Only when the tests passed** we deployed* ✗ → falta la inversión en la segunda parte: ***did we deploy***.
- ***Only when did the tests pass** we deployed* ✗ → la inversión está en la parte equivocada.
- Si *only* va con el **sujeto**, no hay inversión: ***Only Ana** knew the password* ✓.
:::

### Negación total: *Under no circumstances*, *On no account*...

***Under no circumstances, On no account, In no way, By no means*** (de ninguna manera, bajo ningún concepto)

- ***Under no circumstances should** you **share** your password.*
- ***On no account must** this file **be deleted**.*

### *Little*, *So* y *Such*

- ***Little did** they **know** that the system had been hacked.* (no tenían ni idea)
- ***So complex was** the code **that** nobody wanted to maintain it.*
- ***Such was** the demand **that** the servers crashed.*

## Inversión en condicionales

En registro formal se saca el *if* y se invierte el auxiliar (ya lo viste en la unidad 7):

| Con *if* | Con inversión |
|---|---|
| *If you **should need** any help, ...* | ***Should you need** any help, ...* |
| *If I **had known** about the risk, ...* | ***Had I known** about the risk, ...* |
| *If I **were** in your position, ...* | ***Were I** in your position, ...* |
| *If the client **were to** cancel, ...* | ***Were the client to** cancel, ...* |
| *If it **weren't** for your help, ...* | ***Were it not for** your help, ...* |
| *If it **hadn't been** for the backups, ...* | ***Had it not been for** the backups, ...* |

::: ojo
**La negación no se contrae:** ***Had we not** tested it...* ✓ / *Hadn't we tested it...* ✗.
:::

## *Cleft sentences*: partir la oración para destacar

Una ***cleft sentence*** ("oración escindida") divide una oración en dos para poner el foco en una parte. En castellano hacemos lo mismo: "**Fue el caché lo que** causó el bug", "**Lo que** necesitamos **es** más datos".

### Con *It*: *It is / was... that / who*

***It*** + ***be*** + **la parte destacada** + ***that*** (o *who* para personas) + el resto.

| Oración normal | Destacando... | *Cleft sentence* |
|---|---|---|
| *The cache caused the bug.* | la causa | ***It was the cache that** caused the bug.* |
| *Ana found the vulnerability.* | la persona | ***It was Ana who** found the vulnerability.* |
| *We noticed the problem on Monday.* | el momento | ***It was on Monday that** we noticed the problem.* |

Muy usada: ***It wasn't until*** ... ***that***...: ***It wasn't until** 2020 **that** remote work became normal.*

### Con *What*: *What... is / was*

***What*** + sujeto + verbo + ***be*** + **la parte destacada**.

| Oración normal | *Cleft sentence* |
|---|---|
| *We need more data.* | ***What we need is** more data.* |
| *I don't understand the error message.* | ***What I don't understand is** the error message.* |
| *I restarted the server.* | ***What I did was (to) restart** the server.* |
| *The server crashed.* | ***What happened was (that)** the server crashed.* |

### Otras formas

| Estructura | Ejemplo |
|---|---|
| ***All*** + sujeto + verbo + ***be*** (lo único que) | ***All I did was** change one line.* |
| ***The reason (why)... is that*** | ***The reason why** the build failed **is that** a dependency was missing.* |
| ***The thing is (that)*** | ***The thing is**, we don't have enough time.* |
| ***The person who / The place where / The day when*** | ***The person who** helped me most **was** my mentor.* |

::: ojo
- ***What*, no *That* ni *Which***: *What we need is...* ✓ / *That we need is...* ✗ / *The thing what we need* ✗.
- ***The reason... is that***, mejor que *is because* en registro formal: *The reason is **that** it was too slow.*
- Después de ***What I did was*** va la **base** (o *to* + base): *What I did was **restart** it* ✓, *What I did was restarted it* ✗.
:::

## Énfasis con *do/does/did*

En una afirmación, se puede agregar *do/does/did* antes del verbo (que vuelve a la base) para **remarcar** que algo es así, a menudo para contradecir lo que otro piensa:

- *I **do** understand the risks, but we have no choice.* (te juro que sí entiendo)
- *She **did** send the email. I saw it.* (sí lo mandó)
- *The new version **does** work better.*
- En imperativos, para invitar con insistencia: ***Do** join us for the demo!*

**Otras formas de dar énfasis:**

- ***at all*** / ***whatsoever*** en negativas: *There's no evidence **whatsoever**.*
- ***the very*** + sustantivo: *This is **the very** problem we discussed.*
- ***by far*** + superlativo: *It's **by far** the best option.*
- ***indeed***: *The results were very good **indeed**.*

## Ejemplos en inglés técnico

- ***Never before have** language models **been** so accessible to ordinary users.*
- ***Not only does** automation **reduce** errors, but it **also** frees developers for more creative work.*
- ***Only after** the incident **did** the company **invest** in proper monitoring.*
- ***Under no circumstances should** API keys **be committed** to a public repository.*
- ***It was** a single misconfigured server **that** caused the entire outage.*
- ***What** makes this framework popular **is** its simplicity.*
- ***Had we** **monitored** the disk usage, the outage would never have happened.*

## Preguntas tipo examen

::: pregunta Choose the correct option: "Never ___ such a fast deployment process."
- [ ] I have seen
- [x] have I seen
- [ ] I saw
- [ ] did I saw
::: solucion Explicación
***Never*** al principio pide **inversión**: auxiliar + sujeto, ***have I seen***. *did I saw* tiene dos pasados (después de *did* va la base).
:::
:::

::: pregunta Choose the correct option: "Not only ___ faster, but it also uses less memory."
- [ ] the new version runs
- [x] does the new version run
- [ ] the new version does run
- [ ] runs the new version
::: solucion Explicación
***Not only*** al principio → inversión. Como *runs* está en *present simple* (sin auxiliar), aparece ***does*** y el verbo vuelve a la base: *does the new version **run***.
:::
:::

::: pregunta Choose the correct option: "Hardly had we started the migration ___ the database went down."
- [ ] than
- [x] when
- [ ] that
- [ ] then
::: solucion Explicación
La pareja de ***Hardly*** (y de *Scarcely*, *Barely*) es ***when***. ***than*** va con ***No sooner***. Es una de las trampas más típicas de C1.
:::
:::

::: pregunta Choose the correct option: "No sooner ___ the report than the client asked for changes."
- [ ] I had submitted
- [ ] I submitted
- [x] had I submitted
- [ ] did I submitted
::: solucion Explicación
***No sooner*** pide inversión y ***past perfect***: ***had I submitted***. La segunda parte va con *than* y en *past simple*.
:::
:::

::: pregunta Choose the correct option: "Only when the tests passed ___ the new version."
- [ ] we released
- [x] did we release
- [ ] we did release
- [ ] released we
::: solucion Explicación
Con ***Only when***, la inversión va en la **cláusula principal** (la segunda): ***did we release***. La primera parte (*the tests passed*) queda con orden normal.
:::
:::

::: pregunta Choose the correct option: "Under no circumstances ___ your password with anyone."
- [ ] you should share
- [x] should you share
- [ ] you share
- [ ] do you should share
::: solucion Explicación
***Under no circumstances*** (bajo ningún concepto) pide inversión: el modal va antes del sujeto, ***should you share***. *do you should* mezcla dos auxiliares.
:::
:::

::: pregunta Choose the correct option: "Little ___ that the system had already been compromised."
- [ ] they knew
- [ ] they did know
- [x] did they know
- [ ] knew they
::: solucion Explicación
***Little*** al principio, con el sentido de "no tenían ni idea", pide inversión con *did*: ***did they know***. *knew they* invierte el verbo principal, algo que el inglés moderno no hace.
:::
:::

::: pregunta Choose the correct option: "___ about the security flaw, we would have fixed it immediately."
- [ ] If we knew
- [ ] Did we know
- [x] Had we known
- [ ] Have we known
::: solucion Explicación
Tercer condicional con **inversión**: *If we had known* → ***Had we known***. *If we knew* sería segundo condicional y no combina con *would have fixed*.
:::
:::

::: pregunta Choose the correct option: "___ for the backups, we would have lost all our data."
- [ ] Had it not
- [x] Had it not been
- [ ] If it wasn't
- [ ] Hadn't it been
::: solucion Explicación
***Had it not been for*** + sustantivo = "si no hubiera sido por". *Had it not* sola está incompleta, *If it wasn't for* sería segundo condicional (presente), y en la inversión la negación **no se contrae** (*Hadn't it been* ✗).
:::
:::

::: pregunta Choose the correct option: "It was the junior developer ___ found the critical bug."
- [ ] which
- [x] who
- [ ] what
- [ ] whom
::: solucion Explicación
*Cleft sentence* con *It was* + persona + ***who*** (o *that*). *which* es para cosas, *what* no se usa en esta estructura, y *whom* sería objeto, pero acá es el sujeto de *found*.
:::
:::

::: pregunta Choose the correct option: "___ we really need is a better monitoring system."
- [ ] That
- [ ] Which
- [x] What
- [ ] The thing what
::: solucion Explicación
*Cleft sentence* con ***What***: "**lo que** realmente necesitamos es...". *That* y *Which* no pueden empezar esta estructura, y *the thing what* mezcla dos formas (sería *the thing that*).
:::
:::

::: pregunta Choose the correct option: "All I did ___ one line in the configuration file."
- [ ] was changed
- [x] was change
- [ ] is changing
- [ ] did change
::: solucion Explicación
Después de ***All / What*** + sujeto + ***did*** + ***was***, va la **base** del verbo (o *to* + base): *All I did was **change** one line*.
:::
:::

::: pregunta Choose the correct option: "It wasn't until the client complained ___ we realized there was a problem."
- [ ] when
- [ ] then
- [x] that
- [ ] so
::: solucion Explicación
***It wasn't until*** + momento + ***that*** + oración = "recién cuando... nos dimos cuenta". Es una *cleft sentence* con *It*: siempre lleva *that*.
:::
:::

::: pregunta Which sentence is NOT correct?
- [ ] Rarely do we see such good results.
- [ ] We rarely see such good results.
- [x] Rarely we see such good results.
- [ ] Seldom do we see such good results.
::: solucion Explicación
Si ***Rarely*** va al **principio**, la inversión es obligatoria: *Rarely **do we** see*. Si va en el medio (*We rarely see*), el orden es normal. La tercera pone *Rarely* al principio sin invertir.
:::
:::

::: pregunta Choose the correct option: "I know you think I wasn't listening, but I ___ understand your concerns."
- [ ] am
- [x] do
- [ ] have
- [ ] did
::: solucion Explicación
**Énfasis** con *do*: *I **do** understand* = "sí que entiendo", para contradecir lo que piensa el otro. Va en presente porque se habla de ahora; *did understand* sería pasado.
:::
:::
