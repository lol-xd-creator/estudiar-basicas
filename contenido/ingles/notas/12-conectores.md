# 12 · Conectores y estructura del discurso

Los **conectores** (*although*, *despite*, *however*, *therefore*, *so that*...) unen ideas y dicen qué relación hay entre ellas: contraste, causa, consecuencia, finalidad. El examen no pregunta tanto **qué significan** sino **qué estructura va después**: *although* + oración, pero *despite* + sustantivo; *because* + oración, pero *because of* + sustantivo. Además, son la clave para entender los textos de lectura (unidad 16).

::: claves
- **El criterio central: ¿qué va después?**
  - una **oración** (sujeto + verbo): *although, even though, because, since, as, whereas, so that*;
  - un **sustantivo** o ***-ing***: *despite, in spite of, because of, due to, owing to*.
- ***despite*** **sin *of***; ***in spite*** **con *of***.
- ***however, therefore, moreover, nevertheless*** son adverbios: van entre oraciones, con **punto o punto y coma** y **coma**. No unen dos oraciones con una coma sola.
- **Finalidad:** *to / in order to / so as to* + base; ***so that*** + oración (con *can/could/will/would*).
- **Falsos amigos:** ***eventually*** = finalmente (no "eventualmente"); ***actually*** = en realidad (no "actualmente").
:::

## Contraste

| Conector | Qué va después | Ejemplo |
|---|---|---|
| ***although / though / even though*** | oración | ***Although** the model is accurate, it's very expensive.* |
| ***despite / in spite of*** | sustantivo, *-ing* o *the fact that* + oración | ***Despite** the high cost, we chose the cloud.* / ***In spite of being** expensive, ...* |
| ***however*** | oración nueva (con coma) | *The model is accurate. **However**, it's very expensive.* |
| ***nevertheless / nonetheless*** | oración nueva (formal) | *The project was delayed. **Nevertheless**, the client was satisfied.* |
| ***but / yet*** | oración, en la misma oración | *It's fast, **but** it uses a lot of memory.* |
| ***whereas / while*** | oración: compara **dos** cosas | *Python is interpreted, **whereas** C is compiled.* |
| ***on the other hand*** | oración nueva: otra cara del tema | *Cloud services are flexible. **On the other hand**, they can be costly.* |
| ***on the contrary*** | **contradice** lo anterior | *The test wasn't easy. **On the contrary**, it was very hard.* |
| ***even so*** | "aun así" | *It was expensive. **Even so**, it was worth it.* |

::: ojo
**Las trampas del contraste:**

| Mal | Bien |
|---|---|
| ***Despite of** the delay, ...* | ***Despite** the delay, ...* / ***In spite of** the delay, ...* |
| ***Despite** it was late, ...* | ***Although** it was late, ...* / ***Despite the fact that** it was late, ...* |
| ***Although** the delay, ...* | ***Although** there was a delay, ...* / ***Despite** the delay, ...* |
| *It's fast, **however** it uses a lot of memory.* | *It's fast. **However**, it uses a lot of memory.* / *It's fast; **however**, it uses...* |

***even though*** es más fuerte que *although* ("a pesar de que, aunque de verdad..."). ***even if*** es condicional: "aun en el caso de que" (unidad 7).

***Though*** también puede ir al **final**, en el habla: *It was expensive. It worked, **though**.*
:::

## Causa

| Conector | Qué va después | Ejemplo |
|---|---|---|
| ***because*** | oración | *The build failed **because** a dependency was missing.* |
| ***because of / due to / owing to*** | sustantivo o *-ing* | *The build failed **because of** a missing dependency.* |
| ***since / as*** | oración (a menudo al principio) | ***Since** the server was down, we worked offline.* |
| ***due to the fact that*** | oración (formal) | *The release was postponed **due to the fact that** tests were failing.* |
| ***thanks to*** | sustantivo (causa positiva) | ***Thanks to** automation, deployments take five minutes.* |

::: ojo
- ***because*** + oración, ***because of*** + sustantivo: *because **it rained*** / *because of **the rain***.
- ***due to*** después de *be* es el uso más formal y seguro: *The delay **was due to** a network issue.*
- ***since*** tiene dos sentidos: "desde" (tiempo, unidad 3) y "ya que" (causa). El contexto los separa.
:::

## Consecuencia

| Conector | Qué va después | Ejemplo |
|---|---|---|
| ***so*** | oración, en la misma oración | *The server was down, **so** we couldn't deploy.* |
| ***therefore / thus / consequently / as a result*** | oración nueva (formal) | *The data was corrupted. **Therefore**, we restored the backup.* |
| ***as a result of*** | sustantivo | ***As a result of** the outage, we lost two clients.* |
| ***hence*** | sustantivo o frase corta (muy formal) | *The code is open source, **hence** the low cost.* |
| ***so*** + adjetivo + ***that*** / ***such*** + sustantivo + ***that*** | oración (unidad 11) | *It was **so** slow **that** nobody used it.* |

## Finalidad

| Conector | Qué va después | Ejemplo |
|---|---|---|
| ***to / in order to / so as to*** | base del verbo | *We added a cache **in order to** reduce latency.* |
| ***in order not to / so as not to*** | base (negativa) | *I left early **so as not to** miss the train.* |
| ***so that*** | oración, casi siempre con *can, could, will, would* | *We added a cache **so that** the app **would** load faster.* |
| ***for*** | sustantivo o *-ing* (función) | *This script is **for** cleaning the data.* |
| ***in case*** | oración (precaución, unidad 7) | *Keep a backup **in case** something goes wrong.* |

::: ojo
- *We added a cache **for reduce** latency* ✗ → ***to reduce*** ✓ (unidad 10).
- La negativa de *to* es ***not to***, con *not* antes: *in order **not to** lose data*.
- ***so that*** necesita **sujeto y verbo**: *so that **users can** log in faster*.
:::

## Adición

| Conector | Dónde va | Ejemplo |
|---|---|---|
| ***and / also*** | *also* antes del verbo principal, después de *be* | *It's fast. It's **also** cheap.* / *It **also** supports Python.* |
| ***too / as well*** | al **final** | *It supports Python **too**.* |
| ***moreover / furthermore / in addition / what's more*** | principio de oración nueva (formal) | *The tool is free. **Moreover**, it's open source.* |
| ***besides*** | principio de oración (más informal) / + *-ing* | ***Besides** being free, it's very easy to use.* |
| ***in addition to / as well as*** | + sustantivo o ***-ing*** | ***In addition to** writing code, she trains new hires.* |
| ***not only... but also*** | dos elementos paralelos | *AI can **not only** write code **but also** explain it.* |

::: ojo
***in addition to*** y ***as well as*** van con ***-ing***, no con la base: *In addition to **write*** ✗ → *In addition to **writing*** ✓ (*to* es preposición, unidad 10).
:::

## Tiempo y secuencia

| Conector | Uso | Ejemplo |
|---|---|---|
| ***first / then / next / after that / finally*** | ordenar pasos | ***First**, clone the repo. **Then**, install the dependencies.* |
| ***eventually*** | **finalmente** (después de mucho tiempo o esfuerzo) | *After three days of debugging, we **eventually** found the problem.* |
| ***meanwhile / in the meantime*** | mientras tanto | *The build will take an hour. **Meanwhile**, let's review the docs.* |
| ***as soon as / once*** | apenas, una vez que | ***Once** the tests pass, we'll deploy.* (presente, unidad 5) |
| ***until*** contra ***by*** | hasta (duración) / para (límite) | *I'll work **until** 6.* / *I'll finish **by** 6.* |
| ***during*** contra ***while*** | + sustantivo / + oración | ***during** the meeting* / ***while** we were meeting* |

## Ejemplo, aclaración y conclusión

| Conector | Uso | Ejemplo |
|---|---|---|
| ***for example / for instance*** | dar un ejemplo (oración) | *Some languages, **for example** Rust, are memory-safe.* |
| ***such as*** | + sustantivos, una lista de ejemplos | *Cloud providers **such as** AWS and Azure...* |
| ***e.g.*** / ***i.e.*** | "por ejemplo" / "es decir" (escrito) | *a compiled language (**e.g.** C)* / *the default branch (**i.e.** main)* |
| ***in other words / that is (to say) / namely*** | reformular, precisar | *The API is stateless; **in other words**, it doesn't store sessions.* |
| ***in conclusion / to sum up / overall / all in all*** | cerrar | ***Overall**, the migration was a success.* |

## Marcadores del habla y falsos amigos

| Palabra | Significa | **No** significa |
|---|---|---|
| ***actually*** | en realidad, de hecho | actualmente (= *currently*, *nowadays*) |
| ***eventually*** | finalmente, al final | eventualmente (= *possibly*, *occasionally*) |
| ***in fact / as a matter of fact*** | de hecho | |
| ***anyway*** | de todos modos, en fin | |
| ***after all*** | después de todo, al fin y al cabo | "después de todo lo demás" |
| ***by the way*** | a propósito, por cierto | |

- *I thought the bug was in the frontend, but **actually** it was in the API.*
- *We are **currently** migrating to Kubernetes.* (actualmente)

## Ejemplos en inglés técnico

- ***Although** AI tools can generate code quickly, developers **still** need to review it carefully.*
- ***Despite** the outage, the team managed to deliver the project on time.*
- *The model performs well on English texts, **whereas** its results in Spanish are less reliable.*
- *We use containers **so that** every developer has the same environment.*
- *The service was slow **due to** inefficient database queries. **Therefore**, we added indexes.*
- *Python is easy to learn. **Moreover**, it has a huge ecosystem of libraries **such as** NumPy and pandas.*
- *We tried several approaches and **eventually** chose a microservices architecture.*

## Preguntas tipo examen

::: pregunta Choose the correct option: "___ the high cost, the company decided to migrate to the cloud."
- [ ] Although
- [x] Despite
- [ ] Despite of
- [ ] However
::: solucion Explicación
Después viene un **sustantivo** (*the high cost*), sin verbo: ***Despite***. ***Although*** necesita una oración (*Although the cost was high*). *Despite of* no existe: es *despite* o *in spite of*.
:::
:::

::: pregunta Choose the correct option: "___ the documentation was clear, many users had problems with the installation."
- [x] Even though
- [ ] In spite of
- [ ] Despite
- [ ] Because of
::: solucion Explicación
Después viene una **oración** completa (*the documentation was clear*): ***Even though*** (o *although*). *In spite of* y *Despite* necesitarían un sustantivo o *the fact that*. *Because of* no es contraste.
:::
:::

::: pregunta Choose the correct option: "The new laptop is very powerful. ___, it's too heavy to carry every day."
- [ ] Although
- [ ] Despite
- [x] However
- [ ] Whereas
::: solucion Explicación
Empieza una **oración nueva**, después de un punto y seguida de una coma: ***However***. *Although* y *whereas* unen dos partes de la misma oración, y *Despite* necesita un sustantivo.
:::
:::

::: pregunta Choose the correct option: "The flight was cancelled ___ a technical problem."
- [ ] because
- [x] due to
- [ ] since
- [ ] so
::: solucion Explicación
Después viene un **sustantivo** (*a technical problem*): ***due to*** (o *because of*). *because* y *since* necesitan una oración (*because there was a problem*). *so* indica consecuencia, no causa.
:::
:::

::: pregunta Choose the correct option: "We compressed the images ___ the website would load faster."
- [ ] in order to
- [ ] for
- [x] so that
- [ ] to
::: solucion Explicación
Después viene una **oración** con sujeto propio (*the website would load*): ***so that***. *in order to* y *to* necesitan la base del verbo (*to make the website load faster*). *for* no se usa así.
:::
:::

::: pregunta Choose the correct option: "We wrote extensive tests ___ introduce new bugs."
- [ ] in order to not
- [x] so as not to
- [ ] for not
- [ ] so that not
::: solucion Explicación
Finalidad negativa: ***so as not to*** o *in order not to* + base. El *not* va **antes** del *to*. *so that* necesitaría sujeto y verbo (*so that we wouldn't introduce*).
:::
:::

::: pregunta Choose the correct option: "Python is dynamically typed, ___ Java is statically typed."
- [ ] however
- [x] whereas
- [ ] despite
- [ ] therefore
::: solucion Explicación
Se **comparan dos cosas** opuestas en la misma oración: ***whereas*** (o *while*). *however* no puede unir dos oraciones con una coma sola; *despite* necesita un sustantivo; *therefore* indica consecuencia.
:::
:::

::: pregunta Choose the correct option: "In addition to ___ the backend, she is responsible for the CI/CD pipelines."
- [ ] develop
- [ ] to develop
- [x] developing
- [ ] developed
::: solucion Explicación
En ***in addition to***, *to* es una **preposición**: va ***-ing***. Lo mismo con *as well as* y *besides*.
:::
:::

::: pregunta Choose the correct option: "After weeks of negotiations, the client ___ agreed to sign the contract."
- [ ] actually
- [x] eventually
- [ ] currently
- [ ] possibly
::: solucion Explicación
***eventually*** = **finalmente**, después de mucho tiempo o esfuerzo (*after weeks of negotiations*). Es un falso amigo: no significa "eventualmente". *actually* = en realidad; *currently* = actualmente.
:::
:::

::: pregunta Choose the correct option: "I thought the meeting was at 10, but ___ it starts at 11."
- [ ] currently
- [ ] eventually
- [x] actually
- [ ] nowadays
::: solucion Explicación
***actually*** = **en realidad** (corrige lo que se pensaba). Es un falso amigo: "actualmente" es *currently* o *nowadays*.
:::
:::

::: pregunta Choose the correct option: "The tests failed. ___, we couldn't release the new version on Friday."
- [ ] Because
- [ ] Despite
- [x] As a result
- [ ] Although
::: solucion Explicación
La segunda oración es la **consecuencia** de la primera, y empieza una oración nueva: ***As a result*** (o *Therefore*, *Consequently*). *Because* indicaría causa, y *Despite* y *Although* indican contraste.
:::
:::

::: pregunta Which sentence is correct?
- [ ] Despite it was raining, the conference was full.
- [ ] Although the rain, the conference was full.
- [x] Despite the fact that it was raining, the conference was full.
- [ ] In spite it was raining, the conference was full.
::: solucion Explicación
***despite*** + oración solo funciona con ***the fact that***: *Despite the fact that it was raining*. La primera pone una oración directamente después de *despite*; la segunda, un sustantivo después de *although*; la cuarta usa *in spite* sin *of* y con una oración.
:::
:::

::: pregunta Choose the correct option: "Many cloud providers, ___ AWS, Azure and Google Cloud, offer free tiers."
- [ ] for example as
- [x] such as
- [ ] like as
- [ ] in other words
::: solucion Explicación
Para presentar una **lista de ejemplos** con sustantivos: ***such as***. *for example as* y *like as* mezclan dos expresiones. *in other words* reformula, no da ejemplos.
:::
:::

::: pregunta Choose the correct option: "AI assistants can not only generate code ___ explain how it works."
- [ ] and also
- [x] but also
- [ ] as well as
- [ ] moreover
::: solucion Explicación
***not only... but also*** es una estructura fija: *not only generate code **but also** explain it*. Las dos partes van en paralelo (dos verbos en base: *generate* y *explain*).
:::
:::
