# 4 · Pasados y hábitos

Esta unidad cubre las cuatro formas del pasado y cómo se combinan para **contar una historia**, por ejemplo un incidente en producción. Cierra con una de las trampas más famosas de los exámenes: ***used to*** contra ***be used to*** contra ***get used to***.

::: claves
- ***Past simple:*** acción terminada, con momento. Una secuencia de acciones: *I **opened** the logs, **found** the error and **fixed** it.*
- ***Past continuous*** (*was/were* + *-ing*): acción **en curso** en un momento del pasado, a menudo interrumpida. *I **was deploying** when the server **crashed**.*
- ***Past perfect*** (*had* + participio): el pasado **del pasado**. *When I arrived, the meeting **had** already **started**.*
- ***Past perfect continuous*** (*had been* + *-ing*): duración hasta un momento pasado.
- **Hábitos pasados:** *used to* + base (acciones y estados), *would* + base (**solo acciones**).
- ***used to do*** (antes hacía) ≠ ***be used to doing*** (estar acostumbrado) ≠ ***get used to doing*** (acostumbrarse).
- **Después de *did*:** *Did you **use to**...?* / *I **didn't use to**...*, sin *-d*.
:::

## *Past simple*

**Forma:** verbo en pasado (*-ed* o irregular, unidad 2). Preguntas y negaciones con ***did*** + base.

| Uso | Ejemplo |
|---|---|
| Acción terminada en un momento del pasado | *We **released** version 2.0 **last week**.* |
| **Secuencia** de acciones, una después de otra | *She **cloned** the repo, **ran** the tests and **opened** a pull request.* |
| Estado o hábito del pasado, ya terminado | *I **lived** in Rosario for five years.* |

## *Past continuous*

**Forma:** ***was/were*** + ***-ing***.

| Uso | Ejemplo |
|---|---|
| Acción **en curso** en un momento del pasado | *At 11 p.m. I **was** still **coding**.* |
| Acción larga **interrumpida** por una corta | *I **was deploying** when the server **crashed**.* |
| Dos acciones largas **en paralelo** | ***While** I **was writing** the code, she **was testing** the API.* |
| El **fondo** de una historia | *It **was raining**, and everyone **was working** from home.* |

### *when* y *while*

- ***while*** + acción **larga** (*continuous*): *While I **was reading** the logs, I **noticed** something strange.*
- ***when*** + acción **corta** (*simple*): *I was reading the logs **when** I **noticed** something strange.*

::: ojo
**Con *when*, el tiempo cambia el significado:**

| Oración | Qué pasó |
|---|---|
| *When the alarm went off, I **was sleeping**.* | Ya estaba durmiendo y la alarma me interrumpió. |
| *When the alarm went off, I **got up**.* | Primero la alarma, **después** me levanté (secuencia). |
:::

## *Past perfect*

**Forma:** ***had*** + **participio**, igual para todas las personas.

Sirve para dejar claro que algo pasó **antes** de otro momento del pasado. Es el "había hecho" del castellano.

```text
──────●──────────────●──────────────● ahora
   had started      I arrived
  (antes)          (punto de referencia en el pasado)
```

| Uso | Ejemplo |
|---|---|
| Acción anterior a otra pasada | *When I joined the call, they **had** already **made** the decision.* |
| Con *by the time* (para cuando) | ***By the time** we noticed the bug, it **had** already **affected** thousands of users.* |
| Explicar la **causa** de algo pasado | *The build failed because someone **had deleted** a dependency.* |
| Experiencia hasta un momento pasado | *I **had never used** Linux before I started this job.* |

::: ojo
**Cambia el significado:**

| Oración | Qué pasó |
|---|---|
| *When I arrived, the meeting **started**.* | Llegué y **entonces** empezó. |
| *When I arrived, the meeting **had started**.* | Ya había empezado cuando llegué. |

**No hace falta** si *before* o *after* ya marcan el orden: *After I **finished** the tests, I **pushed** the code* está bien.
:::

## *Past perfect continuous*

**Forma:** ***had been*** + ***-ing***.

- **Duración hasta un momento pasado:** *We **had been waiting** for an hour when the server finally came back.*
- **Causa visible en el pasado:** *She was tired because she **had been working** on the migration all night.*

Es el equivalente pasado del *present perfect continuous* (unidad 3): ***how long*** + actividad.

## Hábitos en el pasado: *used to* y *would*

| Forma | Para qué | Ejemplo |
|---|---|---|
| ***used to*** + base | Hábitos **y estados** pasados que **ya no** son así. | *I **used to work** in an office.* / *This laptop **used to be** fast.* |
| ***would*** + base | **Solo acciones** repetidas del pasado (no estados). Suele aparecer en relatos. | *Every Friday we **would order** pizza and **play** games.* |
| ***past simple*** | Sirve siempre, pero no marca el contraste con el presente. | *I **worked** in an office for two years.* |

::: ojo
- ***would*** **no sirve para estados:** *I would live in Rosario* ✗ → *I **used to live** in Rosario* ✓. *This laptop would be fast* ✗.
- ***used to*** **es solo pasado.** Para hábitos actuales se usa el *present simple* con *usually*: *I usually work from home*, nunca *I use to work*.
- **Con *did*, se pierde la *-d*:**
  - *I **didn't use to** like testing.* ✓
  - ***Did** you **use to** work there?* ✓
  - *I didn't used to* ✗ en un examen.
:::

## *used to* contra *be used to* contra *get used to*

Es la trampa clásica: las tres frases tienen *used to* y significan cosas distintas. La clave es **qué va después**.

| Frase | Significado | Qué va después | Ejemplo |
|---|---|---|---|
| ***used to*** | antes hacía (y ya no) | **base** del verbo | *I **used to work** in an office.* |
| ***be used to*** | estar acostumbrado | ***-ing*** o sustantivo | ***I'm used to working** remotely.* / *I'm used to **the noise**.* |
| ***get used to*** | acostumbrarse (proceso) | ***-ing*** o sustantivo | *It took me a month to **get used to working** with Linux.* |

¿Por qué *-ing*? En *be/get used to*, la palabra ***to*** es una **preposición** (como en "acostumbrado **a**"), y después de una preposición el verbo va con *-ing* (unidad 10).

***be used to*** y ***get used to*** se conjugan en cualquier tiempo:

- *I **wasn't used to** speaking English in meetings.* (pasado)
- ***You'll** soon **get used to** the new IDE.* (futuro)
- ***I've** finally **got used to** the time difference.* (*present perfect*)

::: ojo
- *I'm used to **work** remotely* ✗ → *I'm used to **working*** ✓.
- *I used to **working*** ✗ → *I used to **work*** ✓.
:::

## Los tiempos del relato: un *postmortem*

Un *postmortem* es el informe de un incidente. Fijate cómo cada tiempo cumple una función:

> *On Tuesday night, the payment service **went down** for two hours. At 10:15 p.m. the team **was running** a routine database migration when alerts **started** to fire. The on-call engineer **checked** the dashboards and **saw** that the database **had run out** of disk space. Logs **had been growing** uncontrollably for weeks, because someone **had disabled** log rotation during a previous release. While one engineer **was freeing** disk space, another **was updating** the status page. The service **came back** at 12:20 a.m. We **used to check** disk usage manually; now **we've set up** automatic alerts.*

::: solucion Ver la función de cada tiempo
| Forma | Tiempo | Función |
|---|---|---|
| *went down, started, checked, saw, came back* | *past simple* | La secuencia de hechos principales. |
| *was running*, *was freeing*, *was updating* | *past continuous* | Acciones en curso (fondo) y en paralelo. |
| *had run out*, *had disabled* | *past perfect* | Lo que ya había pasado antes del incidente. |
| *had been growing* | *past perfect continuous* | Duración hasta el momento del incidente. |
| *used to check* | *used to* | Hábito anterior que ya no existe. |
| *'ve set up* | *present perfect* | Resultado actual. |
:::

## Ejemplos en inglés técnico

- *I **was reviewing** your pull request when I **noticed** a security issue.*
- *By the time the hotfix **was** ready, the client **had** already **reported** the problem.*
- *Before the cloud, companies **used to buy** their own servers.*
- *Developers **would spend** hours searching for answers on forums; now they ask an AI assistant.*
- ***I'm** not **used to reading** such long stack traces, but **I'm getting used to** it.*
- *We **had been training** the model for three days when we **discovered** a bug in the data.*

## Preguntas tipo examen

::: pregunta Choose the correct option: "I ___ the new feature when the power went out."
- [ ] tested
- [x] was testing
- [ ] had tested
- [ ] have tested
::: solucion Explicación
Acción **larga en curso** (estaba probando) **interrumpida** por una corta (se cortó la luz): ***past continuous*** + *past simple*. *had tested* diría que ya había terminado de probar antes del corte.
:::
:::

::: pregunta Choose the correct option: "When I joined the meeting, they ___ the main topic, so I missed it."
- [ ] already discussed
- [ ] were already discussing
- [x] had already discussed
- [ ] have already discussed
::: solucion Explicación
Lo discutieron **antes** de que yo llegara (por eso me lo perdí): pasado del pasado, ***past perfect***. *were discussing* diría que lo estaban discutiendo cuando llegué, y entonces no me lo habría perdido.
:::
:::

::: pregunta Choose the correct option: "I ___ in an office, but now I work from home."
- [ ] use to work
- [x] used to work
- [ ] am used to work
- [ ] used to working
::: solucion Explicación
Hábito del pasado que **ya no** existe: ***used to*** + **base**. *use to* (sin *-d*) solo se usa después de *did*. *am used to* significa "estoy acostumbrado" y pide *-ing*. *used to working* mezcla las dos estructuras.
:::
:::

::: pregunta Choose the correct option: "After two years in Poland, she is used to ___ in English every day."
- [ ] speak
- [x] speaking
- [ ] spoke
- [ ] have spoken
::: solucion Explicación
***be used to*** = estar acostumbrado. Acá *to* es una **preposición**, así que va ***-ing***: *used to **speaking***. Es la trampa más común con *used to*.
:::
:::

::: pregunta Choose the correct option: "At first the new IDE was confusing, but I quickly ___ it."
- [ ] used to
- [x] got used to
- [ ] was using to
- [ ] am used to
::: solucion Explicación
***get used to*** = **acostumbrarse** (el proceso de cambio): *I quickly **got used to** it*. *used to it* no tiene sentido (necesitaría un verbo) y *am used to* está en presente y describe el estado, no el proceso.
:::
:::

::: pregunta Which sentence is NOT correct?
- [ ] When I was a student, I would study in the library every evening.
- [x] When I was a student, I would live near the university.
- [ ] When I was a student, I used to live near the university.
- [ ] When I was a student, I used to study in the library every evening.
::: solucion Explicación
***would*** solo sirve para **acciones** repetidas (estudiar todas las tardes), no para **estados** (vivir en un lugar). Para estados va ***used to***: *I used to live near the university*.
:::
:::

::: pregunta Choose the correct option: "___ you use to work with Java before you switched to Python?"
- [ ] Were
- [ ] Have
- [x] Did
- [ ] Used
::: solucion Explicación
*used to* se comporta como un verbo común en *past simple*: pregunta con ***did***, y después *use to* sin *-d*: ***Did** you **use to** work...?*
:::
:::

::: pregunta Choose the correct option: "By the time the support team responded, the client ___ for over an hour."
- [ ] waited
- [ ] was waiting
- [x] had been waiting
- [ ] has been waiting
::: solucion Explicación
**Duración** (*for over an hour*) hasta un momento del **pasado** (cuando respondió soporte): ***past perfect continuous***. *has been waiting* mide hasta **ahora**, no hasta un momento pasado.
:::
:::

::: pregunta Choose the correct option: "While she ___ the database, I was updating the documentation."
- [ ] backed up
- [x] was backing up
- [ ] had backed up
- [ ] backs up
::: solucion Explicación
Dos acciones largas **en paralelo** en el pasado, unidas por ***while***: las dos en ***past continuous***. La segunda ya está en *was updating*, que confirma el paralelo.
:::
:::

::: pregunta Choose the correct option: "She opened the terminal, ___ the script and checked the output."
- [ ] was running
- [x] ran
- [ ] had run
- [ ] has run
::: solucion Explicación
Es una **secuencia** de acciones, una después de otra: todas en ***past simple*** (*opened, ran, checked*). *run* es irregular: *run – ran – run*.
:::
:::

::: pregunta "When the manager arrived, the team had fixed the bug." What happened first?
- [ ] The manager arrived.
- [x] The team fixed the bug.
- [ ] Both things happened at the same time.
- [ ] It is impossible to know.
::: solucion Explicación
El ***past perfect*** (*had fixed*) marca la acción **anterior**: primero arreglaron el bug y después llegó el gerente. Con *When the manager arrived, the team fixed the bug* sería al revés: llegó y **entonces** lo arreglaron.
:::
:::

::: pregunta Choose the correct option: "I had never ___ a code review before I started working here."
- [ ] do
- [ ] did
- [x] done
- [ ] doing
::: solucion Explicación
*had* + **participio** (*past perfect*): ***done*** (*do – did – done*). *had did* es un error muy común: después de *have/has/had* va el participio, no el pasado.
:::
:::

::: pregunta Choose the correct option: "We didn't ___ automated tests, but now every project has them."
- [ ] used to have
- [x] use to have
- [ ] use to having
- [ ] used to having
::: solucion Explicación
Después de ***didn't*** va la base: ***use to*** (sin *-d*), y *used to* como hábito pasado va con la **base** del verbo: *have*. Las opciones con *-ing* confunden *used to* con *be used to*.
:::
:::
