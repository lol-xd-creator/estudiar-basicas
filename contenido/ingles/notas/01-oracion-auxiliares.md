# 1 · La oración: sujeto, auxiliares, pronombres y concordancia

Esta unidad es la base de todo lo demás. Explica cuatro cosas que hacés "a oído" y que el examen pregunta con trampa: por qué en inglés siempre hay sujeto, cómo se arman las preguntas y las negaciones, por qué el verbo a veces lleva **-s**, y cuándo va *I*, *me*, *my* o *mine*.

::: claves
- **El sujeto es obligatorio:** *it* y *there* aparecen donde en castellano no hay nada (*It is important*, *There are bugs*).
- **El orden es fijo:** sujeto + verbo + objeto. Los adjetivos van **antes** del sustantivo.
- **Los auxiliares** (*do*, *be*, *have*, *will*, *can*...) arman las preguntas, las negaciones y los *question tags*. Si la oración no tiene auxiliar, aparece **do/does/did**.
- **Después de *do/does/did* el verbo va en forma base:** *Does it **work**?*, nunca *Does it works?*
- **La -s de tercera persona** (*he/she/it works*) es casi el único cambio del verbo según el sujeto. Hay casos difíciles: *everyone*, *each of*, *the list of*, *the number of*.
- **Pronombres:** sujeto (*I*), objeto (*me*), posesivo (*my*, *mine*), reflexivo (*myself*). *His* o *her* según quién posee, no según la cosa.
- **Incontables:** *information, advice, feedback, software, research* no llevan *a* ni plural.
:::

## El sujeto nunca se omite

En castellano el verbo ya dice quién hace la acción ("funciona", "trabajamos"), así que el sujeto se puede omitir. En inglés el verbo casi no cambia, así que **el sujeto tiene que estar siempre**. Cuando no hay nadie que haga la acción, se pone un sujeto "vacío": ***it*** o ***there***.

| Castellano | Inglés | Por qué |
|---|---|---|
| Funciona. | ***It** works.* | Sujeto obligatorio. |
| Es importante testear. | ***It is** important to test.* | *It* anticipa lo que viene después. |
| Tarda cinco minutos en compilar. | ***It takes** five minutes to build.* | *It takes* + tiempo. |
| Parece que el servidor está caído. | ***It seems** that the server is down.* | *It seems / It looks like*. |
| Hay un bug. | ***There is** a bug.* | "Hay" = *there is / there are*. |
| Hay dos bugs. | ***There are** two bugs.* | *there are* con plural. |

::: ojo
- **"Hay" nunca es *have*:** *Have a problem* ✗ → ***There is** a problem* ✓.
- ***There is* contra *it is*:** *there* dice que algo **existe**; *it* habla de algo **ya mencionado**.
  - *There's a new release. **It** includes a faster model.*
- ***Is important*** ✗ → ***It is** important* ✓.
:::

## El orden: sujeto + verbo + objeto

En castellano podés decir "lo arregló Juan" o "Juan lo arregló". En inglés el orden es casi siempre **sujeto + verbo + objeto**, y lo que va después marca quién es quién.

> ***The model** **predicts** **the next word**.* — sujeto, verbo, objeto.

**Reglas de orden que el examen pregunta:**

- **El adjetivo va antes del sustantivo:** *a **large** language model*, nunca *a model large*.
- **Un sustantivo puede funcionar como adjetivo**, y entonces **no lleva plural:** *a **data** pipeline*, *a **user** interface*, *a **40-minute** test* (no *40-minutes*).
- **Nada se mete entre el verbo y su objeto:** *I speak **English** well* ✓, *I speak well English* ✗.
- **Lugar y tiempo van al final**, en ese orden: *I work **remotely from Córdoba every day***.
- **Los adverbios de frecuencia** (*always, usually, often, sometimes, never*):

| Dónde van | Ejemplo |
|---|---|
| **Antes** del verbo principal | *We **always** test our code.* |
| **Después** de *be* | *The build **is always** slow.* |
| **Entre** el auxiliar y el verbo | *I **have never** used Go.* |

## Los auxiliares: el motor del inglés

Un **auxiliar** es un verbo que acompaña al verbo principal para marcar tiempo, pregunta o negación. Son pocos:

| Auxiliar | Formas | Para qué |
|---|---|---|
| ***do*** | *do, does, did* | Preguntas y negaciones en *present simple* y *past simple*. |
| ***be*** | *am, is, are, was, were* | Formas *continuous* (*is running*) y pasiva (*is used*). |
| ***have*** | *have, has, had* | Formas *perfect* (*has finished*). |
| ***will*** | *will, would* | Futuro y condicional. |
| **modales** | *can, could, may, might, must, should* | Habilidad, permiso, obligación, deducción (unidad 6). |

**La regla de oro:** si la oración **ya tiene** un auxiliar, se usa ese. Si **no tiene** (el verbo está solo, en *present simple* o *past simple*), aparece ***do/does/did*** para hacer el trabajo.

### Preguntas: el auxiliar va antes del sujeto

| Afirmación | Pregunta | Qué pasó |
|---|---|---|
| *It **is** running.* | ***Is** it running?* | *is* pasa adelante. |
| *They **have** merged the branch.* | ***Have** they merged the branch?* | *have* pasa adelante. |
| *You **can** deploy today.* | ***Can** you deploy today?* | *can* pasa adelante. |
| *It **works**.* | ***Does** it **work**?* | No había auxiliar: aparece *does* y *works* pierde la *-s*. |
| *It **worked**.* | ***Did** it **work**?* | Aparece *did* y *worked* vuelve a la forma base. |

Con palabra interrogativa (*what, where, why, how, who*) el orden es el mismo: **palabra + auxiliar + sujeto + verbo**.

- *What **does** this function **return**?*
- *Where **do** you **work**?*
- *Why **is** the build **failing**?*

::: ojo
**Cuando la pregunta es por el sujeto, no hay *do*:**

- *Who **wrote** this code?* ✓ (*who* es el que escribió) — *Who did write this code?* ✗
- *What **happened**?* ✓ — *What did happen?* ✗
- Comparalo con una pregunta por el objeto: *What **did** you **change**?* (*you* es el sujeto, *what* es lo que cambiaste).
:::

### Negaciones: *not* va después del auxiliar

- *It **is not** (isn't) running.*
- *We **have not** (haven't) merged it.*
- *It **does not** (doesn't) **work**.*
- *It **did not** (didn't) **work**.*

::: ojo
**Después de *do/does/did*, el verbo va siempre en forma base**, sin *-s* y sin *-ed*. El auxiliar ya se llevó la información:

| Mal | Bien |
|---|---|
| *She doesn't **knows**.* | *She doesn't **know**.* |
| *It didn't **worked**.* | *It didn't **work**.* |
| *Does he **uses** Java?* | *Does he **use** Java?* |
| *She **don't** know.* | *She **doesn't** know.* |
:::

**Be como verbo principal** (ser/estar) es su propio auxiliar: *Are you ready?* ✓, *Do you are ready?* ✗. **Have** (tener) en cambio usa *do*: *Do you have access?* ✓ (en inglés británico también *Have you got access?*).

### Respuestas cortas y *question tags*

Para contestar "sí" o "no" se repite **el auxiliar**, no el verbo:

- *Does it work?* — *Yes, it **does**.* / *No, it **doesn't**.*
- *Have you pushed?* — *Yes, I **have**.* / *No, I **haven't**.*

Un ***question tag*** es la "¿no?" o "¿verdad?" del final. Se arma con **el mismo auxiliar** y **el signo contrario**:

| Oración | *Tag* | Regla |
|---|---|---|
| *It **works**,* | ***doesn't it**?* | Afirmativa → *tag* negativo; sin auxiliar → *do*. |
| *You **haven't** pushed,* | ***have you**?* | Negativa → *tag* afirmativo. |
| *She **can** code,* | ***can't she**?* | Mismo auxiliar. |
| *They **deployed** it,* | ***didn't they**?* | Pasado → *did*. |
| ***I'm** right,* | ***aren't I**?* | Excepción: *amn't* no existe. |
| ***Nobody** called,* | ***did they**?* | *Nobody* ya es negativo → *tag* afirmativo, con *they*. |
| *Let's start,* | ***shall we**?* | Fórmula fija. |

## Concordancia: cuándo el verbo cambia

En castellano el verbo cambia con cada persona (trabajo, trabajás, trabaja, trabajamos...). En inglés **casi no cambia**: en *present simple* solo agrega **-s** con *he, she, it* (tercera persona del singular).

| Sujeto | *work* | *be* | *have* | *do* |
|---|---|---|---|---|
| *I* | *work* | *am* | *have* | *do* |
| *you / we / they* | *work* | *are* | *have* | *do* |
| ***he / she / it*** | ***works*** | ***is*** | ***has*** | ***does*** |

En pasado no cambia nada (*I worked, she worked*), salvo *be*: *I/he/she/it **was***, *you/we/they **were***.

**Cómo se escribe la -s:**

- **-es** después de *s, sh, ch, x, o*: *fix**es**, push**es**, catch**es**, go**es**, do**es***.
- **consonante + y → -ies**: *try → tr**ies***, *copy → cop**ies***. Pero vocal + y queda: *deploy**s**, play**s***.

### Quién cuenta como "tercera persona del singular"

No solo *he, she, it*. Cualquier sujeto que **sea una sola cosa**:

- un sustantivo singular: *The server **crashes** every night.*
- un nombre: *EPAM **offers** a training program.*
- un gerundio: ***Writing** tests **takes** time.*
- un incontable: *The software **runs** on Linux.*

### Los casos difíciles

| Sujeto | Verbo | Por qué |
|---|---|---|
| *Everyone / Everybody / Nobody / Someone* | ***has*** *access.* | Son gramaticalmente singulares, aunque hablen de muchos. |
| *Each of the files* | ***is*** *encrypted.* | El núcleo es *each* (cada uno). |
| *Every test* | ***passes**.* | *every* + singular. |
| *One of the servers* | ***is*** *down.* | El núcleo es *one*, no *servers*. |
| *The list of users* | ***is*** *empty.* | El verbo concuerda con el **núcleo** (*list*), no con la palabra más cercana. |
| *The number of AI tools* | ***is*** *growing.* | *the number* = la cantidad (una). |
| *A number of users* | ***have*** *complained.* | *a number of* = varios (plural). |
| *Python and Java* | ***are*** *popular.* | Dos sujetos unidos por *and* = plural. |
| *Ten minutes* | ***is*** *enough.* | Una cantidad de tiempo o dinero se toma como una sola cosa. |
| *People* | ***are*** *using AI.* | *people* ya es plural (*persons* es muy formal). |
| *The news* | ***is*** *good.* | *news* es incontable, aunque termine en *s*. |
| *There* | ***is*** *a bug / **are** two bugs.* | Concuerda con lo que viene **después**. |

::: ojo
**El truco del sujeto largo:** tachá mentalmente todo lo que va después de *of*, *with* o *in*, y mirá qué queda.

- *The **results** of the test **are** ready.* → *The results are*.
- *The **quality** of the answers **depends** on the data.* → *The quality depends*.
:::

## Pronombres

| Sujeto | Objeto | Posesivo + sustantivo | Posesivo solo | Reflexivo |
|---|---|---|---|---|
| *I* | *me* | *my laptop* | *mine* | *myself* |
| *you* | *you* | *your laptop* | *yours* | *yourself* / *yourselves* |
| *he* | *him* | *his laptop* | *his* | *himself* |
| *she* | *her* | *her laptop* | *hers* | *herself* |
| *it* | *it* | *its interface* | — | *itself* |
| *we* | *us* | *our laptop* | *ours* | *ourselves* |
| *they* | *them* | *their laptop* | *theirs* | *themselves* |

**Las reglas que se preguntan:**

- **Sujeto antes del verbo, objeto después del verbo o de una preposición:**
  - ***My colleague and I*** *reviewed the code.* ✓ (*Me and my colleague reviewed* ✗ en un examen)
  - *The manager thanked **my colleague and me**.* ✓
  - *between you and **me*** ✓ (*between you and I* ✗).
  - **Truco:** sacá al otro. *I reviewed* ✓ / *Me reviewed* ✗; *thanked me* ✓ / *thanked I* ✗.
- **"Su" se traduce según quién posee:** *Ana fixed **her** bug*, *Juan fixed **his** bug*, *The company and **its** employees*, *The users and **their** data*. En castellano "su" sirve para todo; en inglés no.
- **Con un sujeto sin género** (*each user, someone, everyone*), se usa ***their*** (el *they* singular): *Every user can change **their** password.*
- **Posesivo + sustantivo contra posesivo solo:** *This is **my** laptop* / *This laptop is **mine***. *A friend **of mine***.
- **Reflexivo** cuando el sujeto y el objeto son el mismo: *The system updates **itself***. Si son dos que se hacen algo mutuamente, ***each other***: *The services talk to **each other*** (no *themselves*).

::: ojo
**Palabras que suenan igual y el examen confunde:**

| Forma | Qué es | Ejemplo |
|---|---|---|
| ***its*** | posesivo de *it* | *The model and **its** parameters.* |
| ***it's*** | *it is* / *it has* | ***It's** running. **It's** been fixed.* |
| ***their*** | posesivo de *they* | ***their** code* |
| ***they're*** | *they are* | ***They're** online.* |
| ***there*** | "allí" / "hay" | ***There** are three bugs.* |
| ***whose*** | de quién | ***Whose** laptop is this?* |
| ***who's*** | *who is* / *who has* | ***Who's** on call tonight?* |
| ***your*** | posesivo de *you* | ***your** account* |
| ***you're*** | *you are* | ***You're** right.* |
:::

## Contables e incontables

Un sustantivo **contable** se puede contar: *a bug, two bugs*. Uno **incontable** es una masa: no lleva *a/an* ni plural, y el verbo va en singular.

| Incontables frecuentes en el trabajo | Cómo "contarlos" |
|---|---|
| *information* | *a piece of information* |
| *advice* (consejo) | *a piece of advice*, *some advice* |
| *feedback* | *some feedback* |
| *research* (investigación) | *a study*, *some research* |
| *software*, *hardware*, *equipment* | *a program*, *a tool*, *a device* |
| *code* | *a line of code*, *a snippet* |
| *work* (trabajo como actividad) | *a job*, *a task* |
| *knowledge*, *progress*, *documentation*, *evidence* | — |
| *news* | *a piece of news* |

::: ojo
**Errores típicos de hispanohablante:** *informations*, *an advice*, *advices*, *feedbacks*, *researches*, *softwares*, *a work*. En castellano decís "consejos" o "informaciones" en plural; en inglés, nunca.

***data*** en textos técnicos se usa casi siempre como incontable (*the data **is** ready*); en textos académicos a veces como plural (*the data **are***). Por eso un buen examen no lo pregunta.
:::

## Ejemplos en inglés técnico

Fijate en los auxiliares y en la concordancia:

- *The API **returns** a JSON object. **Does** it **return** errors in the same format?*
- *There **are** three open pull requests, but nobody **has** reviewed them yet.*
- *Each of the models **has** its own configuration file.*
- *It **takes** about two hours to train the model on a single GPU.*
- *The team **doesn't** use Java anymore, **does** it?*
- *Who **broke** the build? — I **did**. Sorry!*
- *Large language models **don't** understand text the way people **do**.*

## Preguntas tipo examen

::: pregunta Choose the correct option: "___ important to back up the database every day."
- [ ] Is
- [x] It's
- [ ] There is
- [ ] Has
::: solucion Explicación
En inglés el sujeto es obligatorio. "Es importante..." necesita un sujeto vacío: ***It's** (It is) important to...* *Is important* es el error del hispanohablante que traduce palabra por palabra. *There is* dice que algo existe ("hay"), y *Has* no tiene sentido acá.
:::
:::

::: pregunta Choose the correct option: "___ several bugs in the latest release."
- [ ] There is
- [ ] It has
- [x] There are
- [ ] They have
::: solucion Explicación
"Hay" es ***there is / there are***, y concuerda con lo que viene después: *several bugs* es plural, así que va ***There are***. *It has* y *They have* traducen "hay" con *have*, que en inglés es "tener".
:::
:::

::: pregunta Choose the correct option: "___ the new feature work on mobile devices?"
- [ ] Is
- [ ] Do
- [x] Does
- [ ] Has
::: solucion Explicación
El verbo principal es *work*, solo, en *present simple*: no hay auxiliar, así que aparece ***do/does***. El sujeto *the new feature* es tercera persona del singular (*it*), así que va ***Does***. *Is* serviría para *Is the new feature working?*, con *-ing*.
:::
:::

::: pregunta Which sentence is grammatically correct?
- [ ] She doesn't knows the answer.
- [ ] She don't know the answer.
- [x] She doesn't know the answer.
- [ ] She not know the answer.
::: solucion Explicación
Con *she* va ***does*** (tercera persona), y después de *does* el verbo va en forma base: ***know***, sin *-s*. La primera pone la *-s* dos veces; la segunda usa *don't* con *she*; la cuarta no tiene auxiliar.
:::
:::

::: pregunta Choose the correct option: "Who ___ this function? It's really clean."
- [ ] did write
- [x] wrote
- [ ] did wrote
- [ ] has wrote
::: solucion Explicación
*Who* es el **sujeto** (el que escribió), y cuando la pregunta es por el sujeto **no se usa *do***: ***Who wrote...?*** *did wrote* tiene dos pasados, y *has wrote* usa mal el participio (sería *has written*).
:::
:::

::: pregunta Choose the correct option: "Each of the microservices ___ its own database."
- [ ] have
- [x] has
- [ ] are having
- [ ] have got
::: solucion Explicación
El núcleo del sujeto es ***each*** (cada uno), que es singular: ***has***. *microservices* está en plural, pero va después de *of* y no manda sobre el verbo. Además, *its* (y no *their*) confirma que se habla de uno por vez.
:::
:::

::: pregunta Choose the correct option: "The information you requested ___ in the attached file."
- [ ] are
- [x] is
- [ ] were
- [ ] have been
::: solucion Explicación
***information*** es **incontable**: no tiene plural y el verbo va en singular, ***is***. En castellano decís "las informaciones", pero en inglés nunca.
:::
:::

::: pregunta Choose the correct option: "Can you give me some ___ about my presentation?"
- [ ] advices
- [ ] feedbacks
- [x] advice
- [ ] an advice
::: solucion Explicación
***advice*** es incontable: no lleva *-s* ni *an*. Se dice *some advice* o *a piece of advice*. *feedbacks* tiene el mismo error: sería *some feedback*.
:::
:::

::: pregunta Choose the correct option: "The list of failed tests ___ longer every day."
- [ ] get
- [ ] are getting
- [x] is getting
- [ ] have got
::: solucion Explicación
El núcleo del sujeto es ***list*** (una lista), no *tests*. Tachá lo que va después de *of*: *The list is getting longer*. Las opciones en plural caen en la trampa de concordar con la palabra más cercana.
:::
:::

::: pregunta Choose the correct option: "My manager and ___ reviewed the pull request together."
- [ ] me
- [x] I
- [ ] myself
- [ ] mine
::: solucion Explicación
Va antes del verbo, así que es **sujeto**: ***I***. Truco: sacá al otro. *I reviewed* ✓, *Me reviewed* ✗. *myself* es reflexivo (cuando sujeto y objeto son el mismo) y *mine* es posesivo ("mío").
:::
:::

::: pregunta Choose the correct option: "Every user can change ___ password in the settings."
- [ ] its
- [ ] it's
- [x] their
- [ ] there
::: solucion Explicación
Con un sujeto de persona sin género (*every user, someone, each employee*) se usa ***their***, el *they* singular. *its* es para cosas, no para personas; *it's* es *it is*; *there* es "allí" o "hay".
:::
:::

::: pregunta Choose the correct option: "The service restarts ___ automatically after a crash."
- [x] itself
- [ ] himself
- [ ] it
- [ ] its
::: solucion Explicación
El servicio se reinicia **a sí mismo**: el sujeto y el objeto son la misma cosa, así que va el reflexivo de *it*, ***itself***. *himself* es para un hombre; *it* sería otra cosa distinta del servicio; *its* es posesivo.
:::
:::

::: pregunta Choose the correct question tag: "You haven't pushed your changes yet, ___?"
- [ ] haven't you
- [x] have you
- [ ] did you
- [ ] don't you
::: solucion Explicación
El *tag* repite **el mismo auxiliar** (*have*) con **el signo contrario**: la oración es negativa (*haven't*), así que el *tag* es afirmativo, ***have you?*** *did* y *do* no sirven porque la oración ya tiene auxiliar.
:::
:::

::: pregunta Which sentence has the correct word order?
- [ ] We test always our code before merging.
- [x] We always test our code before merging.
- [ ] Always we are test our code before merging.
- [ ] We test our code before always merging.
::: solucion Explicación
Los adverbios de frecuencia van **antes del verbo principal**: *We **always** test*. Si hubiera *be* o un auxiliar, irían después de él (*It is always slow*, *I have never used Go*). La primera mete el adverbio entre el verbo y el objeto, algo que el inglés no permite.
:::
:::

::: pregunta Choose the correct option: "The number of companies using AI ___ growing every year, and a number of them ___ already replaced some manual processes."
- [ ] are / has
- [x] is / have
- [ ] is / has
- [ ] are / have
::: solucion Explicación
- ***The number of*** = "la cantidad de": una sola cosa, singular → ***is***.
- ***A number of*** = "varios": plural → ***have***.

Es un clásico porque las dos frases se parecen y el verbo va al revés en cada una.
:::
:::
