# Cambio de variables en integrales triples

Para simplificar el cálculo de una integral triple $\iiint_D f(x;y;z)\,\dx\,\dy\,\dz$ se usan las conclusiones vistas para el [[Cambio de variables en integrales múltiples]] de las integrales dobles, con una transformación de características similares.

::: claves
- **Fórmula general**: con $(x;y;z) = \mathbf T(u;v;w)$ biunívoca y de derivadas parciales continuas, $\dx\,\dy\,\dz = \left|J\!\left(\frac{x\,y\,z}{u\,v\,w}\right)\right|\du\,\dd v\,\dd w$. Ver [[1. Transformación y fórmula general]].
- **Coordenadas cilíndricas**: polares en un plano y la tercera variable igual a sí misma; $|J| = r$. Se usan cuando la proyección de $D$ sobre ese plano pide polares (un eje de simetría). Ver [[2. Coordenadas cilíndricas]].
- **Coordenadas esféricas**: $x = \rho\cos\theta\sen\varphi$, $y = \rho\sen\theta\sen\varphi$, $z = \rho\cos\varphi$; $|J| = \rho^2\sen\varphi$. Ver [[3. Coordenadas esféricas]].
:::
