# 05/10 · EDO lineales de 1.er orden

*Clase práctica del 05/10. La teoría está en [[4. Ecuaciones lineales y de Bernoulli]].*

::: claves
- **Forma:**
  $$\frac{\dy}{\dx} + P(x)\,y = Q(x)$$
  con $P(x)$ y $Q(x)$ funciones de $x$ o constantes. Si $y'$ tiene un coeficiente, **se divide toda la ecuación** por él. Si viene como $M\,\dx + N\,\dy = 0$, se despeja $\frac{\dy}{\dx}$ primero.
- **Identificar $P$ y $Q$ con su signo:** en $y' - \frac{2}{x + 1}\,y = \dots$, es $P = -\frac{2}{x + 1}$.
- **Solución general:**
  $$y = v\,[u + C] \qquad v = e^{-\int P(x)\,\dx} \qquad u = \int Q(x)\,e^{\int P(x)\,\dx}\,\dx$$
  (en $u$ el exponente va **sin** el signo menos; es lo mismo que $u = \int \frac{Q}{v}\,\dx$).
- **Exponencial y logaritmo:** $e^{\ln f} = f$ y $e^{k\ln f} = f^k$. Por ejemplo, $e^{2\ln(x + 1)} = (x + 1)^2$ y $e^{-\ln x} = x^{-1}$.
- **ILATE** para integrar por partes, $\int u\,\dd v = u\,v - \int v\,\dd u$: se elige como $u$ la función que aparece **primero** en la lista **I**nversas trigonométricas, **L**ogarítmicas, **A**lgebraicas, **T**rigonométricas, **E**xponenciales. El resto es $\dd v$.
:::

## Ejercicio 1

::: ejercicio Resolver $(x + 1)\,y' - 2y = (x + 1)^4$
::: solucion
**Forma lineal**, dividiendo por $(x + 1)$:

$$
\frac{\dy}{\dx} \underbrace{- \frac{2}{x + 1}}_{P(x)}\,y = \underbrace{(x + 1)^3}_{Q(x)}
$$

**$v$:**

::: pasos
v = e^{-\int -\frac{2}{x + 1}\,\dx} = e^{2\int \frac{\dx}{x + 1}} = e^{2\ln(x + 1)} = e^{\ln(x + 1)^2} = (x + 1)^2
:::

**$u$:**

::: pasos
u = \int (x + 1)^3\,e^{\int -\frac{2}{x + 1}\,\dx}\,\dx = \int (x + 1)^3\,e^{\ln(x + 1)^{-2}}\,\dx
= \int (x + 1)^3\,(x + 1)^{-2}\,\dx = \int (x + 1)\,\dx = \frac{x^2}{2} + x
:::

::: resultado
$$
y = (x + 1)^2\left[\frac{x^2}{2} + x + C\right]
$$
:::
:::
:::

## Ejercicio 2

::: ejercicio Resolver $\dfrac{y + \ln x}{x^2}\,\dx - \dfrac{1}{x}\,\dy = 0$
::: solucion
**Forma lineal:** pasando el $\dy$ y multiplicando por $x$:

::: pasos
\frac{y + \ln x}{x^2}\,\dx = \frac{1}{x}\,\dy \then \frac{y + \ln x}{x} = \frac{\dy}{\dx}
\frac{\dy}{\dx} - \frac{1}{x}\,y = \frac{\ln x}{x}        // $P = -\frac{1}{x}$, $Q = \frac{\ln x}{x}$
:::

**$v$:** $v = e^{-\int -\frac{1}{x}\,\dx} = e^{\ln x} = x$.

**$u$:**

$$
u = \int \frac{\ln x}{x}\,e^{\int -\frac{1}{x}\,\dx}\,\dx = \int \frac{\ln x}{x}\,e^{-\ln x}\,\dx = \int \frac{\ln x}{x}\cdot x^{-1}\,\dx = \int \ln x\cdot x^{-2}\,\dx
$$

**Por partes** (ILATE: el logaritmo va primero): $u_p = \ln x \then \dd u_p = \frac{1}{x}\,\dx$; $\dd v_p = x^{-2}\,\dx \then v_p = -x^{-1}$.

::: pasos
\int \ln x\cdot x^{-2}\,\dx = \ln x\,(-x^{-1}) - \int -x^{-1}\cdot\frac{1}{x}\,\dx = -\frac{\ln x}{x} + \int x^{-2}\,\dx = -\frac{\ln x}{x} - \frac{1}{x}
:::

::: resultado
$$
y = x\left[-\frac{\ln x}{x} - \frac{1}{x} + C\right] = -\ln x - 1 + C\,x
$$
:::

:::

## Ejercicio 3

::: ejercicio Resolver $(1 - x^2)\,y' - x\,y = 1$
::: solucion
**Forma lineal**, dividiendo por $(1 - x^2)$:

$$
\frac{\dy}{\dx} \underbrace{- \frac{x}{1 - x^2}}_{P(x)}\,y = \underbrace{\frac{1}{1 - x^2}}_{Q(x)}
$$

**Cálculo auxiliar** (sustitución $t = 1 - x^2$, $\dd t = -2x\,\dx$):

$$
\int \frac{x}{1 - x^2}\,\dx = -\frac{1}{2}\int \frac{\dd t}{t} = -\frac{1}{2}\ln(1 - x^2)
$$

**$v$:**

::: pasos
v = e^{-\int -\frac{x}{1 - x^2}\,\dx} = e^{\int \frac{x}{1 - x^2}\,\dx} = e^{-\frac{1}{2}\ln(1 - x^2)} = (1 - x^2)^{-1/2}
:::

**$u$:**

::: pasos
u = \int \frac{1}{1 - x^2}\,e^{\frac{1}{2}\ln(1 - x^2)}\,\dx = \int (1 - x^2)^{-1}\,(1 - x^2)^{1/2}\,\dx
= \int \frac{\dx}{\sqrt{1 - x^2}} = \arcsen x        // integral de tabla
:::

::: resultado
$$
y = \frac{1}{\sqrt{1 - x^2}}\,\big[\arcsen x + C\big]
$$
:::

::: aclaracion
En la carpeta quedó $\arccos x$, pero $\int \frac{\dx}{\sqrt{1 - x^2}} = \arcsen x$ (la derivada de $\arccos x$ es $-\frac{1}{\sqrt{1 - x^2}}$, con signo menos).
:::
