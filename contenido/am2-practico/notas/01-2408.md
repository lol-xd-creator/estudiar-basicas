# 24/08 · Integrales dobles: iteradas y áreas

*Clase práctica del 24/08. La teoría está en [[Integrales dobles]] ([[2. Integrales iteradas]], [[3. Dominios generales]] y [[5. Área y volumen]]).*

::: claves
- **Integral iterada:** se resuelve **de adentro hacia afuera**. En la de adentro, la otra variable es **constante**.
- **Orden $\dy\,\dx$:** los límites de $y$ (adentro) pueden depender de $x$; los de $x$ (afuera) son **números**.
- **Barrow:** primitiva evaluada en el límite de arriba **menos** evaluada en el de abajo.
- **Área:** $A = \displaystyle\iint_D \dx\,\dy$ (el integrando es $1$). Se expresa en **u.a.** (unidades de área). Si adentro hay una función $f \ne 1$, lo que se calcula es un **volumen**.
- **Piso y techo:** en $\dy\,\dx$, $y$ va de la curva de **abajo** (piso) a la de **arriba** (techo); $x$, entre los **puntos de corte**. Los cortes salen de **igualar** las curvas.
- **Si el piso o el techo cambian** en el medio de la región, se **parte** la integral en dos (en el punto donde cambian).
- **Truco:** si la integral de adentro es difícil, se puede **cambiar el orden** (ejercicio 4).
:::

## Ejercicio 1

::: ejercicio Calcular $\displaystyle\int_1^4\!\int_1^3 x\,y\,\dy\,\dx$
::: solucion
Primero en $y$ ($x$ es constante):

::: pasos
\int_1^4 x\,\eval{\frac{y^2}{2}}{1}{3}\,\dx = \int_1^4 x\left(\frac{9}{2} - \frac{1}{2}\right)\dx
= \int_1^4 4x\,\dx = 2x^2\,\Big|_1^4 = 2\,(16 - 1)
:::

::: resultado
$$
\int_1^4\!\int_1^3 x\,y\,\dy\,\dx = 30
$$
:::

## Ejercicio 2

::: ejercicio Calcular con una integral doble el área del rectángulo $0 \le x \le 1$, $0 \le y \le 2$
::: solucion
```grafico
0 <= x <= 1, 0 <= y <= 2 ; "$D$"
x: -0.5..2
y: -0.5..2.5
```

::: pasos
A = \int_0^1\!\int_0^2 \dy\,\dx = \int_0^1 y\,\Big|_0^2\,\dx = \int_0^1 2\,\dx = 2x\,\Big|_0^1
:::

::: resultado
$$
A = 2\ \text{u.a.}
$$
:::

Es base por altura, $1 \cdot 2$: sirve para controlar.
:::
:::

## Ejercicio 3

::: ejercicio Calcular $\displaystyle\int_0^1\!\int_0^2 (x + y)\,\dy\,\dx$
::: solucion
::: pasos
\int_0^1 \left(x\,y + \frac{y^2}{2}\right)\Big|_0^2\,\dx = \int_0^1 \left[x\,(2 - 0) + \left(\frac{4}{2} - 0\right)\right]\dx
= \int_0^1 (2x + 2)\,\dx = \left(x^2 + 2x\right)\Big|_0^1 = (1 + 2) - 0
:::

::: resultado
$$
\int_0^1\!\int_0^2 (x + y)\,\dy\,\dx = 3
$$
:::

## Ejercicio 4

::: ejercicio Calcular $\displaystyle\int_0^2\!\int_0^{\sqrt{4 - y^2}} \frac{2}{\sqrt{4 - y^2}}\,\dx\,\dy$
::: solucion
La región es un cuarto del círculo de radio $2$: $x$ va de $0$ a $\sqrt{4 - y^2}$, la mitad derecha de $x^2 + y^2 = 4$.

```grafico
0 <= x <= raiz(4 - y^2), 0 <= y <= 2 ; "$D$"
x^2 + y^2 = 4 ; gris ; punteada ; ""
x: -0.5..2.6
y: -0.5..2.6
```

::: tip
El integrando **no depende de $x$**, así que conviene dejar $\dx$ adentro: la primera integral es inmediata. En el otro orden ($\dy$ adentro) hay que integrar $\frac{2}{\sqrt{4 - y^2}}$ respecto de $y$, que es más difícil (en la carpeta quedó tachado).
:::

::: pasos
\int_0^2 \frac{2}{\sqrt{4 - y^2}}\;x\,\Big|_0^{\sqrt{4 - y^2}}\,\dy = \int_0^2 \frac{2}{\sqrt{4 - y^2}}\left(\sqrt{4 - y^2} - 0\right)\dy
= \int_0^2 2\,\dy = 2y\,\Big|_0^2 = 2\,(2 - 0)        // las raíces se simplifican
:::

::: resultado
$$
\int_0^2\!\int_0^{\sqrt{4 - y^2}} \frac{2}{\sqrt{4 - y^2}}\,\dx\,\dy = 4
$$
:::
:::
:::

## Ejercicios 5 y 6: áreas de rectángulos

::: ejercicio Calcular con integrales dobles el área de los rectángulos **a)** $0 \le x \le 8$, $0 \le y \le 3$ y **b)** $1 \le x \le 3$, $1 \le y \le 3$
::: solucion
```grafico
0 <= x <= 8, 0 <= y <= 3 ; "a)"
1 <= x <= 3, 1 <= y <= 3 ; "b)" ; rayado
x: -0.5..8.5
y: -0.5..3.5
aspecto: libre
alto: 200
```

**a)** Con $\dx$ adentro:

::: pasos
A = \int_0^3\!\int_0^8 \dx\,\dy = \int_0^3 x\,\Big|_0^8\,\dy = \int_0^3 8\,\dy = 8y\,\Big|_0^3 = 24
:::

**b)**

::: pasos
A = \int_1^3\!\int_1^3 \dx\,\dy = \int_1^3 (3 - 1)\,\dy = 2y\,\Big|_1^3 = 2\,(3 - 1) = 4
:::

::: resultado
$$
\text{a)}\ A = 24\ \text{u.a.} \qquad \text{b)}\ A = 4\ \text{u.a.}
$$
:::
:::
:::

## Ejercicio 7

::: ejercicio Calcular el área bajo la curva $y = \dfrac{1}{\sqrt{x - 1}}$, sobre el eje $x$, entre $x = 2$ y $x = 5$
::: solucion
**Techo:** la curva; **piso:** $y = 0$.

```grafico
2 <= x <= 5, 0 <= y <= 1/raiz(x - 1) ; "$D$"
y = 1/raiz(x - 1) ; x: 1.08..6 ; azul ; "$y = \frac{1}{\sqrt{x - 1}}$"
x: 0..6
y: -0.3..3
```

::: pasos
A = \int_2^5\!\int_0^{1/\sqrt{x - 1}} \dy\,\dx = \int_2^5 \left(\frac{1}{\sqrt{x - 1}} - 0\right)\dx
:::

**Cálculo auxiliar** (sustitución $t = x - 1$, $\dd t = \dx$; los límites pasan a $t = 1$ y $t = 4$):

::: pasos
\int \frac{\dd t}{\sqrt t} = \int t^{-1/2}\,\dd t = \frac{t^{1/2}}{1/2} = 2\sqrt t = 2\sqrt{x - 1}
\int_2^5 \frac{\dx}{\sqrt{x - 1}} = 2\sqrt{x - 1}\,\Big|_2^5 = 2\left(\sqrt 4 - \sqrt 1\right) = 2\,(2 - 1)
:::

::: resultado
$$
A = 2\ \text{u.a.}
$$
:::
:::
:::

## Ejercicio 8

::: ejercicio Calcular el área de la región comprendida entre $y = x$ y $y = -x^2 + 4x$
::: solucion
**Cortes:** $x = -x^2 + 4x \then x^2 - 3x = 0 \then x = 0$ y $x = 3$. Entre ellos, la parábola está arriba (techo) y la recta abajo (piso).

```grafico
x <= y <= -x^2 + 4x, 0 <= x <= 3 ; "$D$"
y = -x^2 + 4x ; azul ; "$y = -x^2 + 4x$"
y = x ; rojo ; "$y = x$"
x: -0.5..4.5
y: -0.5..4.5
```

::: pasos
A = \int_0^3\!\int_x^{-x^2 + 4x} \dy\,\dx = \int_0^3 \left(-x^2 + 4x - x\right)\dx = \int_0^3 \left(-x^2 + 3x\right)\dx
= \left(-\frac{x^3}{3} + \frac{3x^2}{2}\right)\Big|_0^3 = -9 + \frac{27}{2}
:::

::: resultado
$$
A = \frac{9}{2} = 4{,}5\ \text{u.a.}
$$
:::
:::
:::

## Ejercicio 9: cambia el techo

::: ejercicio Calcular el área de la región limitada por $y = x^2 + 2x - 2$, $y = 2x + 7$ y $y = -2x + 3$
::: solucion
**Cortes:**

- las dos rectas: $2x + 7 = -2x + 3 \then x = -1$ (punto $(-1;5)$);
- parábola y $y = 2x + 7$: $x^2 + 2x - 2 = 2x + 7 \then x^2 = 9 \then x = -3$;
- parábola y $y = -2x + 3$: $x^2 + 4x - 5 = 0 \then x = 1$ (la otra raíz, $-5$, queda fuera).

El **piso** es siempre la parábola, pero el **techo cambia** en $x = -1$: a la izquierda es $y = 2x + 7$ y a la derecha $y = -2x + 3$. Se parte en dos integrales.

```grafico
x^2 + 2x - 2 <= y <= min(2x + 7, -2x + 3), -3 <= x <= 1 ; "$D$"
y = x^2 + 2x - 2 ; azul ; "$y = x^2 + 2x - 2$"
y = 2x + 7 ; rojo ; "$y = 2x + 7$"
y = -2x + 3 ; violeta ; "$y = -2x + 3$"
segmento (-1, -3) (-1, 5) ; gris ; punteada
x: -4..2
y: -3.5..6
```

::: pasos
A = \int_{-3}^{-1}\!\int_{x^2 + 2x - 2}^{2x + 7} \dy\,\dx + \int_{-1}^{1}\!\int_{x^2 + 2x - 2}^{-2x + 3} \dy\,\dx
= \int_{-3}^{-1} \left(9 - x^2\right)\dx + \int_{-1}^{1} \left(5 - 4x - x^2\right)\dx
= \left(9x - \frac{x^3}{3}\right)\Big|_{-3}^{-1} + \left(5x - 2x^2 - \frac{x^3}{3}\right)\Big|_{-1}^{1}
= \left[\left(-9 + \frac{1}{3}\right) - (-27 + 9)\right] + \left[\frac{8}{3} - \left(-\frac{20}{3}\right)\right] = \frac{28}{3} + \frac{28}{3}
:::

::: resultado
$$
A = \frac{56}{3}\ \text{u.a.}
$$
:::
