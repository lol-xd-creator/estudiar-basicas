# 14/09 · Integrales curvilíneas

*Clase práctica del 14/09. La teoría está en [[Integral curvilínea (1.ª parte)]] ([[3. Cálculo de una integral de línea]] y [[4. Área plana con integral curvilínea]]).*

::: claves
- **Integral curvilínea** de $A$ a $B$ a lo largo de la curva $L$:
  $$\int_L P(x;y)\,\dx + Q(x;y)\,\dy$$
- **Propiedades:**
  - si se invierte el sentido, **cambia el signo**: $\int_A^B = -\int_B^A$;
  - se puede **partir el camino** en un punto intermedio $C$: $\int_A^B = \int_A^C + \int_C^B$.
- **Pasos para calcularla:**
  1. **Curva:** escribir la ecuación de $L$ ($y = f(x)$, $x = g(y)$ o paramétrica).
  2. **Derivar:** $\dy = f'(x)\,\dx$ (o $\dx = g'(y)\,\dy$, o $\dx = x'(t)\,\dd t$ y $\dy = y'(t)\,\dd t$).
  3. **Sustituir** todo en la integral: queda una integral **simple** en una sola variable, con los límites de **esa** variable (las coordenadas de $A$ y $B$, o los valores de $t$).
- **Truco:** si la curva viene como $x = g(y)$, conviene pasar todo a $y$.
- **Área de una región limitada por una curva cerrada** (recorrida en sentido **antihorario**):
  $$A = \frac{1}{2}\oint_L (-y)\,\dx + x\,\dy$$
  con **una integral por cada tramo** de la curva.
:::

## Ejercicio 1

::: ejercicio Calcular la integral curvilínea $\displaystyle\int_{(0;0)}^{(1;1)} (x + y^2)\,\dx + 2xy\,\dy$ a lo largo de la parábola $y = x^2$
::: solucion
```grafico
(t, t^2) ; t: 0..1 ; azul ; gruesa ; flecha ; "$y = x^2$"
(0, 0) ; "$A$"
(1, 1) ; "$B$"
x: -0.3..1.5
y: -0.3..1.5
```

1. **Curva:** $y = x^2$, con $x$ de $0$ a $1$.
2. **Derivo:** $\dy = 2x\,\dx$.
3. **Sustituyo:**

::: pasos
\int_0^1 \left(x + (x^2)^2\right)\dx + 2x\,x^2\,(2x\,\dx) = \int_0^1 \left(x + x^4 + 4x^4\right)\dx
= \int_0^1 \left(5x^4 + x\right)\dx = \left(x^5 + \frac{x^2}{2}\right)\Big|_0^1 = 1 + \frac{1}{2}
:::

::: resultado
$$
\int_L (x + y^2)\,\dx + 2xy\,\dy = \frac{3}{2}
$$
:::
:::
:::

## Ejercicio 2

::: ejercicio Calcular $\displaystyle\int_L y\,\dx + x\,\dy$, siendo $L$ el arco de la parábola $x = 9 - y^2$ desde $(0;3)$ hasta $(5;2)$
::: solucion
```grafico
(9 - (5 - t)^2, 5 - t) ; t: 2..3 ; azul ; gruesa ; flecha ; "$x = 9 - y^2$"
x = 9 - y^2 ; gris ; punteada ; ""
(0, 3) ; "$(0;3)$"
(5, 2) ; "$(5;2)$"
x: -1..10
y: -0.5..4
```

La curva está como $x = g(y)$: se pasa todo a $y$, que va de $3$ a $2$ (de $A$ a $B$, aunque baje).

**Derivo:** $\dx = -2y\,\dy$.

::: pasos
\int_3^2 y\,(-2y\,\dy) + (9 - y^2)\,\dy = \int_3^2 \left(-3y^2 + 9\right)\dy
= \left(-y^3 + 9y\right)\Big|_3^2 = (-8 + 18) - (-27 + 27)
:::

::: resultado
$$
\int_L y\,\dx + x\,\dy = 10
$$
:::

::: tip
$y\,\dx + x\,\dy$ es la diferencial de $x\,y$, así que la integral solo depende de los extremos ([[2. Independencia del camino]]): $x\,y\,\big|_{(0;3)}^{(5;2)} = 10 - 0 = 10$. Sirve para controlar.
:::
:::
:::

## Ejercicio 3: segmento en paramétricas

::: ejercicio Calcular $\displaystyle\int_L y\,\dx + x^2\,\dy$, siendo $L$ el segmento de recta $x = t + 2$, $y = 6t$, con $0 \le t \le 1$
::: solucion
```grafico
(t + 2, 6t) ; t: 0..1 ; azul ; gruesa ; flecha ; ""
(2, 0) ; "$t = 0$"
(3, 6) ; "$t = 1$"
x: 0..4
y: -0.5..7
```

**Derivo la curva:** $\dx = \dd t$, $\dy = 6\,\dd t$. **Sustituyo** $x = t + 2$, $y = 6t$, y $t$ va de $0$ a $1$:

::: pasos
\int_0^1 6t\,\dd t + (t + 2)^2\,6\,\dd t = \int_0^1 6t\,\dd t + \left(t^2 + 4t + 4\right)6\,\dd t
= \int_0^1 \left(6t^2 + 30t + 24\right)\dd t = \left(2t^3 + 15t^2 + 24t\right)\Big|_0^1 = 2 + 15 + 24
:::

::: resultado
$$
\int_L y\,\dx + x^2\,\dy = 41
$$
:::
:::
:::

## Ejercicio 4: área con integral curvilínea

::: ejercicio Calcular con una integral curvilínea el área de la región limitada por $x^2 = 4y$ y $y^2 = 4x$
::: solucion
**Despejo cada curva:**

- (1) $x^2 - 4y = 0 \then y = \dfrac{x^2}{4}$; **derivo:** $\dy = \dfrac{x}{2}\,\dx$.
- (2) $4x - y^2 = 0 \then x = \dfrac{y^2}{4}$; **derivo:** $\dx = \dfrac{y}{2}\,\dy$.

**Cortes:** $x^2 = 4y$ y $x = \frac{y^2}{4}$: $\frac{y^4}{16} = 4y \then y^3 = 64 \then y = 4$. Se cortan en $(0;0)$ y $(4;4)$.

**Sentido antihorario:** de $(0;0)$ a $(4;4)$ por la de abajo, (1), en $x$ de $0$ a $4$; y de vuelta por la de arriba, (2), en $y$ de $4$ a $0$.

```grafico
x^2/4 <= y <= 2 raiz(x), 0 <= x <= 4 ; "$D$"
(t, t^2/4) ; t: 0..4 ; azul ; gruesa ; flecha ; "$x^2 = 4y$"
((4 - t)^2/4, 4 - t) ; t: 0..4 ; rojo ; gruesa ; flecha ; "$y^2 = 4x$"
x: -0.5..5
y: -0.5..5
```

**Tramo (1):** $-y\,\dx + x\,\dy = -\frac{x^2}{4}\,\dx + x\cdot\frac{x}{2}\,\dx = \frac{x^2}{4}\,\dx$.

**Tramo (2):** $-y\,\dx + x\,\dy = -y\cdot\frac{y}{2}\,\dy + \frac{y^2}{4}\,\dy = -\frac{y^2}{4}\,\dy$.

::: pasos
A = \frac{1}{2}\int_0^4 \frac{x^2}{4}\,\dx + \frac{1}{2}\int_4^0 -\frac{y^2}{4}\,\dy
= \frac{1}{2}\cdot\frac{x^3}{12}\,\Big|_0^4 + \frac{1}{2}\left(-\frac{y^3}{12}\right)\Big|_4^0 = \frac{1}{2}\cdot\frac{16}{3} + \frac{1}{2}\cdot\frac{16}{3}
:::

::: resultado
$$
A = \frac{16}{3}\ \text{u.a.}
$$
:::

::: aclaracion
En la carpeta se integró hasta $3$ y dio $\frac{9}{4}$. Pero $x^2 = 4y$ y $y^2 = 4x$ se cortan en $(4;4)$, no en $x = 3$: el área es $\frac{16}{3}$. (Si el enunciado fuera $x^2 = 3y$ y $y^2 = 3x$, se cortarían en $(3;3)$ y el área sería $3$.) Control con una doble: $\int_0^4 \left(2\sqrt x - \frac{x^2}{4}\right)\dx = \frac{32}{3} - \frac{16}{3} = \frac{16}{3}$.
:::
