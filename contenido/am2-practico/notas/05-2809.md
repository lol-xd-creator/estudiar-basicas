# 28/09 · EDO homogéneas de 1.er orden

*Clase práctica del 28/09. La teoría está en [[3. Ecuaciones homogéneas]].*

::: claves
- **Forma:** $\dfrac{\dy}{\dx} = f(x;y)$. Se despeja $\dfrac{\dy}{\dx}$ de $M\,\dx + N\,\dy = 0$: $\dfrac{\dy}{\dx} = -\dfrac{M}{N}$.
- **Verificar que es homogénea:** se reemplaza $x \to \lambda x$ e $y \to \lambda y$. Si los $\lambda$ **se simplifican** y vuelve a quedar la misma $f(x;y)$, es homogénea.
- **Resolver:** cambio de variable
  $$y = t\,x \quad\then\quad \frac{\dy}{\dx} = x\,\frac{\dd t}{\dx} + t$$
  Se reemplaza, se simplifica la $x$ (siempre se va, si es homogénea) y se **pasa la $t$ restando**: $f(1;t) - t = x\,\dfrac{\dd t}{\dx}$.
- **Separar variables:** se invierten los dos lados (elevar a la $-1$) para pasar $\dd t$ multiplicando:
  $$\frac{\dd t}{f(1;t) - t} = \frac{\dx}{x}$$
- **Integrar:** el lado de $x$ da $\ln x + C$. En el de $t$, si es una fracción con el grado del denominador **mayor** que el del numerador, por **fracciones simples**.
- **Volver a $y$:** se reemplaza $t = \dfrac{y}{x}$. Esa es la **solución general**.
- **Propiedades de $\ln$** para simplificar: $a\ln b = \ln b^a$, $\ln a + \ln b = \ln(a\,b)$.
:::

## Ejercicio 1

::: ejercicio Resolver $(4y + 9x)\,\dx + (3y + 8x)\,\dy = 0$
::: solucion
**Despejo:** $\dfrac{\dy}{\dx} = \dfrac{4y + 9x}{-(3y + 8x)}$.

**Verifico** con $\lambda$:

$$
\frac{4\lambda y + 9\lambda x}{-(3\lambda y + 8\lambda x)} = \frac{\cancel{\lambda}\,(4y + 9x)}{\cancel{\lambda}\,(-3y - 8x)} = \frac{\dy}{\dx} \quad\then\quad \text{homogénea}
$$

**Resuelvo** con $y = t\,x$:

::: pasos
\frac{4t\,x + 9x}{-3t\,x - 8x} = x\,\frac{\dd t}{\dx} + t \then \frac{4t + 9}{-3t - 8} - t = x\,\frac{\dd t}{\dx}        // se simplifica la $x$
\frac{4t + 9 - t\,(-3t - 8)}{-3t - 8} = \frac{3t^2 + 12t + 9}{-3t - 8} = x\,\frac{\dd t}{\dx}
\int \frac{-3t - 8}{3t^2 + 12t + 9}\,\dd t = \int \frac{\dx}{x}        // invirtiendo los dos lados
\frac{1}{3}\int \frac{-3t - 8}{t^2 + 4t + 3}\,\dd t = \ln x + C        // sacando el $3$ del denominador
:::

**Fracciones simples** (cálculo auxiliar): $t^2 + 4t + 3 = (t + 1)(t + 3)$, raíces $-1$ y $-3$.

$$
\frac{-3t - 8}{(t + 1)(t + 3)} = \frac{A}{t + 1} + \frac{B}{t + 3} \quad\then\quad A\,(t + 3) + B\,(t + 1) = -3t - 8
$$

- con $t = -3$: $B\,(-2) = 9 - 8 = 1 \then B = -\frac{1}{2}$;
- con $t = -1$: $A\cdot 2 = 3 - 8 = -5 \then A = -\frac{5}{2}$.

::: pasos
\frac{1}{3}\left[-\frac{5}{2}\ln(t + 1) - \frac{1}{2}\ln(t + 3)\right] = \ln x + C
-\frac{5}{6}\ln(t + 1) - \frac{1}{6}\ln(t + 3) = \ln x + C
:::

**Vuelvo a $y$** con $t = \frac{y}{x}$:

::: resultado
$$
-\frac{5}{6}\ln\!\left(\frac{y}{x} + 1\right) - \frac{1}{6}\ln\!\left(\frac{y}{x} + 3\right) = \ln x + C
$$

Multiplicando por $-6$ y juntando los logaritmos se llega a una forma más corta: $(y + x)^5\,(y + 3x) = C$.
:::

::: aclaracion
En el recuadro final de la carpeta quedó $-\frac{5}{2}\ln\left(\frac{y}{x} + 1\right)$: es $-\frac{5}{6}$, como en el renglón anterior (el $\frac{1}{3}$ multiplica a los dos términos).
:::

## Ejercicio 2

::: ejercicio Resolver $-x\,y\,\dx + (x^2 + y^2)\,\dy = 0$
::: solucion
**Despejo y verifico:**

$$
\frac{\dy}{\dx} = \frac{x\,y}{x^2 + y^2} \qquad \frac{\lambda^2\,x\,y}{\lambda^2\,(x^2 + y^2)} = \frac{x\,y}{x^2 + y^2} \quad\then\quad \text{homogénea}
$$

**Resuelvo** con $y = t\,x$:

::: pasos
\frac{x\cdot t\,x}{x^2 + t^2x^2} = x\,\frac{\dd t}{\dx} + t \then \frac{t}{1 + t^2} - t = x\,\frac{\dd t}{\dx}
\frac{t - t\,(1 + t^2)}{1 + t^2} = \frac{-t^3}{1 + t^2} = x\,\frac{\dd t}{\dx}
\int \frac{1 + t^2}{-t^3}\,\dd t = \int \frac{\dx}{x}        // invirtiendo
-\int \left(t^{-3} + \frac{1}{t}\right)\dd t = \ln x + C        // separando la fracción: $\frac{1}{t^3} + \frac{t^2}{t^3}$
-\left[\frac{t^{-2}}{-2} + \ln t\right] = \ln x + C \then \frac{t^{-2}}{2} - \ln t = \ln x + C
:::

**Vuelvo a $y$:**

::: resultado
$$
\frac{1}{2}\left(\frac{y}{x}\right)^{-2} - \ln\frac{y}{x} = \ln x + C
$$

Como $\ln\frac{y}{x} + \ln x = \ln y$, también se puede escribir $\dfrac{x^2}{2y^2} = \ln y + C$.
:::
