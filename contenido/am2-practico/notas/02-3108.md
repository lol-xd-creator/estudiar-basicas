# 31/08 · Áreas entre curvas con integrales dobles

*Clase práctica del 31/08. La teoría está en [[5. Área y volumen]] y [[3. Dominios generales]].*

::: claves
- **Siempre graficar primero:** se ve qué curva es techo, cuál es piso y si cambian.
- **Cortes:** igualar las curvas de a dos. Dan los límites de $x$.
- **Área entre curvas:**
  $$A = \int_a^b\!\int_{\text{piso}}^{\text{techo}} \dy\,\dx = \int_a^b \left(\text{techo} - \text{piso}\right)\dx$$
- **Si el techo o el piso cambian** (porque se cruzan curvas o porque la región tiene más de dos bordes), se parte en una integral por tramo.
- **Control:** el área siempre da **positiva**. Si da negativa, el techo y el piso están invertidos.
- Un **eje** o una recta vertical ($x = 0$, $x = 2$…) también puede ser un borde de la región.
:::

## Ejercicio 1

::: ejercicio Calcular el área bajo $y = \dfrac{1}{x}$, sobre el eje $x$, entre $x = 1$ y $x = 3$ (la recta $y = 2x - 1$ corta a la curva en $(1;1)$)
::: solucion
```grafico
1 <= x <= 3, 0 <= y <= 1/x ; "$D$"
y = 1/x ; x: 0.3..4 ; azul ; "$y = \frac{1}{x}$"
y = 2x - 1 ; x: 0.3..2.2 ; rojo ; "$y = 2x - 1$"
x: 0..4
y: -0.3..3.4
```

::: ojo
El techo es $y = \frac{1}{x}$, **no** la recta: la recta queda por encima de la región. Por eso en la carpeta se tachó el primer intento, $\int_1^3\!\int_0^{2x - 1}\dy\,\dx = 6$.
:::

::: pasos
A = \int_1^3\!\int_0^{1/x} \dy\,\dx = \int_1^3 \frac{1}{x}\,\dx = \ln x\,\Big|_1^3 = \ln 3 - \ln 1
:::

::: resultado
$$
A = \ln 3 \approx 1{,}10\ \text{u.a.}
$$
:::

En la carpeta quedó planteada hasta $\int_1^3 \frac{1}{x}\,\dx$.
:::

## Ejercicio 3: se cruzan las curvas

::: ejercicio Calcular el área entre $y = x^2$ y $y = x$, desde $x = 0$ hasta $x = 2$
::: solucion
Las curvas se cortan en $x = 0$ y $x = 1$ ($x^2 = x$). Entre $0$ y $1$ la recta está arriba; entre $1$ y $2$, la parábola. Hay que partir en $x = 1$.

```grafico
min(x, x^2) <= y <= max(x, x^2), 0 <= x <= 2 ; "$D$"
y = x^2 ; azul ; "$y = x^2$"
y = x ; rojo ; "$y = x$"
segmento (2, 0) (2, 4) ; gris ; punteada
x: -0.5..2.5
y: -0.5..4.5
```

::: pasos
A = \int_0^1\!\int_{x^2}^{x} \dy\,\dx + \int_1^2\!\int_x^{x^2} \dy\,\dx = \int_0^1 \left(x - x^2\right)\dx + \int_1^2 \left(x^2 - x\right)\dx
= \left(\frac{x^2}{2} - \frac{x^3}{3}\right)\Big|_0^1 + \left(\frac{x^3}{3} - \frac{x^2}{2}\right)\Big|_1^2 = \frac{1}{6} + \left[\left(\frac{8}{3} - 2\right) - \left(\frac{1}{3} - \frac{1}{2}\right)\right] = \frac{1}{6} + \frac{5}{6}
:::

::: resultado
$$
A = 1\ \text{u.a.}
$$
:::

## Ejercicio 4: tres curvas y el eje $y$

::: ejercicio Calcular el área de la región limitada por $y = x + 2$, $y = -2x + 5$, $y = x^2 - x - 1$ y el eje $y$ ($x = 0$)
::: solucion
**Cortes:** las rectas, $x + 2 = -2x + 5 \then x = 1$; la parábola con $y = -2x + 5$: $x^2 + x - 6 = 0 \then x = 2$. El **piso** es la parábola; el **techo** es $y = x + 2$ hasta $x = 1$ y $y = -2x + 5$ después.

```grafico
x^2 - x - 1 <= y <= min(x + 2, -2x + 5), 0 <= x <= 2 ; "$D$"
y = x^2 - x - 1 ; azul ; "$y = x^2 - x - 1$"
y = x + 2 ; rojo ; "$y = x + 2$"
y = -2x + 5 ; violeta ; "$y = -2x + 5$"
x: -1.5..3.5
y: -2..5
```

::: pasos
A = \int_0^1\!\int_{x^2 - x - 1}^{x + 2} \dy\,\dx + \int_1^2\!\int_{x^2 - x - 1}^{-2x + 5} \dy\,\dx
= \int_0^1 \left(-x^2 + 2x + 3\right)\dx + \int_1^2 \left(-x^2 - x + 6\right)\dx
= \left(-\frac{x^3}{3} + x^2 + 3x\right)\Big|_0^1 + \left(-\frac{x^3}{3} - \frac{x^2}{2} + 6x\right)\Big|_1^2 = \frac{11}{3} + \left(\frac{22}{3} - \frac{31}{6}\right) = \frac{11}{3} + \frac{13}{6}
:::

::: resultado
$$
A = \frac{35}{6}\ \text{u.a.}
$$
:::

::: aclaracion
En la carpeta, la primera integral quedó con $(x - 2)$ en lugar de $(x + 2)$: da $-x^2 + 2x - 1$ y un total de $\frac{11}{6}$. Con $x + 2$ sale $\frac{35}{6}$, que es la respuesta anotada al lado del gráfico.
:::

## Ejercicio 5: cambia el piso

::: ejercicio Calcular el área de la región limitada por $y = 4 - x^2$, $y = -2 - x$, $y = -x^2 + 2x - 2$ y la recta $x = 2$
::: solucion
**Cortes:**

- $4 - x^2 = -2 - x \then x^2 - x - 6 = 0 \then x = -2$ (punto $(-2;0)$, el borde izquierdo);
- $-2 - x = -x^2 + 2x - 2 \then x^2 - 3x = 0 \then x = 0$ (punto $(0;-2)$, donde cambia el piso).

El **techo** es siempre $y = 4 - x^2$. El **piso** es la recta $y = -2 - x$ entre $-2$ y $0$, y la parábola de abajo entre $0$ y $2$.

```grafico
max(-2 - x, -x^2 + 2x - 2) <= y <= 4 - x^2, -2 <= x <= 2 ; "$D$"
y = 4 - x^2 ; azul ; "$y = 4 - x^2$"
y = -2 - x ; rojo ; "$y = -2 - x$"
y = -x^2 + 2x - 2 ; violeta ; "$y = -x^2 + 2x - 2$"
segmento (2, -3) (2, 1) ; gris ; punteada
x: -3..3
y: -4..5
```

::: pasos
A = \int_{-2}^{0}\!\int_{-2 - x}^{4 - x^2} \dy\,\dx + \int_0^2\!\int_{-x^2 + 2x - 2}^{4 - x^2} \dy\,\dx
= \int_{-2}^{0} \left(6 + x - x^2\right)\dx + \int_0^2 \left(6 - 2x\right)\dx        // en la segunda se cancela $x^2$
= \left(6x + \frac{x^2}{2} - \frac{x^3}{3}\right)\Big|_{-2}^{0} + \left(6x - x^2\right)\Big|_0^2 = \left(12 - 2 - \frac{8}{3}\right) + (12 - 4) = \frac{22}{3} + 8
:::

::: resultado
$$
A = \frac{46}{3}\ \text{u.a.}
$$
:::

En la carpeta quedó planteado; la cuenta está terminada acá.
