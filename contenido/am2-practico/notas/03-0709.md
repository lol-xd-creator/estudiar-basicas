# 07/09 · Integrales dobles en polares

*Clase práctica del 07/09. La teoría está en [[3. Integrales dobles en coordenadas polares]].*

::: claves
- **Cuándo:** siempre que la región sea una **circunferencia o parte de ella** (círculo, cuarto de círculo, anillo, lemniscata).
- **Cambio:** $x = r\cos\theta$, $y = r\sen\theta$ y
  $$\dx\,\dy = r\,\dr\,\dd\theta$$
  **No olvidarse la $r$** (es el jacobiano).
- **Identidad:** $\cos^2\theta + \sen^2\theta = 1$, así que $x^2 + y^2 = r^2$. La circunferencia $x^2 + y^2 = a^2$ es $r = a$.
- **Límites de $\theta$:** desde el eje $x$ positivo, en **sentido antihorario**, hasta donde llega la región. 1.er cuadrante: $0$ a $\frac{\pi}{2}$; círculo entero: $0$ a $2\pi$.
- **Límites de $r$:** desde el centro (o la circunferencia de adentro) hasta la curva de afuera. Anillo $a^2 \le x^2 + y^2 \le b^2$: $a \le r \le b$.
- **Área:** $A = \displaystyle\iint r\,\dr\,\dd\theta$. **Volumen** bajo $z = f(x;y)$: $V = \displaystyle\iint f\;r\,\dr\,\dd\theta$. Si adentro de la integral hay algo distinto de $1$, se calcula un **volumen**.
- **Analizar $z$:** reemplazar $x$ e $y$ en la superficie. Por ejemplo, $z = 9 - x^2 - y^2 \then z = 9 - r^2$.
- **Integral de tabla:** $\int u'\cos u\,\dd\theta = \sen u$. Por ejemplo, $\int 2\cos(2\theta)\,\dd\theta = \sen(2\theta)$.
- **Simetría:** si la región tiene partes iguales, se calcula una y se multiplica (lemniscata: $4$ partes).
:::

## Ejercicio 1: cuarto de círculo

::: ejercicio Calcular el área de la región del 1.er cuadrante limitada por $x^2 + y^2 = 4$
::: solucion
$x^2 + y^2 = 4 \then r^2 = 4 \then r = 2$. En el 1.er cuadrante, $0 \le \theta \le \frac{\pi}{2}$.

```grafico
r <= 2, 0 <= θ <= pi/2 ; "$D$"
x^2 + y^2 = 4 ; gris ; punteada ; ""
x: -2.5..2.5
y: -2.5..2.5
```

::: pasos
A = \int_0^{\pi/2}\!\int_0^2 r\,\dr\,\dd\theta = \int_0^{\pi/2} \frac{r^2}{2}\,\Big|_0^2\,\dd\theta = \int_0^{\pi/2} 2\,\dd\theta = 2\theta\,\Big|_0^{\pi/2} = 2\cdot\frac{\pi}{2}
:::

::: resultado
$$
A = \pi\ \text{u.a.}
$$
:::

Control: es un cuarto del círculo, $\frac{1}{4}\pi\,2^2 = \pi$.
:::
:::

## Ejercicio 2: anillo

::: ejercicio Calcular el área de la región entre las circunferencias $x^2 + y^2 = 4$ y $x^2 + y^2 = 25$
::: solucion
$r$ va de $2$ a $5$, y $\theta$ da la vuelta entera: de $0$ a $2\pi$.

```grafico
2 <= r <= 5 ; "$D$"
x: -6..6
y: -6..6
```

::: pasos
A = \int_0^{2\pi}\!\int_2^5 r\,\dr\,\dd\theta = \int_0^{2\pi} \frac{r^2}{2}\,\Big|_2^5\,\dd\theta = \int_0^{2\pi} \left(\frac{25}{2} - 2\right)\dd\theta = \int_0^{2\pi} \frac{21}{2}\,\dd\theta = \frac{21}{2}\cdot 2\pi
:::

::: resultado
$$
A = 21\pi\ \text{u.a.}
$$
:::
:::
:::

## Ejercicio 3: volumen (tipo parcial)

::: ejercicio Encontrar el volumen del paraboloide $z = 9 - x^2 - y^2$ dentro del cilindro $x^2 + y^2 = 4$
::: solucion
```grafico3d
0 <= z <= 9 - x^2 - y^2, x^2 + y^2 <= 4
```

**Analizo $z$:** $z = 9 - (r\cos\theta)^2 - (r\sen\theta)^2 = 9 - r^2(\cos^2\theta + \sen^2\theta) = 9 - r^2$.

**Región:** el círculo $r \le 2$, $0 \le \theta \le 2\pi$.

::: pasos
V = \iint z\,\dx\,\dy = \int_0^{2\pi}\!\int_0^2 \left(9 - r^2\right) r\,\dr\,\dd\theta = \int_0^{2\pi}\!\int_0^2 \left(9r - r^3\right)\dr\,\dd\theta
= \int_0^{2\pi} \left(\frac{9r^2}{2} - \frac{r^4}{4}\right)\Big|_0^2\,\dd\theta = \int_0^{2\pi} (18 - 4)\,\dd\theta = 14\cdot 2\pi
:::

::: resultado
$$
V = 28\pi\ \text{u.v.}
$$
:::
:::
:::

## Ejercicio 4: lemniscata

::: ejercicio Calcular el área encerrada por la lemniscata $r = \sqrt{4\cos 2\theta}$
::: solucion
La curva tiene **dos lazos**, y el eje $x$ parte cada uno en dos mitades iguales: son **4 partes iguales**. Se calcula la del 1.er cuadrante, donde $\theta$ va de $0$ a $\frac{\pi}{4}$ (en $\frac{\pi}{4}$, $\cos 2\theta = 0$ y la curva vuelve al origen), y se multiplica por $4$.

```grafico
r^2 <= 4 cos(2θ) ; "" ; rayado
r^2 <= 4 cos(2θ), 0 <= θ <= pi/4 ; rojo ; "$\frac{1}{4}$"
segmento (0, 0) (1.3, 1.3) ; gris ; punteada
texto (1.45, 1.35) "$\frac{\pi}{4}$"
x: -2.5..2.5
y: -1.5..1.5
```

::: pasos
A = 4\int_0^{\pi/4}\!\int_0^{\sqrt{4\cos 2\theta}} r\,\dr\,\dd\theta = 4\int_0^{\pi/4} \frac{r^2}{2}\,\Big|_0^{\sqrt{4\cos 2\theta}}\,\dd\theta
= 4\int_0^{\pi/4} \frac{4\cos 2\theta}{2}\,\dd\theta = 4\int_0^{\pi/4} 2\cos(2\theta)\,\dd\theta        // la raíz al cuadrado se va
= 4\,\sen(2\theta)\,\Big|_0^{\pi/4} = 4\left[\sen\frac{\pi}{2} - \sen 0\right] = 4\,(1 - 0)        // $\int u'\cos u = \sen u$
:::

::: resultado
$$
A = 4\ \text{u.a.}
$$
:::
:::
:::

## Ejercicio 5: círculo menos parábola

::: ejercicio Calcular el área de la región del 1.er cuadrante que queda entre la circunferencia $x^2 + y^2 = 9$ y la parábola $y = -x^2 - 2x + 3$
::: solucion
La parábola pasa por $(0;3)$ y $(1;0)$, y la región es el **cuarto de círculo menos lo que queda bajo la parábola**: el cuarto de círculo en polares y lo de la parábola con una doble común.

```grafico
x^2 + y^2 <= 9, x >= 0, y >= 0, y >= -x^2 - 2x + 3 ; "$D$"
y = -x^2 - 2x + 3 ; x: -3.2..1.6 ; azul ; "$y = -x^2 - 2x + 3$"
x^2 + y^2 = 9 ; gris ; ""
x: -3.5..3.5
y: -3.5..4.5
```

::: pasos
A = \underbrace{\int_0^{\pi/2}\!\int_0^3 r\,\dr\,\dd\theta}_{\text{polar}} - \underbrace{\int_0^1\!\int_0^{-x^2 - 2x + 3} \dy\,\dx}_{\text{doble}}
= \int_0^{\pi/2} \frac{9}{2}\,\dd\theta - \int_0^1 \left(-x^2 - 2x + 3\right)\dx
= \frac{9}{2}\cdot\frac{\pi}{2} - \left(-\frac{x^3}{3} - x^2 + 3x\right)\Big|_0^1 = \frac{9\pi}{4} - \left(-\frac{1}{3} - 1 + 3\right) = \frac{9\pi}{4} - \frac{5}{3}
:::

::: resultado
$$
A = \frac{9\pi}{4} - \frac{5}{3} \approx 5{,}40\ \text{u.a.}
$$
:::

::: aclaracion
En la carpeta, después de $5{,}40$ figura $= \frac{7}{12}\pi$, pero eso vale $1{,}83$: no son iguales. El resultado es $\frac{9\pi}{4} - \frac{5}{3} = \frac{27\pi - 20}{12} \approx 5{,}40$.
:::

## Ejercicios 6 y 7: más volúmenes

::: ejercicio Calcular el volumen de **a)** $z = 16 - x^2 - y^2$ dentro de $x^2 + y^2 = 4$ y **b)** $z = 25 - x^2 - y^2$ dentro de $x^2 + y^2 = 9$
::: solucion
Igual que el ejercicio 3. Analizando $z$: **a)** $z = 16 - r^2$ con $r \le 2$; **b)** $z = 25 - r^2$ con $r \le 3$.

**a)**

::: pasos
V = \int_0^{2\pi}\!\int_0^2 \left(16r - r^3\right)\dr\,\dd\theta = \int_0^{2\pi} \left(\frac{16r^2}{2} - \frac{r^4}{4}\right)\Big|_0^2\,\dd\theta = \int_0^{2\pi} (32 - 4)\,\dd\theta = 28\cdot 2\pi
:::

**b)**

::: pasos
V = \int_0^{2\pi}\!\int_0^3 \left(25r - r^3\right)\dr\,\dd\theta = \int_0^{2\pi} \left(\frac{25\cdot 9}{2} - \frac{81}{4}\right)\dd\theta = \int_0^{2\pi} \frac{369}{4}\,\dd\theta = \frac{369}{4}\cdot 2\pi
:::

::: resultado
$$
\text{a)}\ V = 56\pi\ \text{u.v.} \qquad \text{b)}\ V = \frac{369}{2}\pi\ \text{u.v.}
$$
:::
:::
:::

## Ejercicio 8: repaso de área entre curvas

::: ejercicio Hallar el área de la región comprendida entre la parábola $y = 4 - x^2$ y la recta $y = x + 2$
::: solucion
**Cortes:** $4 - x^2 = x + 2 \then x^2 + x - 2 = 0 \then x = -2$ y $x = 1$. La parábola es el techo; la recta, el piso.

```grafico
x + 2 <= y <= 4 - x^2, -2 <= x <= 1 ; "$D$"
y = 4 - x^2 ; azul ; "$y = 4 - x^2$"
y = x + 2 ; rojo ; "$y = x + 2$"
x: -3..3
y: -1.5..5
```

::: pasos
A = \int_{-2}^{1}\!\int_{x + 2}^{4 - x^2} \dy\,\dx = \int_{-2}^{1} \left(-x^2 - x + 2\right)\dx = \left(-\frac{x^3}{3} - \frac{x^2}{2} + 2x\right)\Big|_{-2}^{1}
= \frac{7}{6} - \left(-\frac{10}{3}\right)
:::

::: resultado
$$
A = \frac{9}{2}\ \text{u.a.}
$$
:::

::: aclaracion
En la carpeta se integró de $-2$ a $2$ (las raíces de $4 - x^2 = 0$) y dio $\frac{8}{3}$. Los límites son los **cortes entre las dos curvas**, $-2$ y $1$, como se ve en el gráfico: el área es $\frac{9}{2}$.
:::
:::
:::
